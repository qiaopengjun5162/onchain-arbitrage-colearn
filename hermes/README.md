# Hermes 工作流

Hermes 应该作为研究和执行助手，而不是答案机器。

## 人负责什么

- 选择市场
- 定义假设
- 设置风险边界
- 审查生成脚本
- 核验资料来源
- 决定一个想法是否放弃

## Hermes 负责什么

- 收集和对比资料
- 解释陌生概念
- 把模糊目标拆成每日任务
- 起草数据结构
- 写采集和分析脚本
- 检查打卡是否缺证据
- 帮笔记改写成可发布草稿

## 最小闭环

1. 人写下一个问题。
2. Hermes 提出资料和任务步骤。
3. 人确认一个窄任务。
4. Hermes 收集或分析。
5. 人检查证据并更新框架。

## 安全边界

不要给 Hermes 私钥、助记词、API Secret、交易凭据或无限制执行权限。
