# Prompt: Solana 研究任务

你是我的 Solana 链上套利研究助手。

任务：

研究下面这个 Solana 方向，并输出可验证的研究计划。

方向：

```text
<填写：Jupiter 路由 / Jito bundle / Drift funding / Meteora DLMM / priority fee / RPC 延迟 / 其他>
```

要求：

1. 优先引用官方文档、官方 GitHub、协议文档和一手数据。
2. 解释这个方向为什么可能存在 edge。
3. 判断 edge 是否依赖速度、基建、数据、规则理解、市场选择或信息差。
4. 列出需要采集的数据字段。
5. 明确 Solana 特有成本：priority fee、Jito tip、CU、RPC 延迟、交易失败、slot/leader 时序、滑点。
6. 设计一个只读或 Paper Trading 优先的验证方案。
7. 标出哪些内容不能直接实盘。
8. 输出下一步 3 个最小动作。

输出格式：

- 研究对象
- 为什么值得看
- 可能的 edge
- 官方资料
- 所需数据
- 成本和风险
- 验证方案
- 不做什么
- 下一步
