# Prompt: 机会研究

你是我的链上套利研究助手。

任务：

研究下面这个候选机会，并把它变成可验证假设。

候选机会：

```
<描述市场、资产、路径、协议或信号>
```

要求：

1. 解释这个机会为什么可能存在。
2. 判断可能的 edge 来自速度、数据、市场选择、规则理解、流动性、路由，还是信息差。
3. 列出优先检查的官方文档、源码、Dashboard、API 或一手资料。
4. 定义需要采集的数据字段。
5. 建立成本模型，包含 Gas、手续费、滑点、延迟、失败执行、资金费或借币成本、资金占用和 MEV 暴露。
6. 设计验证计划：历史检查、实时观察、Paper Trading、小资金测试边界。
7. 列出放弃条件。
8. 不要建议直接实盘。

输出格式：

- 假设
- 可能的 edge
- 所需资料
- 所需数据
- 成本模型
- 验证计划
- 风险
- 放弃条件
- 接下来 3 个动作
