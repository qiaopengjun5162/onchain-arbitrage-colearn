# 共学 D3：Solana 第一笔真实 swap 全流程

> 链上套利残酷共学 · 第 3 天
> 2026-08-07

---

计划里 D3 是"第一笔 devnet swap"，最后变成了 mainnet 真实小额 swap——中间踩了三个坑，每个都值得记下来。

---

## 坑一：Jupiter 旧 API 已下线/被墙

按计划先探测 Jupiter API 连通性。`quote-api.jup.ag` 的 v6/v7 端点**超时无响应**——DNS 正常，但连接不通（中国网络被墙）。

现行 API 是：

```
https://api.jup.ag/swap/v1/quote   （Metis 路由引擎报价）
https://api.jup.ag/swap/v2/build   （Router 路径，返回 raw instructions）
```

而且从中国网络直连依然超时，**必须走本机 Clash 代理 `127.0.0.1:7890`** 才能访问。

## 坑二：Jupiter 只路由 mainnet，devnet 无池

quote 成功后想发 devnet swap——结果发现 **Jupiter Swap API 只索引 MAINNET 流动性**。devnet 上 program 和 USDC mint 都在，但 Metis 路由引擎不索引 devnet 的池子，无池可路由。

结论：devnet 上没有现成池子，想练 devnet 得自己用 Raydium SDK 建测试池（工程量不小，留给后续）。

**决定：改走 mainnet 极小金额真实 swap**——0.01 SOL（约 0.73 美元），风险可忽略。

## 执行记录：quote → build → 签名 → 广播

1. **quote**：0.01 SOL → 0.73 USDC（minOut 0.72，slippage 1%）
2. **build**：拿到 computeBudget + 4 条 setup + swapInstruction（JUP6Lk...）+ 4 张 lookup table
3. **组装**：`@solana/web3.js` 组装 v0 transaction，本地 `id.json` 签名（私钥不出本机）
4. **广播**：发送到 mainnet Helius RPC → confirmed

## 坑三：客户端自报成功 ≠ 链上可查

广播后客户端立刻返回 SUCCESS，但**马上查 `getTransaction` 是 NOT FOUND**——索引延迟约 3 秒，等几秒再查才成功。

这个教训很重要：**「客户端自报」不能当「链上可查」的证据**。验证必须用二值判据（tx hash 在 Solscan/链上存在才算数），这也是这几天共学一直在强调的方法论。
