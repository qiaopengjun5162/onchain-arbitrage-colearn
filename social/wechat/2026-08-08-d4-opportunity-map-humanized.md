# 共学 D4：主流价差磨平之后，机会地图重画

> 链上套利残酷共学 · 第 4 天
> 2026-08-08

第四天我只干了一件事，把"主流币跨所搬砖还有没有肉"这个问号，用真实数据钉在墙上。答案是没肉。但这个负结果反而逼出了一张全新的机会地图。

这一天下来，仓库里多了 8 个监控哨兵、31 篇归档笔记、1 个公开 GitHub 仓库，外加 Python 和 Rust 两套实现。下面的讲法按三步走，先钉死旧的，再画出新的，最后说方法论沉淀了什么。

---

## 一、钉死旧的：主流币跨所价差已被磨平

先写了监控脚本 `cex_spread_monitor.py`，用 ccxt 只读接 okx、bitget、kucoin、gate 四家交易所，实测 BTC、ETH、SOL 三个主流币。结果如下表。

| 指标 | 实测值 |
|---|---|
| 毛价差最大 | 1.62 bps（ETH gate→okx） |
| 扣成本后净收益 | **-24 ~ -37 bps（全为负）** |
| 成本构成 | 手续费 20bps + 提币费 + 滑点 5bps |

结论就一句话，主流币跨所搬砖没机会。这跟赛道选择图上那条"跨链 60.6bps 成本对 26.49bps 价差"的曲线完全对得上，主流币的价差早让专业团队、同机房机器和 API 权限磨平了。

但脚本本身还能复用，长尾币和新币刚上架的那一刻，才是价差还活着的地方。负结果也是有效产出，这是共学第一天就定下的原则。

## 二、新地图①：币股时钟差，闭市漂移 30-100bps

同一脚本加 `--stocks` 模式，挖到一个更值钱的结构。xStocks 币股只有 gate 一家上架，okx、bitget、kucoin 都没有，跨所没有对手盘。正确的对手是真实美股，赚的是时钟差。

周六美股闭市实测，6 只触发 ≥30bps 信号，见下表。

| 币股 | 溢价 |
|---|---|
| MCDX（麦当劳） | **+103.5 bps** |
| SPYX（标普） | +66.3 bps |
| GOOGLX（谷歌） | +43.5 bps |
| AVGOX（博通） | +38.0 bps |
| COINX（Coinbase） | +34.2 bps |
| TSLAX（特斯拉） | +31.5 bps |

全部溢价，方向一致。机制不难理解，美股闭市时币股失去锚定，价格被情绪推离，开盘瞬间就有收敛压力。这是还没被磨平的结构差。

> 数据坑记录，NFLXX 用 yfinance 对不上（NFLX $74.14 vs gate 744.29，10 倍差），数据源异常已剔除待核。

## 三、新地图②：资金费率拥挤度，Z-score + OI 交叉

把私信分享的《优化 Funding Rate 交易信号》方法论落成脚本 `funding_sentinel_v2.py`，拆成两步做。

- Z-score 标准化（30 条滚动历史）→ 横截面 Rank → OI 交叉 → 价格维度（扛单检测）
- 首跑实测，SOL 拥挤积累（okx z=1.76）、XRP 被动扛单（z=3.67 + 24h 横盘）、DOGE/ETH/BTC 单所显著

踩坑沉淀，单所显著会被平均稀释，判定用 max_z。gate 没有 OI 数据。funding 8 小时结算一次，哨兵挂 8h cron。

## 四、新地图③：同链跨 DEX，还有 17-20bps

Solana 侧主线，DEX 价差监控 v0，双数据源交叉验证，两条腿分别走。

1. Helius RPC 直读 Raydium SOL-USDC 池 vault（恒定乘积定价 + 模拟 1 SOL swap）
2. Jupiter Swap API 多金额采样（0.1/1/10/100 SOL），观察 AMM 路由选择

实测（Python），Raydium 直读 73.81 对 Jupiter HumidiFi 73.94，池间价差约 17bps。

然后用 Rust 重写同一套逻辑（`solana-rs spread` 子命令），实测 20.7bps，和 Python 版互相印证。这是本项目"Python + Rust 双实现"的惯例，两种语言、同一套逻辑，谁也别想骗过谁。

这里有个关键发现，不同金额会触发不同的 AMM。0.1、1、10 SOL 走 HumidiFi 单池，100 SOL 就变成 BisonFi、HumidiFi、SolFi V2 四池拆分路由。大额 swap 被拆了腿，报价就得按每条腿的 inAmount 和 outAmount 算，不能盯着总金额。

> 意义在于，同链跨 DEX 监控是第二周 Jito 原子套利的数据基础。机会在链上，CEX 之间的路已经走到头了。

## 六、链上取证：解剖两个真实套利地址

D4 完成了两份取证级地址调研，用横纵分析法，已经沉淀成 `onchain-address-forensics` skill。下面逐个解剖。

**① Aave 清算器 0x8d64（四角色系统）**

```
① Aave V3 FlashLoan 借 LINK（premium 0.05%）
② liquidationCall 替借款人还债 → 领 USDC 抵押品
③ Bebop RFQ 精确换回还款资产
④ 归还闪电贷 → 利润 0.5366 WETH 全部付给 BuilderNet
```

> 一句话，真实利润取决于事后的 refund，链上那笔表面转账当不了真。用闪电贷零本金抢清算折价，把 surplus 报给私有区块构建者，换排序权。

**② Robinhood 套利器 0xd712（高频 + 便宜失败）**

- 68 万笔交易不等于 68 万笔盈利，归集地址余额也不等于累计利润
- 三角色架构，提交 EOA（签名付 gas）→ 原子执行代理（合约余额 = 0，不留库存）→ 利润归集地址
- 最近 20 笔里 9 成功、11 失败，失败吃掉约一半 gas。长期期望 = 成功率 × 净利 − 失败率 × 失败成本
- 成功单笔 $0.17~$0.64，回报率低到 0.0672% 也执行。最低利润阈值可能很低，也可能上链后价差已经缩了

> 方法论，从失败交易反推成本结构（gasUsed=74643、$0.0045）比猜策略更可靠。"链下模拟器"才是这类机器人的护城河。

## 八、吃费率的真正对手：逆向选择成本

D4 补读三篇广度笔记（toll-fee-pool / premium-buyin-lp / funding-fee-arbitrage-1token），三篇串起来看，收获有三条。

1. LP 过路费已经被回测证伪，高费率池吃不到流量，LVR 逆向选择把手续费吃掉。机器人走你的池，恰恰因为你价格滞后，你系统性站在价格发现的错误一侧
2. 溢价买 LP 入场券，花 50-150u 溢价换高利差收入，把价差回归风险换成已知上限的成本
3. 资金费套利，收益 = 资金费 − 基差收敛成本 − 执行成本。高 funding + 高 basis 分位 = 接盘信号

> 共同的方法论，吃费率的真正对手是逆向选择成本（LVR/基差/知情流量）。按笔算账，不能按 APR 外推。
