# 共学 D2：套利分层——价差、MEV 与执行成本

> 链上套利残酷共学 · 第 2 天
> 2026-08-06

---

第二天的主题是「分层」。群里讨论时经常把两种完全不同的套利混在一起，我花了一天把它们拆开，顺便盘了四个工具，最后用真实报价算了一笔执行成本账。

结论先放前面：**套利不是只有 MEV，而个人开发者的路，很可能不在 MEV。**

---

## 一、价差套利 vs MEV 套利：先把概念分开

| | 价差套利 | MEV 套利 |
|---|---|---|
| **关注点** | 找**目标**：不同市场/资产间的价格不一致 | 找**手段**：利用交易排序权和 mempool |
| **核心动作** | 买低卖高 | 抢跑 / 夹击 / 尾随 |
| **典型形式** | 跨所套利、三角套利、期现套利 | 三明治攻击、Back-running、清算抢跑 |
| **利润来源** | 市场定价失效 | 区块排序权 |
| **对普通用户** | 中性甚至正面（抹平价差） | 负面（抬高交易成本） |
| **依赖** | 多市场数据、快速执行 | mempool 可见性、区块构建权 |

实际策略里两者经常交织：发现跨所价差是价差套利，但要用 MEV 手法抢在别人前面执行——这时价差是目标，MEV 是手段。分不清这个概念，后面讨论工具、讨论策略都会跑偏。

---

## 二、今天盘的四个工具

**1. Gate CrossEx — 跨所统一保证金**

聚合 Binance、OKX、Bybit、Kraken、Hyperliquid、Deribit 等 7 个交易所，核心卖点是把跨所套利的两大痛点干掉：单边爆仓风险（两边浮盈浮亏对冲）和保证金平衡（不用频繁调仓）。作者实测 SKHYNIX/SKHY 溢价 40%+，6000u 10x 杠杆赚 3500u。5 倍杠杆下传统跨所波动 20% 就单边爆仓，CrossEx 要价差拉大 20% 才爆。

**2. Backpack — 交易所把套利路径喂给你**

聚合数据后直接在界面展示套利路径，零门槛。但所有人看到同样的路径，利润窗口极短——本质是"搬砖"不是 alpha。它提醒我一件事：**交易所展示的机会往往是竞争最充分的，真 edge 来自信息不对称或基础设施优势。**

**3. LI.FI — 跨链执行基础设施**

聚合 Bridge、DEX、Solver 的统一 API。它不是策略系统——策略负责"哪里有机会、扣完成本值不值得做"，LI.FI 负责"资金怎么走、要花多少钱、执行到哪一步"。后面单独算账。

**4. LP 过路费 — 从套利机器人身上收钱**

常规路径卷不过套利机器人，那就换个方向：在机器人经常经过的位置（高流量交易对、反复穿越的价格区间）放一个高费率池，收它的过路费。入场条件是爆量、缺池、剧烈波动、反复穿越。精髓是**不卷速度**——承认 MEV 层面卷不过专业团队，利用他们的存在本身作为收益来源。

---

## 三、用真实报价算执行成本：25 bps 能吃掉多少价差

跨链套利最容易踩的坑是只看两边的价格差，忽略执行磨损。我用 LI.FI 对 Ethereum USDC → Arbitrum USDC 做了一次真实只读报价（未签名、未广播）：

```
输入:         1,000 USDC (Ethereum)
预计到手:     997.5 USDC
LI.FI 服务费: 2.5 USDC = 25 bps
Gas:          ~0.15 美元
总显性成本:   ~2.65 美元 ≈ 26.5 bps
```

**结论一：稳定币跨链没有套利空间。** 表面价差只有 ~9 bps，远低于 26.5 bps 的成本线。

**结论二：25 bps 是绝对大头。** 套利机会的边际经常只有几十个 bps——表面价差 20 bps，光 LI.FI 费用就吃掉了；价差 40 bps，扣完 Gas、目标链滑点、延迟风险后也未必有利润。

算账公式：

```
最低所需价差 = LI.FI Service Fee (25 bps)
            + 两端 Gas
            + 目标链交易滑点 + Price Impact
            + 延迟 / 失败 / 资金占用成本
            ≈ 30-35 bps（实测量级）
```

**结论三：更适合这条路的是非稳定币。** 代币化股票（如 NVDAx）、波动性资产，或者用"预置资金"模式——提前在各链放好钱，不临时跨链，把"抓机会"和"跨链调仓"拆开。

---

## 四、个人开发者该走哪条路

MEV vs API 套利的分层很清楚：

| | MEV（链底层） | API 套利（应用层） |
|---|---|---|
| **拼什么** | mempool 监听、排序、Gas 优化、Builder 竞争 | 多 DEX 报价、价差发现、自动执行 |
| **需要什么** | 节点、低延迟基础设施 | 不需要节点，API 即可 |
| **核心竞争** | 毫秒级链上优势 | 策略、资金、滑点管理 |
| **适合谁** | 专业团队 | 个人开发者 |

我的结论：**个人开发者先做聚合套利、CEX-DEX 套利（API 层），积累策略能力后再考虑 MEV。** 一层一层往上打，不要跳过 API 层直接冲链底层。
