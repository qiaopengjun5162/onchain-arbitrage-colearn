第四天的核心动作只有一个：**把"主流币跨所搬砖还有没有肉"用真实数据钉死。** 结论是没有——但这个负结果，逼出了一张全新的机会地图。

## 一、钉死旧的：主流币跨所价差已被磨平

先写监控脚本 `cex_spread_monitor.py`（ccxt 接 okx/bitget/kucoin/gate 四所，只读），实测 BTC/ETH/SOL：

| 指标 | 实测值 |
|---|---|
| 毛价差最大 | 1.62 bps（ETH gate→okx） |
| 扣成本后净收益 | **-24 ~ -37 bps（全为负）** |
| 成本构成 | 手续费 20bps + 提币费 + 滑点 5bps |

**结论：主流币跨所搬砖无机会。** 这与赛道选择图上"跨链 60.6bps 成本 vs 26.49bps 价差"完全同构——主流币的价差早被专业团队、同机房机器、API 权限磨平了。

但脚本本身可复用：**长尾币、新币上架瞬间，才是价差存在的地方。** 负结果也是有效产出，这是共学第一天就定下的原则。

## 二、新地图①：币股时钟差，闭市漂移 30-100bps

同一脚本加 `--stocks` 模式，发现一个更值钱的结构：**xStocks 币股只有 gate 一家有**（okx/bitget/kucoin 都没有）——跨所没对手盘，正确方向是**币股 vs 真实美股**的时钟差。

周六美股闭市实测，6 只触发 ≥30bps 信号：

| 币股 | 溢价 |
|---|---|
| MCDX（麦当劳） | **+103.5 bps** |
| SPYX（标普） | +66.3 bps |
| GOOGLX（谷歌） | +43.5 bps |
| AVGOX（博通） | +38.0 bps |
| COINX（Coinbase） | +34.2 bps |
| TSLAX（特斯拉） | +31.5 bps |

全部溢价、方向一致。机制：**闭市漂移 → 开盘收敛**——美股闭市时币股失去锚定，价格被情绪推离；开盘瞬间有收敛压力。这是还没被磨平的结构差。

## 四、新地图③：同链跨 DEX，还有 17-20bps

Solana 侧主线：**DEX 价差监控 v0**，双数据源交叉验证：

1. Helius RPC 直读 Raydium SOL-USDC 池 vault（恒定乘积定价 + 模拟 1 SOL swap）
2. Jupiter Swap API 多金额采样（0.1/1/10/100 SOL）→ 观察 AMM 路由选择

实测（Python）：Raydium 直读 73.81 vs Jupiter HumidiFi 73.94 = **~17bps 池间价差**。

然后用 **Rust 重写同一套逻辑**（`solana-rs spread` 子命令），实测 **20.7bps**，与 Python 版互相印证——这是本项目"Python + Rust 双实现"的惯例，两种语言、同一套逻辑，谁也别想骗过谁。

**关键发现：不同金额触发不同 AMM。** 0.1/1/10 SOL 走 HumidiFi；100 SOL 走 BisonFi/HumidiFi/SolFi V2 **四池拆分路由**。大额 swap 被拆腿，报价必须按各腿 inAmount/outAmount 算，不能看总金额。

> 意义：同链跨 DEX 监控 = 第二周 Jito 原子套利的数据基础——机会在链上，不在 CEX 之间。

## 六、链上取证：解剖两个真实套利地址

D4 完成了两份取证级地址调研（横纵分析法，已沉淀为 `onchain-address-forensics` skill）：

**① Aave 清算器 0x8d64（四角色系统）**

```
① Aave V3 FlashLoan 借 LINK（premium 0.05%）
② liquidationCall 替借款人还债 → 领 USDC 抵押品
③ Bebop RFQ 精确换回还款资产
④ 归还闪电贷 → 利润 0.5366 WETH 全部付给 BuilderNet
```

> 一句话结论：**真实利润取决于事后 refund，不是链上那笔表面转账。** 用闪电贷零本金抢清算折价，把 surplus 报给私有区块构建者换取排序权。

**② Robinhood 套利器 0xd712（高频 + 便宜失败）**

- **68 万笔交易 ≠ 68 万笔盈利**，归集地址余额 ≠ 累计利润
- 三角色架构：提交 EOA（签名付 gas）→ 原子执行代理（合约余额 = 0，不留库存）→ 利润归集地址
- 最近 20 笔：**9 成功 / 11 失败**，失败占 gas 约一半——**长期期望 = 成功率 × 净利 − 失败率 × 失败成本**
- 成功单笔 $0.17~$0.64，回报率低至 0.0672% 仍执行：最低利润阈值可能很低，或上链后价差已缩

> 方法论：从**失败交易反推成本结构**（gasUsed=74643、$0.0045）比猜策略更可靠；"链下模拟器"才是这类机器人的护城河。

## 八、广度闭环：逆向选择成本，吃费率的真正对手

D4 补读三篇广度笔记（toll-fee-pool / premium-buyin-lp / funding-fee-arbitrage-1token），认知闭环：

1. **LP 过路费已被回测证伪**：高费率池吃不到流量，LVR 逆向选择吃掉手续费——机器人走你的池恰恰因为你价格滞后，你在系统性站在价格发现的错误一侧
2. **溢价买 LP 入场券**：花 50-150u 溢价换高利差收入，把价差回归风险换成已知上限的成本
3. **资金费套利**：收益 = 资金费 − 基差收敛成本 − 执行成本；**高 funding + 高 basis 分位 = 接盘信号**

> 共同方法论：**吃费率的真正对手是逆向选择成本（LVR/基差/知情流量）**——按笔算账，不能按 APR 外推。
