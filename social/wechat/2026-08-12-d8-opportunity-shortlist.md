# 共学 D8：11 个机会候选只剩 3 个，清单是怎么筛出来的

> 链上套利残酷共学 · 第 8 天
> 2026-08-12

第八天是官方路线图的关键节点 L0008：机会候选清单 v1。

前一天沉淀的 5 问筛选框架（税前口径 / 成本占比 / 返佣依赖 / 样本窗口 / 最小有效规模）第一次派上大用场。11 个候选方向过完五问，只有 3 个进了清单。更值钱的是清单之外的收获：挂掉的候选，全部挂在同一个问题上。

这天同时也是密集实验日：PM 返佣流水三分账、低容量可行域量化、80 个多链资产全扫、bStocks 事件线实况，全是在给清单供证据。

结论先说：机会清单的意义不是「找到能赚钱的方向」，而是「把还没有证据的方向明明白白挂起」。

---

## 一、L0008：11 进 3，五问定生死

候选池 = 研究线 backlog 14 个方向 × Bruce 14 类对照 × 本周全部实测（网格 / Polymarket / gas 反杀 / TUT / DOS / 888BMM）。每个候选过五问：

1. 最小有效规模可承受？
2. 净收益公式为正？
3. 样本是否只覆盖友好窗口？
4. 有无返佣/补贴支撑？
5. 有无 30 天以上真实净收益证据（含失败）？

| 候选方向 | 判定 |
|---|---|
| PM 天气「几成定局」 | ✅ 进清单 |
| 事件驱动「吃尸体」（TUT/下架/插针） | ✅ 进清单 |
| 跨所资金费率事件窗口 | ✅ 进清单 |
| RWA/币股闭市漂移 | 🟡 待验证（30 天数据） |
| 链上 perp funding 拥挤度 | 🟡 待验证 |
| 低容量结构性价差（#13） | 🟡 待验证 |
| PM rebalancing 盘口套利 | 🟡 观察 |
| PM 带方向 LP | 🟡 计划（先 paper 验证返佣） |
| OFT 跨链价差（DOS 线） | 🟡 监控（等上币窗口） |
| Cosmos 偏门跨链 | ❌ 暂缓（未核查） |
| Meme 壳价 + Dev 状态机 | ❌ 不列（博弈非套利） |

**进清单的 3 个，全部有真实证据：**

1. **PM 天气「几成定局」**：已实盘验证（日化 3% + 600 笔公开案例互证）；容量 $300/天/市场是硬约束，按多市场复制扩展；尾部风险 = 极端天气 + 多市场相关性
2. **事件驱动吃尸体**：下架合约 439bps + TUT 插针 16.16% 窗口双案例验证；低频高幅；价差 + 爆仓量两因子判窗口
3. **跨所资金费率事件窗口**：TUT 生命周期完整实证（正常期吃费率 → 异动止损 → 逼空观望 → 收敛）；与吃尸体共用监控基建

**挂掉的候选，全部挂在同一个问题**：⑤ 30 天证据。没有长期真实净收益记录（含失败记录）的方向，不进实盘清单。五问的筛选力就在这里——它不淘汰「可能性」，只淘汰「没证据」。

## 二、PM 返佣流水三分账：第④问的实证课

清单里「PM 带方向 LP」标了计划，先 paper 验证返佣流水。当天就用 leaderboard 头部账户的真实 /activity 数据跑了一版：

- **实锤案例 0x204f**：7 天返佣 $9.47K = 纯交易 $5.0K 的 **1.9 倍**——去掉返佣是亏损的
- 5 问第④问「返佣/补贴依赖度」被真实数据钉死：返佣支撑的表面收益，剥掉返佣立刻现形
- 0x6d20 案例：榜单口径 420% vs 真实到手（gross 不含费用）

这就是五问的价值：不是理论说教，是任何地址都能用 activity 事件流重建验证的硬方法。

## 三、低容量可行域量化：#13 假设成立

研究线 #13「低容量结构性价差」从 🟡 转 ✅：2.3 天 501 个样本（剔除两个损坏数据源后）：

- **「薄池价差持续更久」假设成立**：薄池对出轨率 100% vs 深池对 54%
- 持续时长：薄池 3-7 小时 vs 深池 <2 小时
- 容量边界 ≈ 100 SOL/笔（走廊含冲击项，大档出轨率下降）

数据质量发现：Aquifer（+150 万 bps）和 Manifest（+12 万 bps）的报价是损坏的——雷达需要异常值过滤。这个方向还在等竞争度维度，但可行性已经量化。

## 四、OFT 全扫：80 个资产，0 口可执行

三步法闭环（找多链币 → 询价 → 判定）跑完整个 playbook：

- LayerZero 官方 playbook：361 个已验证 OFT 资产 / 653 部署 / 704 活跃 peer 路径
- 升级到地址级扫描后，假币池彻底消失（symbol 搜索必撞假币：DAPPOS 挂着 DOS 符号，1755 亿枚）
- 冒头候选 IMD Base→ETH +438.8bps（$476K 深度）→ LI.FI 桥费核验：路由损耗 **-1065bps**，价差被吃 2.4 倍 → NO-GO
- **结论：当前时刻 80 个资产无一口可执行正价差**

过滤器如实报空 = 正确输出。工具链已经就绪，bStocks 新品/新批次公告一到就能复用。

## 六、附带勘误：L0006 的 25bps 地板不是地板

跨链实验复测发现：`integrator=jumper.exchange` 参数让 LI.FI 平台费全档归零（到账 100% vs 默认 99.75%）。**D6 的「25bps 恒定地板」修正为「默认参数的渠道费」**——跨链门槛整体下移 25bps。

但同一天 DOS 重测证伪了反向假设：LI.FI 对 BSC→ETH 全 404，DOS 走 LayerZero 原生 OFT 桥，与 LI.FI 平台费无关。新发现：**LI.FI 覆盖 ≠ 全链**，聚合器查不到 ≠ 路径不存在。

## 方法论沉淀

1. 机会清单的意义是把「没证据的方向」明明白白挂起，不是收藏「可能赚钱的方向」
2. 筛选力来自淘汰规则：五问的第五问（30 天真实净收益证据）筛掉了大多数
3. 返佣支撑的表面收益，用事件流三分账一剥就现形——任何地址可审计
4. 过滤器如实报空 = 正确输出；工具链就绪，等窗口比乱开枪强
5. 聚合器覆盖 ≠ 全链：查不到 ≠ 路径不存在，成本模型按实际桥核算
