**1/6**
链上套利残酷共学 Day 3。今天的计划是"第一笔 devnet swap"，结果变成了 mainnet 真实小额 swap——0.01 SOL 走完 Jupiter API 全流程，踩了三个坑，每个都值得单独说。

**2/6**
坑一：Jupiter 旧 API 已经下线。quote-api.jup.ag 的 v6/v7 端点直接超时无响应（DNS 正常但连不通）。现行 API 是 api.jup.ag/swap/v1/quote（Metis 路由引擎）+ /swap/v2/build（Router 路径）。而且从国内网络直连也超时，必须走代理。

**3/6**
坑二：Jupiter Swap API 只路由 MAINNET。devnet 上 program 和 USDC mint 都在，但 Metis 路由引擎根本不索引 devnet 的池子——无池可路由。想练 devnet 得自己用 Raydium SDK 建测试池，工程量不小。结论：直接 mainnet 极小金额真实交易，0.01 SOL（约 0.73 美元）风险可忽略。

**4/6**
执行记录：quote（0.01 SOL → 0.73 USDC，slippage 1%）→ build（computeBudget + 4 setup + swapInstruction + 4 张 lookup table）→ 本地 id.json 签名（私钥不出本机）→ Helius RPC 广播 confirmed。实际路由 4 池多跳：PancakeSwap → Meteora DLMM → AlphaQ → Deriverse，Gas 仅 0.0000086 SOL（≈$0.0006）。

**5/6**
坑三，也是今天最重要的一课：广播后客户端立刻返回 SUCCESS，但马上查 getTransaction 是 NOT FOUND——索引延迟约 3 秒。「客户端自报」不能当「链上可查」的证据，验证必须用二值判据：tx hash 在 Solscan/链上真实存在才算数。钱包核对：SOL 0.2011→0.1911、USDC 29.5→30.22，与 quote 完全吻合。

**6/6**
同一套链路还写了 Rust 版（quote/build/swap 三子命令 CLI），真发验证 finalized，顺手沉淀了 solana-sdk 2.x 的 API 迁移坑。Python/Node/Rust 三版全链路跑通。明天：价格监控脚本 v0，拉 DEX 报价打印价差。个人套利者的 edge 不在速度，在信息差和成本模型。
