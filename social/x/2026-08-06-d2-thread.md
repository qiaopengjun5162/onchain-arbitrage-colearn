**1/6**
链上套利残酷共学 Day 2。今天主题：分层。群里讨论时经常把两种完全不同的套利混在一起——价差套利和 MEV 套利，其实是两个物种。

**2/6**
价差套利找"目标"：不同市场/资产间的价格不一致，买低卖高。跨所、三角、期现。MEV 套利找"手段"：利用交易排序权和 mempool，抢跑/夹击/尾随。利润来源一个是市场定价失效，一个是区块排序权。实际策略常交织：价差是目标，MEV 是手段。

**3/6**
今天盘了三个工具：Gate CrossEx（跨所统一保证金，干掉单边爆仓和调仓两大痛点）、Backpack（交易所把套利路径直接喂给你——但所有人看到同样的路，那是搬砖不是 alpha）、LP 过路费（卷不过机器人，就在它必经的位置放个高费率池收过路费，不卷速度的思路）。

**4/6**
重头戏：用 LI.FI 做了真实跨链报价，Ethereum 1000 USDC → Arbitrum。到手 997.5，LI.FI 服务费 25bps 是大头，加 Gas 总显性成本 26.5bps。套利价差经常只有几十 bps——表面 20bps 的价差，光 LI.FI 费就吃完了。

**5/6**
算账公式：最低所需价差 = 服务费 + 两端 Gas + 滑点 + Price Impact + 延迟/失败/资金占用 ≈ 30-35bps。结论：稳定币跨链没机会；个人开发者先走 API 层（聚合套利、CEX-DEX），积累策略能力再考虑 MEV。一层层往上打，别跳过。

**6/6**
下一步：第一笔真实链上 swap（Jupiter API）+ AMM 流动性深度。个人套利者的 edge 不在速度，在信息差和成本模型。21 天，第 2 天把概念和成本账先算清。
