## 经济结构

- 用户净：-12.471 WBNB（≈-$10,725）+ 966.373 USDL
- LP 池：借出 37.763 / 收回 37.767 = **持平 + 0.004 WBNB 闪贷费（0.01%）**
- 金库：入 37.763 WBNB 抵押 → mint 14512.89 USDL → 全额 burn 还贷 → 退 28.78 WBNB

## 结论：不是套利，是「闪贷还贷 + 赎回抵押品」复合操作

1. **目的单一**：用户用自己的合约，借 LP 池 WBNB 凑够抵押品 → 全额还清 USDL 贷款 → 赎回 WBNB 抵押品
2. **套利三特征检查**：
   - 循环路径？❌ 无 A→B→C→A 搬砖
   - 闪贷借还对？⚠️ 有（LP 池 37.76↔37.77），但**用途是凑抵押品不是搬砖**——闪贷的存在不自动等于套利
   - 多池比价 staticcall？❌ 无 DEX 比价
3. **闪贷 ≠ 套利**：这次的关键认知——闪贷是「资金临时凑集」工具，用途决定性质；还贷/赎回用它 = 常规资金操作

## 方法沉淀

- **owner() 查执行器归属**：`0xc89e92` 的 owner = from → 用户自己的合约（个人工具合约 vs 公共聚合器的重要区分）
- **LP 池身份识别**：TradingView 收录 + 持仓结构（WBNB 54%/USDT 45%）= PancakeSwap 类池
- **闪贷费反推**：37.767/37.763 - 1 = 0.01%（PancakeSwap 标准闪贷费）
- **90 个 logs 的复杂交易**：先抓 Transfer 主干（20 个）→ 再补 owner/池识别 → 最后经济汇总，不要一开始就解全部事件
