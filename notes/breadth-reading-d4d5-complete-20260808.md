## 一、收过路费（toll-fee-pool）：已被回测证伪

原始思路：在套利机器人必经之路放高费率池收过路费（入场：爆量/缺池/剧烈波动/反复穿越）。

**证伪结论**（`toll-fee-pool-backtest-falsified-20260805.md`）：
- 高费率池吃不到流量，**LVR 逆向选择吃掉手续费**
- 对手盘是「知情流量」：机器人走你的池恰恰因为你的价格滞后——你在系统性站在价格发现的错误一侧
- 本质：你在卖「让机器人拿你套现」的期权，fee 是权利金；**策略是否赚钱 = fee vs LVR 的对比，不是 vs 零**

**更可用的指标**：费效比 = 成交量 × 费率 / 该流量造成的价格偏移
- 反复穿越的量（价格回来）= 收租 ✅
- 单边趋势的量（一去不回）= 接盘 ❌
- 「成交量大就做」要加过滤：这个量是来回的还是一去不回的

## 二、溢价买入 + 加池子（premium-buyin-lp）：idea 未验证

操作：资产参考价 750u，市场价 800-900u 溢价买入 → 加 LP 池吃高利差覆盖溢价。

**核心算术**：把「价差回归风险」换成一个已知上限的成本（溢价），换取一段时间高利差收入——花 50-150u 买「吃高利差的入场券」。

**四个真问题**（藏着的风险）：
1. 溢价能持续多久？利差要赚几天覆盖 100u？
2. 参考价 750u 本身是不是底？（跌破后还有无常损失，「最差亏溢价」假设不成立）
3. 退出流动性：暴跌时能不能出来、滑点多少
4. fee APR 是按当前量外推的，量萎缩后快速衰减

**验证方式**：记录池子/链/协议/买入价/fee APR → 画「回本天数」曲线 → 预设放弃条件

## 三、资金费套利（funding-fee-arbitrage-1token）：风险清单最完整

**机制**：资金费 = 资金费率 × 头寸名义价值；正费率 = 做空永续 + 买现货；负费率 = 做多永续 + 借币卖现货（借币利率 < 资金费收益才成立）。

**5 大风险**：
1. 逼空/强平：对冲也会因杠杆/集中度/抵押品折价爆仓
2. ADL 强行减仓：盈利侧被强减 → 突然暴露敞口 → 必须第一时间探测仓位变化
3. 抵押品折价：非稳定币抵押品被折价，不能只看账户净值
4. Maker/Taker 执行风险：maker 低成本但暴露 delta；高频换仓依赖执行质量
5. **基差即成本（最重要洞察）**：高资金费 = perp 偏离大 = 入场时在偏离价成交 → 真实收益 = 资金费 - 基差收敛成本 - 双边手续费滑点

**推论**：比较机会不能只看 funding rate，**要同时看 basis 处于历史什么分位**——高 funding + 高 basis 分位 = 在为前面的持有者接盘。

## 三篇的认知闭环

1. **LP 类策略（过路费/溢价买入）的共性**：收益 = fee 覆盖显性成本（LVR / 溢价）的对比——**按笔算账，不能按 APR 外推**
2. **资金费套利的共性**：收益 = 资金费 - 基差成本 - 执行成本——**名义费率诱人 ≠ 净收益**
3. **共同方法论**：任何「吃费率/吃 fee」策略，真正的对手是**逆向选择成本**（LVR/基差/知情流量），不是手续费
4. **对我们哨兵的指导**：funding_sentinel_v2 已实现 Z-score + OI 交叉，**下一步应加 basis 分位维度**（高 funding + 高 basis 分位 = 接盘信号，反而该避开）
