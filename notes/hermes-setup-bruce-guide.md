# Bruce 的 Hermes Agent 配置指南：Setup、硬件、模型、学习 Prompt

日期：2026-08-05（共学第一天，Bruce 发布）

来源：https://x.com/brucexu_eth/status/2084604766714261729

标题：套利共学｜从零配置一个链上套利辅助和学习的 Hermes Agent：我的 Setup、硬件、模型和学习 Prompt

## 为什么用 Agent 辅助套利

Bruce 给的三个理由，按价值排序应该是：

1. 积累判断：普通聊天问完就过去，Agent 能把看过的策略、做过的回测、当时为什么不成立都留下来。下次类似机会，不用从零再来。——这是复利的来源。
2. 自动化验证：写脚本、跑回测，快速验证。
3. 学习：不懂的直接问，顺着资料继续查。

典型案例：把 X 上看到的帖子丢给 Hermes，先提取策略，规则和时间范围够明确就找数据、写脚本、跑回测。他测了某"土狗王"喊单：抓三个月推特，喊单买 1WU、亏 10% 止损、喊卖就卖、翻倍出本，约 1 小时回测完。

注意他自己也标了：回测和实盘是两码事。这个方法的价值是"快速证伪"，不是"发现圣杯"——1 小时排除一个不靠谱的策略，本来就是巨大收益。

配套的 MVP 方法论（原文校对补充）：数据挖掘、链上合约检查、API 分析也一样。以前是先评估"值不值得专门写工具"，现在是先让 Agent 做一个最小版本，跑出来再说，真值得深挖再继续。——验证成本从"评估会议"降到"一小时回测"，想法的试错速度完全变了。

## 部署路径：先本地，后服务器

- 新手：先本地。Mac/Windows 用 Hermes Desktop，Linux/macOS/WSL2 用命令行。电脑关机 Agent 就离线，定时任务和长任务会断。
- 进阶：需要一直在线（定时抓资料、跑脚本、Telegram 随时访问）再上服务器。
- 判断标准：先本地跑通一次，确认真的会长期使用，再迁移。
- 安装教程（原文精确链接）：https://hermescn.org/docs/tutorials/guide/install-and-first-run ，中文社区 X 账号 @hermescn_org

## 硬件参考

- Bruce 自用：家里裸金属 i7-14700KF / 128G，虚拟机 8C 32G + 2x4T SSD（之前跑以太坊节点的机器），人在新西兰。
- 起步配置：2C 4G 就够用；大量计算或跑实盘策略再单独买。
- CN2 主机商：小兔互联（moebun.com），他用的是美国精品 CN2/BGP A 区放 Sub2API，28 RMB/月，推荐链接 https://moebun.com/aff/FOSAPRNV 。他自己提醒：非知名主机商，重要代码和数据放上去要慎重——Sub2API 这种无状态反代合适，策略代码和私钥不合适。
- 要跑链上节点时考虑 netcup；Hetzner 类主机很多不允许挖矿/节点类负载。

## 模型选择

- 主模型：gpt-5.6-sol medium/high（200 USD ChatGPT Sub，用 Sub2API 反代给各主机；国内用户建议买 CN2 主机放 Sub2API，他自用美国 CN2/BGP，约 28 RMB/月）。
- Sub2API 方案灵感来自 @icooperhero；Bruce 说未来会单独写一篇详细的搭建部署文章——列入跟踪源，发了就收进知识库。
- 备模型：DeepSeek（传闻训练数据含幻方量化数据，可能在量化场景有优势——未验证，标注为待测试假设）。
- 原则：永远用前沿模型，尤其拼智力的场景。预算有限可以用便宜模型，但要设好预期。

## 数据存储

做策略有大量数据读写：写 Hermes memory 不现实，Markdown/JSON 也不够用。直接让 Hermes 装 Docker、起 PostgreSQL 容器存。

## 消息平台

- 主力：Telegram。关键技巧是建私人群 + 开 Topics：每个 Topic 独立对话线程，按策略/任务分区，定时任务结果也能投递到指定 Topic。
- Bruce 的 Topic 分类实例（可直接抄）："套利学习"、"策略研究"、"数据与回测"、"开发"、"打卡"。
- 群组配置三个检查项：允许访问的 Chat ID 白名单、Privacy Mode 和 Bot 权限、是否需要 @Bot 才触发。
- 国内替代：飞书。
- 微信：只有单窗口、无法并发、群消息接入不可靠，不适合做主入口。
- 新手可以先私聊跑通连接，长期使用一定要上群组 + Topic。

## 工具分工

手里已有 Codex / Claude Code / Workbuddy 的，学习阶段完全可以先用，不必为了学套利先研究一遍所有 Agent 工具。

Bruce 选 Hermes 的五个理由（原文）：长期在线、Telegram 随时接任务、能找到以前的会话、保存少量长期信息、把重复流程沉淀成 Skills、跑定时任务。

Bruce 的分工：Hermes 负责理解上下文、拆任务、调工具、长期在线；大型开发任务交给 Coding Agent。

## 学习方法：先让 Agent 了解你

开新方向时的第一个 Prompt（可直接复用）：

> 问我 10 个问题，判断我目前对链上、DeFi、编程和套利的了解，我接下来想做什么，以及每天愿意投入多少时间。一次问一个问题。问完以后再制定学习计划。

要点：

- 一次一个问题，问完再出计划。
- 10 个问题不是固定题库，重点是让 Agent 先知道六件事（原文完整清单）：
  1. 我已经会什么，不需要重复学什么
  2. 我真正感兴趣的方向是什么
  3. 我的编程和链上操作能力到哪里
  4. 我希望偏研究、开发、数据分析，还是以后做真实策略
  5. 我每天能投入多少时间
  6. 哪些事情不能自动执行
- 计划先给最近一两周方向，不要一次拆太细；今天能做的放进 Todo。
- 每天：取出下一条，学习或执行，不懂继续查，做完记录结果。计划不对就改，动态调整。
- 成长路径（原文）：随着共学推进缺什么补什么——一步步注册账号、给 Hermes 授权、安装大佬们做的 Skills 来增强。能力是按需求一点点长出来的，不是第一天配齐的。

这和群里"找 AI 根据自己情况脑暴大纲"的总结是同一个方法，这里给出了具体操作法。

## 共学平台 Agent 接入

残酷共学平台已支持 Agent Access Keys：

1. 官网右上角 Access Keys -> 创建 Key
2. 发给 Hermes 的精确 Prompt（原文）：

   > 这是访问 https://intensivecolearn.ing/ 的 key，你记录一下，帮我测试一下连通性，读取 https://intensivecolearn.ing/programs/b43d2e97-ed88-4ca3-b12f-7ef672b01205 课程内容测试。

3. 之后每天学完，直接让 Agent 整理"今天做了什么、证据在哪、什么没完成"并完成打卡
4. 学习计划、执行、记录、打卡连成一条线，不用手动复制

另一个高价值点：通过 Hermes 可以检索几百位同学的打卡笔记，找灵感、认识人——"大佬笔记是精华"这句话有了可执行的读取方式。
