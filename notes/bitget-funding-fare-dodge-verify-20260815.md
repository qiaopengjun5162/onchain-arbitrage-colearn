## 一句话

**Bitget 资金费逃票不成立**：主流币费率被钳制在 ±0.01%（p99=0.0100%），往返手续费 0.12% 是费率的 12 倍，**100 期里 0 期扣费后为正**；唯一的高费率币全是 4h 结算的负费率事件（空头付费），与逃票方向相反。结论与 taoli 一致，且新增「结算频率分叉」证据。

## 官方规则（已核验）

1. **结算频率分叉**（2025-09-22 公式更新后）：
   - 主流币（BTC/ETH/SOL）：**8h 结算**，实测 UTC 0/8/16 = **北京时间 08:00/16:00/00:00**
   - 长尾币（COW/ACE/WAL/ALICE/HOME/CAP/ESPORTS 等）：**4h 结算**（UTC 0/4/8/12/16/20）
   - 个别币（PROM）：1h 结算
   - ⚠️ 官方文档写 07:00/15:00/23:00 (UTC+8)，**实测差 1 小时**（08/16/00:00）——以 API fundingTime 为准
2. **持仓判定**：只在结算时点持有仓位才收付资金费
3. **费率公式**：F = Clamp(P + Clamp(I − P, ±0.05%), 下限, 上限)；利率固定 0.01%（8h）/0.00125%（1h）；2025-09-22 更新为除以 (8/N) 适配多频率
4. **支付方向**：正费率多头付空头；负费率空头付多头
5. **资金费用 = 费率 × 仓位价值**（与杠杆无关）
6. **特殊条款**：从固定保证金扣除，至多扣至保证金率=维持保证金率——书面推演：BTC 10x/100x 下保证金率均远高于维持率，**无逃票空间**（只有濒临强平才触发，不是策略）

## 结论

1. **逃票机制不成立**（与 taoli #6 互证，且新增实证）：费率钳制 ±0.01% + 手续费 0.12% → 结构性倒挂，任何「结算前建仓→结算后平仓」的逃票都是白逃
2. **结算频率分叉是本次新增发现**：主流 8h / 长尾 4h / 个别 1h——对 funding 哨兵有意义：**扫长尾币要看 4h 结算的时点**，主流币看 8h 时点
3. **高费率 = 事件驱动**（COW −1.93% 单次）：印证「常态空间负、肉在事件窗口」校准结论——但这类事件是负费率（空头亏），与期现多空对冲的常规姿势相反，且无对冲腿时是方向性投机（出局标准）
4. **文档时点偏差**：官方文档 07/15/23 (UTC+8) vs 实测 08/16/00——文档过时，以 API 为准
