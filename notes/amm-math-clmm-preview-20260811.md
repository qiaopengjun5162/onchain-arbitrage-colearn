## 一、tick 与价格：P(t) = 1.0001^tick

- V3/Whirlpool 把价格空间切成 tick，相邻 tick 价格差 0.01%（1 basis point）。`tick=100 → P=1.0100`，`tick=23027 → P=10.0`。
- SOL $74 对应 tick=43043；**±10% 区间 = 2007 ticks**（±5% = 1001 ticks，±20% = 4055——近似线性：宽度 ∝ 区间百分比）。
- 意义：LP 选区间 = 选一段 tick 范围，链上位置用 tick 表示（int24），不用小数价格——gas 友好 + 可精确比较。

## 二、虚拟储备 vs 实际储备：资金效率是 CLMM 的灵魂

- V2：L = √k = √(x·y)，流动性均匀摊在 0~∞，价格只活动在小区间时 99% 资金闲置。
- V3 区间内（当前价 p ∈ [pa, pb]）：
  - `x = L·(1/√p − 1/√pb)`，`y = L·(√p − √pa)`（注意：**X 由当前价和上沿决定，Y 由当前价和下沿决定**——刚写反过一次，负储备是明显信号）
  - 价格在区间内任意点，池子「看起来」像虚拟储备更大的 V2 池——这就是集中流动性的数学本质。
- **实测（Raydium SOL-USDC 储备 67,851 SOL / 5,033,521 USDC，L=584,406）**：
  - 同 L 放 ±10% 区间只需 **3,162 SOL + 257,982 USDC** = 资金效率 **X 21.5x / Y 19.5x**（≈1/区间宽度占比，±10% 双侧 → ~20x）
  - 反向验证自洽：用 V2 的 1/10 资金放 ±10% 区间 → L = V2 的 **195%**（1/10 资金 × 20x 效率）
- 直觉：**区间越窄，同样资金提供的深度越深，但出区间的概率越高**——这是 LP 的核心 trade-off（收益 vs 无常损失），和网格「格子越密赚越多但穿界风险越大」完全同构。

## 三、区间内 swap（L 恒定）

- 卖 X 买 Y（价格上行）：`Δy = L·(√p_new − √p_cur)`
- 卖 Y 买 X（价格下行）：`Δx = L·(1/√p_new − 1/√p_cur)`
- 实测：L=584,406 时 SOL 涨 1% → 池内 USDC 增加 $25,074；涨 5% → +$124,148；涨 9.9% → +$242,977（接近上沿时 Y 趋近总储备）。
- **价格到上沿 = X 耗尽**：再涨只剩 Y=257,982 USDC 单边资产——区间外不再有双向流动性，手续费停止。

## 四、出区间 = 单边资产（网格穿界风险的 AMM 版）

- 价格 < 下沿：仓位 100% 是 X（SOL）；价格 > 上沿：100% 是 Y（USDC）。不赚手续费，等价格回区。
- **与网格回测结论同构**（`notes/grid-trend-backtest-20260811.md`）：网格趋势月=库存单向堆积亏损；CLMM 趋势出区间=单边资产锁定方向性风险。两个模型是同一个数学结构（区间做市）的两端。
- 实盘含义：CLMM LP 的无常损失在「出区间」瞬间被锁定成方向性风险——选区间宽度 ≈ 选方向性敞口，不是纯手续费游戏。

## 五、对套利研究的意义（为什么 D9 要学这个）

1. **Orca Whirlpool / Raydium CLMM 是 Solana 主 DEX 的流动性形态**——薄区间池 = 走廊窄（两腿费率低）→ 出轨频率高 → 机会频率高（接无套利带雷达的逻辑）
2. **区间边界是流动性断层**：价格穿过 tick 边界时深度突变 = 大单冲击的滑点跳变点——backrun 模拟器升级要能识别「池子的流动性区间边界在哪」
3. **虚拟储备公式 = 链上定价工具**：读 Whirlpool 的 sqrtPrice + liquidity 就能算任意价格的边际价（后续 Rust 双实现的候选）
