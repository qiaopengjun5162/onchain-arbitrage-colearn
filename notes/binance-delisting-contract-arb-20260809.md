## 策略描述（原话）

> 分享个策略吧 bn下架合约价差能有几十个点 盯着oi猛干就好了

拆解成可验证的假设：

1. **事件**：币安（BN）公告下架某个永续/交割合约
2. **价差**：下架期间合约价 vs 现货价差能到**几十个百分点**（几十 bps 还是几十 %？待确认口径）
3. **信号**：盯着 **OI（未平仓合约）**——OI 大 = 被迫平仓压力大 = 价差冲击大
4. **操作**：利用下架导致的强制平仓/移仓造成价格错位，做价差收敛

## 机制猜想（为什么会有几十个点的价差）

下架流程（币安典型流程，需验证）：
```
公告下架（提前 N 天）
  ↓
合约进入 reduce-only（只减仓，不能开新仓）
  ↓
到期/下架日：未平仓头寸强制平仓
  ↓
流动性枯竭 + 平仓单砸盘 → 合约价偏离现货
```

价差来源候选：
- **强制平仓冲击**：OI 大但盘口薄 → 平仓单把合约价砸出极端偏离
- **现货侧流动性也差**：下架币通常是流动性差的小币，现货深度不足，无法瞬时吸收
- **做市商撤退**：下架公告后做市商不愿承担库存风险，双边价差拉大
- **恐慌/情绪**：持仓者恐慌性抛售

## 为什么「盯 OI 猛干」可能是对的

- OI = 将要被强制平仓的量，是**确定性的未来卖压**（不像普通策略要猜）
- OI 越大 → 平仓冲击越大 → 价差越极端 → 套利空间越大
- 这是个**事件驱动 + 确定性供需失衡**的策略：信息（下架公告）公开、方向（平仓卖压）确定

## 风险与敞口（必须对照风控总纲）

1. **方向不确定**：多头被强平是卖压，但空头也要买回平仓——净方向取决于多空比例，不是必然单边
2. **现货侧风险**：做空合约 + 做多现货对冲，但下架币现货可能**同时下架/提币受限** → 对冲腿卡死（黑天鹅清单里的「所有腿同时卡死」场景）
3. **时间风险**：reduce-only 窗口多长？强制平仓是瞬间还是摊开？价差收敛时间不确定
4. **流动性陷阱**：价差几十个点 ≠ 能吃几十个点——盘口薄，进场本身就是冲击
5. **交易所规则风险**：币安可能提前/推迟下架、改规则（对手方风险）
6. **小币种归零风险**：下架合约的币往往基本面差，现货可能归零——「做多现货」腿可能归零
