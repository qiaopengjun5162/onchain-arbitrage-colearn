## 一句话

研究团队扒了 Polymarket **2.59 亿笔历史交易**，估算出 **111.8 万 USDC 的机制套利利润**——其中 **108.6 万（97%）来自 NegRisk Adapter**，一种「低价收 NO → 组合转换 → 换现金 + 卖 YES」的循环玩法（作者称「NO 回收套利」）。

## NegRisk Adapter 原理（三个结果的例子）

- 事件只有 A、B、C 三个互斥结果（只有一个获胜）
- **数学恒等式**：NO A + NO B ≡ 1 美元现金 + YES C
  - A 赢 → NO B 值 1 美元；B 赢 → NO A 值 1 美元；C 赢 → 两张 NO 各值 1 美元（共 2 美元）
  - 右边等价：A/B 赢拿 1 美元；C 赢拿 1 美元现金 + 值 1 美元的 YES C
- **Polymarket 把「等结算才能确认」的数学关系写进 Adapter**：不用等开奖，把符合条件的 NO 交进去 → 立即换回现金 + 其他结果的 YES

**利润来源**：NO A 以 0.58 收、NO B 以 0.62 收（成本 1.20）→ Adapter 给 1 美元现金 + YES C 还能卖 0.25 → **单轮毛利 0.05 美元**。
- 利润小，但**现金立即回来 → 一天多轮 → 资金利用率高**（资金周转率 × 单次收益率 = 总收益）

## 真实玩法（论文数据揭示）

- 完整 NO 篮子只贡献 18.9% 利润；**大头来自部分 NO 转换 + 转换后剩余 YES 的继续处理**
- **约 80% 的转换有 maker 成交参与**；利润最高 10 个地址拿走 75% 利润
- 不是「看到价差冲进去吃腿」——是**提前挂 NO 买单，陆续成交，记录真实成本，找最赚钱的子集，Adapter 转换，处理剩余 YES，循环**

```
低价挂 NO 买单 → 陆续成交 → 记录每张 NO 真实成本
→ 寻找最赚钱的子集 → Adapter 转换 → 现金回账户
→ 处理剩余 YES → 继续挂下一轮
```

**本质**：小型做市生意——NO 是原料、Adapter 是加工厂、剩余 YES 是副产品。利润由收货价、库存搭配、资金周转次数决定。

## 风险（作者明确列出）

1. **库存风险（最难的部分）**：想收 NO A + NO B，只成交了 NO A → 变成真方向仓位（会输钱）
2. maker 挂单不保证成交；部分成交产生方向风险
3. 剩余 YES 有显示价格 ≠ 你的数量能全部卖掉（深度问题）
4. Augmented NegRisk 有页面不显示的 placeholder；「Other」定义可能变化
5. 手续费/深度/资金占用/执行速度——几分钱利润容易被吃干净
6. **论文的 108.6 万是历史估算**，部分剩余 YES 按当时市价计价，≠ 已提现
7. **利润被压平**：单次转换利润中位数 2024 年中 ~1 USDC → 2026 年初 ~0.08 USDC（进场人多）

## 与个人套利者的关系

- **机会结构**：把预测市场从「谁猜得准」变成「谁更会处理库存」——**机制套利，不猜方向**
- **门槛曾被拉高**：需要 Gamma API + CLOB WebSocket、订单簿维护、成本记录、最优子集搜索（几十上百个结果）
- **AI 降低门槛**：作者给出第一版「只读 NO 库存优化器」开发需求——读 NegRisk 事件、记录 NO 成本、遍历可转换组合、按真实深度估值剩余 YES、输出净利润为正的组合
- **渐进路线（作者建议）**：只读运行一周 → 模拟 maker 成交 → 模拟有净利润才小资金真实挂单 → 跑通后再考虑自动撤单/自动调 Adapter。**别一上来就把私钥交给 AI**

## 与共学主线的关系

- 呼应「套利本质是找摩擦」：NegRisk Adapter 是**协议规则产生的结构性套利**（不是价格博弈）
- 呼应「个人 edge 在信息差/新资产/新规则」：预测市场机制套利属于「新规则」类
- 与已有 Polymarket skill（`polymarket`）相关：该 skill 查市场/价格/订单簿，本笔记是机制套利策略层
