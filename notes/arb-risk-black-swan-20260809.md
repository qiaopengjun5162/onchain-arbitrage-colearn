# 风控总纲：套利是概率游戏，敞口控制是生死线（2026-08-09）

> 来源：Paxon 群讨论（2026-08-09）：「套利也有风险，概率问题，套利大佬套到最后套爆仓了」「黑天鹅无处不在，控制好风险敞口，和做合约一样」
> 串联：`notes/execution-checklist-5-steps.md`（五步法）、`notes/node-infra-acceptance-checklist-20260808.md`（基建验收）、`notes/day5-real-slippage-verify-20260809.md`（真实滑点）
> 定位：**每次写策略前先过这篇的总纲**——先想敞口，再想机会

## 核心命题

**套利不是无风险，只是风险长得不一样。** 合约的风险写在明面上（杠杆、爆仓价），套利的风险藏在暗处（库存、尾部、对手方）。本质相同：`爆仓 = 尾部概率 × 杠杆 × 敞口`。

## 套利爆仓的四个真实机制

### 1. 库存暴露窗口 = 隐形杠杆
- 跨所/跨链套利买入→卖出之间有时间差，窗口内持有敞口
- 价格反向波动吃掉价差 = 「帮他管库存」的另一面：**接的库存可能砸在手里**
- 流动性越差、路径越长，窗口越大 → 五步法「两侧能否安全回收」不是套话

### 2. 黑天鹅时套利腿被卡死
- 2020-03-12 / LUNA / FTX 暴雷：价差瞬间拉大（看似机会），但执行腿全卡——提币暂停、gas 飙升、RPC 拥堵、熔断
- **你以为在套利，实际在接飞刀**：极端行情下「无风险套利」的每个环节同时失效

### 3. 杠杆是隐藏放大器
- Alameda / 3AC = 「低风险套利 + 高杠杆」标准死法——价差没算错，保证金曲线先爆
- 套利杠杆藏在库存里：借币、跨所持仓、funding 套利的不对冲 delta

### 4. 对手方风险
- 交易所本身会死（FTX）、会限制提币、会改规则
- 你假设「两边都会履约」——这个假设本身就是风险敞口

## 与合约的本质差异（只差一点）

| | 合约 | 套利 |
|---|---|---|
| 杠杆 | 明牌 | 藏在库存里 |
| 风险可见性 | 爆仓价写在界面上 | 尾部 + 敞口看不见 |
| 胜率 | 低 | 高（单笔小赢） |
| 死亡方式 | 杠杆逐仓爆 | 1000 次小赢被一次黑天鹅清零 |

**套利大佬爆仓不是价差算错，是敞口失控**——高胜率让人放松，小亏让人加仓，然后黑天鹅清零。

## LP 是被动做市：「不难」的另一面（Paxon 2026-08-09 补充）

「LP 是被动做市，不难，要么有团队合作要么个人能力强」——机制上确实被动：钱放池子，套利者搬价格，你赚 fee 亏 LVR。但「不难」的另一面：

1. **被动 = 无法选对手**：你是所有知情流量的对手方（逆向选择 / toxic flow）。套利机器人走你的池，恰恰因为你的池价格滞后——你在系统性站在价格发现的错误一侧（LVR）
2. **门槛低 = 竞争激烈**：谁都能放池子，fee 被压薄；「不难」意味着没有护城河，靠团队（专业做市商：Wintermute/Jump 的 tick 分布、波动率模型、费用档选择）或个人能力（理解 LVR vs fee 的按笔算账）才有 edge
3. **结论**：被动 LP 的「不难」是入场不难，**活下来难**——收益 = fee vs LVR 的对比，不是 vs 零（`notes/case-toll-fee-pool.md`、`notes/breadth-reading-d4d5-complete-20260808.md`）

## 敞口控制清单（落地）

- [ ] **单笔上限**：单笔最大亏损 = 总资金 X%（事前定，执行中不改）
- [ ] **库存窗口**：持仓时间 > N 秒/分钟的套利必须算反向波动成本（不只是价差）
- [ ] **尾部预案**：黑天鹅清单——哪些条件下所有腿会同时卡死（提币暂停/gas 飙升/RPC 拥堵），预案是什么
- [ ] **杠杆审计**：这笔套利实际敞口多少？（借币 + 跨所持仓 + 未对冲 delta），按合约仓位标准评估
- [ ] **对手方上限**：单交易所敞口 ≤ 总资金 Y%（防 FTX 式归零）
- [ ] **kill switch**：连续失败上限 / 单日亏损上限（五步法第五步，事先写好）
