## 定位

这篇文章适合作为资金费率套利的基础方法论和风险清单。

它的价值不在于告诉我们“资金费套利能赚钱”，而是把收益、风险、交易风格和风控指标讲得比较完整。

## 核心机制

资金费率是永续合约用来让合约价格贴近现货/指数价格的机制，通常由多空双方定期支付，不是交易所手续费。

常见做法：

- 正资金费：做空永续，买入等量现货。
- 负资金费：做多永续，同时借币卖出现货；前提是借币利率低于资金费收益。

资金费 = 资金费率 x 头寸名义价值。

## 和之前经验的对应

之前的体感：

- 牛市资金费率机会更多。
- 同所正费率机会稀缺。
- 负费率套利经常借不到币。
- 跨所要承担流动性、高波动、滑点、价差不收敛和两头挨打。
- 交易所内部和大团队有天然优势。

文章里的补充：

- 同所资金费套利通常更流行，因为组合保证金能提高资金效率并降低保证金风险。
- 跨所策略管理成本更高，风险更高，容量更低。
- 跨所很多时候更像在套价格差，而不是单纯资金费率差。

## 主要风险

### 1. 逼空和强平

即使现货和永续完全对冲，如果杠杆过高、仓位过于集中，永续和现货的价差在极端行情下仍可能拉开，导致保证金不足。

关键不是只看总杠杆，而要看：

- 单账户维持保证金率
- 超额保证金
- 单币种集中度
- 抵押品折价
- 永续和现货基差

### 2. ADL 强行减仓

ADL 会让盈利的一侧仓位被交易所强行减掉，从而突然暴露现货或永续敞口。

策略必须能第一时间探测仓位变化，并决定：

- 快速市价平敞口，承受滑点
- 被动限价平敞口，承受更长时间风险
- 人工介入

### 3. 抵押品折价

非稳定币作为抵押品时会被交易所折价。流动性越差、市值越小，折价可能越严重。

所以资金费套利不能只看账户净值，也要看交易所风控系统认可的抵押品价值。

### 4. Maker / Taker 执行风险

两条腿交易时：

- maker 成本低，但会暴露 delta 敞口。
- taker 成本高，并承担滑点。
- 高频换仓策略更依赖执行质量。

### 5. 基差即成本：高资金费和同价对冲不可兼得

共学群里的机制洞察（2026-08-05）：

> 资金费的来源就是标记价和实际价的差异。高额资金费也就意味着很难做到同价位对冲。

拆开看：

- 资金费率高，恰恰说明 perp 相对现货/指数的偏离大。
- 入场建对冲时，perp 那条腿就是在偏离价位成交的——你做空的 perp 比现货贵（正费率场景）。
- 资金费机制的设计目标就是把这个偏离收敛回去。
- 所以真实收益 ≈ 收到的资金费 - 基差收敛（回归）的成本 - 双边手续费滑点。
- 名义资金费率越诱人，入场时支付的基差越大，偏离收敛时的账面亏损也越大。

推论：比较机会时不能只看 funding rate，要同时看 basis（spot/perp 价差）处于历史什么分位。高 funding + 高 basis 分位，往往是在为前面的持有者接盘。

## 策略风格维度

### 场所

- 同所
- 跨所

### 币种

- BTC / ETH 等大币：资金费偏稳定，容量大，波动相对可控。
- 小币：资金费可能更高，但操纵、抵押品折价、流动性和集中度风险更高。

### 标的

- 现货 + USDT 永续
- 现货 + USDC 永续
- U 本位永续 + 币本位永续

### 调仓

- 主动调仓：追更高资金费，换手高，执行要求高。
- 被动调仓：更偏统计和持仓管理，换手低。

### 成交

- maker + taker
- taker + taker
- maker + maker

## 对共学的启发

资金费套利可以作为“套利不是无风险”的典型案例。

共学里不应该只问：

> 当前资金费率是多少？

更应该问：

> 在流动性、高波动、抵押品折价、ADL、滑点、借币利率、保证金率和执行达成率都算进去之后，这个策略还活着吗？

以及：

> 当前 basis 处于历史什么分位？我收到的资金费，够不够付入场时吃进的基差？

## 补充：群友的入门建议（2026-08-05）

> 资金费套利非常简单可操作（赚钱另说），都是可实践的。如果真的从 0 开始，我建议让 AI 来制定计划。统一账户的现货合约资费套利、LP 的组建都可以先尝试下。

两个值得摘出来的点：

1. **统一账户（组合保证金）模式是新手练手的正确入口**：现货和合约在同一个账户里，抵押品共享，对冲腿的保证金占用最低——正好对应上文 1Token 文章说的"同所资金费套利通常更流行，因为组合保证金能提高资金效率"。练手路径：同所统一账户 -> 小额现货多 + 合约空 -> 记录资金费结算 -> 算净收益。
2. **"简单可操作，赚钱另说"是诚实的分层**：资金费套利的价值对新手来说是「跑通对冲、结算、成本核算的完整闭环」，盈利依赖费率为正且持续，那是行情给的。先拿它练风控和记账，不指望它出 edge。

## 简单实现步骤（Paxon，2026-08-06）

1. **扫描**：扫 Binance 合约资金费率，找到高额正资费且有现货的币种
2. **对冲开仓**：合约做空 + 现货买入（手动交易或 API 自动化）
3. **吃费率**：持有到结算时间，收取资金费收益。价格波动由对冲平衡
4. **退出**：资金费率逐步靠近 0 时平仓退出套利
