# Binance Alpha「搬砖套利」机制拆解（2026-08-11）

> 触发：群里说「币安 Alpha 上线 DOS，Alpha 和链上有价差可以搬砖」。Paxon 问：这个怎么搬砖？
> 结论先行：**Alpha 不是独立市场，它是币安做的链上聚合交易入口——「Alpha 价 vs 链上价」基本是显示假象，不是可套利价差。真正赚钱的是上币公告前后的信息差/埋伏博弈，那也不是价差套利。**

## 一、Binance Alpha 到底是什么（机制）

- Alpha 1.0：币安 Web3 钱包里的链上交易入口，聚合链上 DEX 流动性，用户一健购买早期代币（「正式上币前的观察池」）
- Alpha 2.0（2025-03 上线）：直接集成进币安交易平台，CEX 用户用现货/资金账户就能交易链上代币，无需钱包
- **关键：Alpha 的订单通过链上市场（DEX/AMM）执行，不是币安订单簿撮合**——币安官方 FAQ 原文：「订单通过链上市场执行，价格波动较币安交易平台更为剧烈」
- 代币展示约 24 小时，之后留在市场选项卡；配合 Alpha Points 空投体系引流

## 二、为什么「Alpha 和链上有价差」是假象

1. **Alpha 就是链上聚合器**：它显示的价格 = 聚合器扫描 DEX 后的报价（类似 Jupiter/1inch）。聚合报价 vs 单个池子价格的差异 = 路由差（哪个池子最优），不是「两个市场」的价差。
2. **显示价 ≠ 可成交价**：Alpha 有内置滑点调整 + MEV 防护 + 最低到账校验，价格快速变化时下单直接失败或自动调滑点——界面上看到的「价差」，下单时大概率已经被吃掉或成交不了。
3. **资金闭环存疑**：Alpha 资产从币安提现有明确限制（官方条款：Alpha Assets cannot be withdrawn）。「链上低价买 → Alpha 高价卖」的两腿，有一条腿可能根本动不了；「Alpha 买 → 提到链上卖」也可能不通。两腿资金不通 = 套利闭环不成立。
4. **谁在赚**：真赚钱的是——①上币公告前就在链上埋伏的人（信息差，公告后 pump 卖给冲进来的 Alpha 用户）；②做市商/聚合器背后的流动性提供方；③刷 Alpha Points 的空投农民。都不是「搬砖」。

## 三、如果真的想碰，风险优先清单

1. **不能提现/资金锁死**：先验证 Alpha 2.0 买的币能不能提到链上钱包，不能提 = 单腿市场，随时被规则关在门里
2. **假价差**：拿 Alpha 显示价去对链上单池价，差异大概率是聚合路由/手续费加成，不是可执行套利空间——验证方法：看 Alpha 成交价 vs 链上实际成交价（滑点后），而不是显示价
3. **上币即砸盘**：Alpha 上币瞬间 pump 后常伴随获利盘砸盘，埋伏的人卖给追高的人；小白追进去就是接盘位
4. **小币深度**：Alpha 早期代币流动性浅，滑点大，插针常见；大额进出直接打穿深度
5. **DOS 具体数据**：本次未拉取（不在可访问交易所列表），机制分析通用；如果要做，先查 DOS 在哪个链、哪些池子、真实深度多少

## 四、正确姿势（如果真想研究）

- 把它当**信息差哨兵案例**而不是套利案例：Alpha 公告 → 链上价格脉冲 → 谁在买/谁在卖 → 公告后 N 小时的量价结构（对应 `notes/information-gap-arb-essence-20260810.md` 的信息差套利三步法）
- 或者当**上币公告哨兵**的输入：`scripts/listing_monitor.py` 已有大所上币公告监控，Alpha 公告可加一个源
- 真要做「价差验证」：对比 Alpha 可成交价（模拟下单）vs 链上最优路由价，用我们的净收益公式（价差 − 滑点 − 手续费 − 提现限制成本）判断——大概率 NO-GO

## 五、结论一句话

「Alpha 和链上有价差搬砖」≈ 「交易所自己的聚合器和自己吃同一锅饭」——价差是显示层的影子，不是两个市场的肉。真机会在公告前的埋伏（信息差），那需要的是消息和胆量，不是搬砖脚本。
