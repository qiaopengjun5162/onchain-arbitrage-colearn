# 案例：溢价买入 + 加池子吃利差

来源：共学群讨论中的具体操作思路（2026-08-04 前后）。

## 操作描述

某资产参考价约 750u，市场价存在溢价，在 800-900u 区间买入，然后加入 LP 池子吃利差（fee/收益）。利差利润很高，足以覆盖买入时支付的溢价。

最差情况：加进去没多久价格暴跌回归 750u，亏损限于买入溢价部分，约 100u 上下。

## 算术拆解

假设参考价 750u：

- 买入价 800u -> 溢价 50u
- 买入价 900u -> 溢价 150u
- 盈亏平衡点：LP 收益 >= 支付的溢价
- 下行保护逻辑：亏损被"溢价"显性限定，而不是裸露的无限下行

这个思路的本质：把"价差回归风险"换成一个已知上限的成本（溢价），去换取一段时间的高利差收入。相当于花 50-150u 买一张"吃高利差的入场券"。

## 为什么这个机会可能存在

溢价和高利差同时存在，通常说明：

- 池子新、流动性薄，fee APR 被短期交易量推高
- 有事件驱动（新资产、新链、通道受限、FOMO），买需求集中
- 大多数人还没进场或不敢付溢价，LP 提供者少

## 这个案例里藏着的真问题

1. 溢价为什么存在、能持续多久？利差要赚多少天才能覆盖 100u 溢价？
2. 参考价 750u 是怎么确定的？如果 750u 本身不是底，"最差亏溢价"的假设就不成立——价格跌破 750u 后还有无常损失。
3. 退出流动性：暴跌时池子能不能出来？出来的时候滑点多少？
4. fee 收入是按当前交易量外推的，交易量萎缩后 APR 会快速衰减。

## 验证方式

- 记录：池子地址、链、协议、买入价、参考价依据、当日 fee APR、交易量
- 每天记录 fee 累计收入 vs 已支付溢价，画出"回本天数"曲线
- 预设放弃条件：fee APR 衰减到回本周期 > N 天，或价格跌破参考价的证据出现
