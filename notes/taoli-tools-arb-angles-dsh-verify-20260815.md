## 三、dsh（DeepSeek Harness）实操验证 + 脚本修复

### 为何做
共学群读到《一切皆插件：DeepSeek Harness 开源了》长文，宣称「Everything is a Plugin」+ 会话日志即架构 + 多 Agent 编排。按「别光吹牛逼实操模拟起来」理念，本机实操验证（本机已装 dsh CLI + 凭证库）。

### 怎么做/结果
1. **验证链路**：`dsh --profile headless "任务"` 跑通——凭证→模型全链路 OK；让它分析共学知识库仓库，真实读了文件给出 3 条建议（依赖未锁定/哨兵重复造轮子/证据数据易丢失），质量可用。
2. **「会话日志即架构」实测属实**：一次任务 185 个事件，`session.jsonl.zstd` 落盘；`bash ls`→`glob`→`read` 每步工具调用参数可回放；沙箱模式（workspace-write）、权限策略全记录。
3. **「一切皆插件」实测属实**：`--dump-config` 显示定时器/会话/模型/标题生成/agent 循环全是独立插件包；profile = `cordis.yml`（清单）+ `cordis.patch.yml`（用户覆盖层）组装。
4. **多 Agent 编排**：headless 派 3 个后台 subagent 并行分析脚本——**踩坑**：主代理 turn/end 即退出，后台子代理只读到文件就被杀，汇总丢失。对策：prompt 明确「用阻塞式 subagent，必须等所有子代理返回再汇总」→ 第二次 2 个阻塞式子代理并行分析 2 脚本成功，且真的挑出脚本 bug。
5. **顺手修 2 个脚本**（dsh 挑的 bug 属实）：
   - `scripts/hl_funding_monitor.py`：+3 次指数退避重试、universe/assetCtxs 长度校验、flock 锁 + 临时文件原子替换（原直接 append 会半截/重复）。实测抓数成功、告警正常。
   - `scripts/amm_v2_verify.py`：+参数边界校验（dx≤0/fee≥1/耗尽储备/负储备全拦截）、+恒定乘积自检断言（k 相对误差 0 通过）。输出格式未变。

### 意义
1. 文章宣称全部实测属实（除 headless 后台 subagent 的坑——已记入 deepseek-harness skill）。
2. dsh 可作为批量化「AI 代码审查/并行调研」工具复用：`dsh --profile headless "..."` 一行式。
3. 与 qintopia-agent-os 框架设计对照：「整机 vs 面包板」架构之争，dsh 是「核心可换」路线的现成参考。
4. Taoli Tools 帖子印证：工具（操作层）同质化，角度（策略层）靠人——与「AI 加速器不是方向盘」互证。
