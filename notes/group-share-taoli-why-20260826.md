2. **现货↔永续基差（期现套利）**：现货买入 + 永续做空同量；永续>现货时价差收敛赚基差，期间可能收资金费；资金费按实际结算计，可能反转；净利 = 基差变化盈亏 + 实际资金费 − 手续费和持仓成本
3. **两永续资金费差**：两边价接近但资金费不同 → 费更有利侧建仓 + 反向对冲；例：A 收 0.03% / B 付 0.01%，扣成本前资金费差 ~0.02%；净 = A 腿实际收付 + B 腿实际收付；⚠️ 页面预测费率≠锁定收益，需按各所规则（正负定义/结算周期/实际结算）核对
4. **跨所现货库存套利**：低价所买 + 高价所卖，需提前双所放资金/币；净利 = 高价卖 − 低价买 − 双边手续费 − 库存调回成本；⚠️ 最容易漏最后一步（库存恢复），充提/跨链/调仓成本算进去才是净利；rebalance 等待有风险

**统一公式**：净利润 = 两条腿价格盈亏 + 实际资金费收入 − 手续费、借币、充提、调仓等实际成本；交易前用真实买卖报价估，交易后用实际成交均价复盘；价格冲击已含在价格里不重复扣滑点；两边未同时成交要算单边仓位风险

**工具部分**：Taoli.Tools 本地网页运行、同页双品种反向下单、免费限 5ku、不收集密钥和交易数据；配置 API 建议只开读取+交易权限、不开提现、开 IP 白名单
