> 先说结论：你现在最需要学的不是"马上找到一个套利机会"，而是学会判断一笔交易到底有没有真实、可执行、扣除成本后仍然存在的利润。
>
> 注：基础解释用于零基础入门；群聊中关于协议盈利、报价失真和收益的说法，仍需用官方文档、区块浏览器和链上数据逐项核查。

## 一、先看懂整张地图

把链上套利想成一条流水线，依次回答五个问题：

1. 在哪里发现价格差？CEX、DEX，还是不同链之间？
2. 两边的资产是不是同一种资产？同名代币不一定是同一个合约。
3. 扣掉交易费、Gas、跨链费、滑点和失败风险后，还剩多少？
4. 买入和卖出两条腿能不能在合适的时间内都完成？
5. 如果价格突然变化或只成交一边，程序和人准备怎么处理？

## 二、第一层基础：你在"链上"到底在做什么

### 1. 区块链、网络和资产

- 区块链：一套公开记录系统。不同网络有不同规则、账户体系和手续费，资产不能默认跨网络通用。
- 原生币与代币：原生币支付 Gas；代币由合约发行。跨链后看到的同名资产，可能只是包装版或映射版。
- 钱包与地址：地址像收款账号，钱包管理密钥并签名。助记词、私钥和授权权限是资产安全的第一道防线。
- 智能合约：部署在链上的程序。DEX、跨链桥、借贷和质押协议都通过合约执行规则。

### 2. 一笔链上交易的基本流程

查看报价 -> 选择路线 -> 钱包签名 -> 广播交易 -> 等待确认 -> 检查最终到账

跨链还多一步：源链资产先被锁定、销毁或转移，目标链再释放、铸造或映射。跨链不是"点击一下马上到账"，等待时间本身就是套利风险。

## 三、第二层基础：CEX、DEX 和报价工具

### 1. CEX 与 DEX 的区别

- CEX：订单簿、账户系统、API，平台托管资产，程序可通过 API 获取行情、下单。
- DEX：钱包直接与合约交互，常见流动性池、Gas、滑点和确认问题。
- 聚合器和路由：比较不同市场或路径的报价。LI.FI、OKX DEX、Jupiter、Uniswap、1inch、PancakeSwap 先当作报价/路由研究的例子，不要理解成同一种工具。

### 2. 四个容易混淆的词

- 报价：根据当时市场状态给出的预计价格，是计算的输入，不等于最终成交。
- 滑点：实际成交价相对预计价格的偏离。金额大、池子浅、市场快时迅速放大。
- 路线：A 换 B 可能经过多个池子、协议甚至多条链；路线越复杂，手续费和失败点越多。
- 模拟：广播前估算交易能否成功、得到多少资产。有帮助，但不能消除链上状态变化的风险。

重要提醒：所谓"虚报价格/偶尔抽风"，先理解成"报价可能过时或不代表最终成交"。不要只看页面数字，要看实际执行和链上结果。

## 四、第三层基础：套利到底是什么

套利不是某个按钮，也不是看到两个价格不同就能赚钱。它是利用价格差、并在扣除所有成本后争取留下净利润的交易逻辑。

```
净利润 = 卖出金额 - 买入金额 - 交易费 - Gas - 跨链费 - 滑点损失 - 失败或对冲损失
```

示意：毛价差 1.00，成本合计 0.75，理论净利 0.25；价格再波动一点或一边失败，就变亏损。

### 1. 四类套利来源

- CEX-DEX 套利：中心化交易所和链上场所之间的价差。
- DEX-DEX 套利：同链不同 DEX 或不同池之间的价差。
- 跨链套利：同一经济资产（或其包装版）在不同链、桥、市场间的价差。
- 协议或桥的盈利：协议通过手续费、报价差、沉淀资金赚钱。这是协议商业模式，不等于用户可复制的套利策略。

### 2. 为什么看见价差也未必能赚

- 报价可能已经过时，成交时价格变了。
- 池子流动性不够，大单会把价格推走。
- Gas、交易费和跨链费吃掉小额利润。
- 跨链确认需要时间，价差可能在到账前消失。
- 同名资产可能不是同一合约，包装资产还有赎回和桥风险。
- 竞争者、MEV 和私有流动性池可能让你慢半拍。
- 一边成交、一边失败时，单腿暴露可能远大于预期利润。

## 六、跨链桥：先理解机制，再理解收益

### 1. 桥在做什么

源链资产被锁定或销毁，目标链发行、释放或映射对应表示。不同桥安全模型不同，"桥"不是完全相同的产品。

### 2. 群聊里的"三层收益"

- 看得见的：用户支付的手续费和 Gas。
- 不容易看见的：跨链资金在合约或池子里停留，形成 TVL/沉淀资金。
- 报价相关的：报价与真实链上价格的差异，体现为滑点、汇率差或服务费。

安全理解法："沉淀资金可以产生收益"是群聊中的商业模式推演，不是所有桥的通用事实。判断某个桥怎么赚钱，查官方文档、合约资金流和链上数据，别把"高年化"当收益承诺。

### 3. "无损跨链"不等于"没有风险"

- 无损：按规则跨链后，名义资产数量不因桥的收费机制直接减少。
- 不代表：没有手续费、没有价格变化、没有等待时间、没有合约风险，也不代表包装资产和原生资产完全等价。

### 4. 群聊出现的桥和协议（研究线索，非推荐）

Gravity Bridge、Wormhole、LayerZero（L0）、CCIP、Relay、Aave（借贷/资金利用例子）、axlUSDC、axlATOM 等包装资产。

## 七、Cosmos 生态与跨链价差

### 1. 说人话

Cosmos = 多条互联链组成的生态，不同链有不同用途、资产和交易场所。Osmosis、Juno、Terra、Celestia、SCRT 都是研究线索。

校正：ATOM 是 Cosmos Hub 的原生代币，不是所有 Cosmos 链上唯一通用的货币。

### 2. 资产名称要特别小心

- axlUSDC / axlATOM：跨链桥映射/包装版。同名不等于同一合约，必须核对发行方、合约地址、赎回路径和流动性。
- stkATOM / pStake：质押生息凭证或衍生资产。价格、赎回时间和风险不等于 ATOM 现货。
- SCRT：隐私链、较冷门套利场景。冷门 = 竞争少，也可能 = 流动性和信息更差。

### 3. Cosmos 套利最简逻辑

同一经济资产多链价格不一致 -> 形成价差 -> 计算成本 -> 判断是否值得执行

1. 确认主链资产、包装资产和 DEX 中的资产是否可互换。
2. 确认跨链/赎回要多久，价格能否在等待期保持。
3. 手续费、Gas、桥费、滑点、失败概率放进同一张表。
4. 最后才讨论可执行的双边交易。

风险提示："解压 14 天、撸 30 个点"是待核查案例，不是收益预期。先弄清锁定期、收益来源、资产价格风险和退出条件。

## 八、MEV、alpha 与竞争

- alpha：相对其他人的优势（更快的数据、更好的流动性、更低成本、独特信息）。alpha 不保证盈利。
- MEV：利用交易排序、打包和执行顺序提取价值，会改变普通交易的成交环境。
- 三明治攻击：目标交易前后插单，先买、让目标推高价格、再卖。初学者先学识别和防范，别当入门策略。
- 私有池、常规池、"慢半拍"指向同一事实：机会不仅由价格决定，也由数据速度、排序、流动性和竞争程度决定。

## 九、从监控到自动交易：程序要解决什么

### 1. 先区分"看机会"和"下交易"

- 监控：持续读取价格、路线、流动性和费用，发现价差。新手先做只读监控。
- 执行：真正签名广播，要额外处理超时、失败、重复发送、授权、Gas 和双腿协调。

### 2. 合格套利程序的六个模块

1. 数据模块：读取 CEX、DEX、聚合器和链上状态。
2. 机会模块：计算不同市场、链之间的价差。
3. 成本模块：交易费、Gas、桥费、滑点和预计失败成本。
4. 执行模块：构造路线、生成交易、发送并追踪状态。
5. 风控模块：金额、滑点、Gas、等待时间和停止条件。
6. 记录模块：保存报价、实际成交、失败原因和最终盈亏。

### 3. API、calldata 和 QPS

- API 返回的报价仍可能过时。
- 自己构建 calldata = 承担更多细节，也获得更多控制权。
- 高 QPS 增加成本和复杂度；关键是机会持续时间和数据质量。

## 十、最重要的风控：单腿风险

单腿 = 本来要同时完成买入和卖出，只成功了一边。手里留下的不是锁定的利润，而是暴露在价格波动中的头寸。

### 1. 常见失败原因

- 一边成功，另一边因余额、Gas、滑点、合约或网络问题失败。
- 报价有效期短，发送后市场已变。
- 跨链未到账，另一边价差已消失。
- 单边爆拉或暴跌，收敛逻辑失效。

### 2. 风控判断框架

- 交易前：设最小净利润、最大金额、最大滑点、最大 Gas、最大等待时间。
- 交易中：确认每一步状态，不因"看起来应该成功"就继续。
- 一边失败：先停止扩大风险，再选止损、撤回、对冲或补全另一边。
- 交易后：记录真实成交价格和失败原因，不只看模拟结果。

压缩成一句话：让程序在执行前就知道什么情况不能做，在一边失败后知道什么时候停、什么时候退出，而不是把判断留给情绪。

## 十一、零基础学习路线

按顺序学，每步有"学会标准"。不要一开始跳到自动化跨链套利。

- 阶段 1 建立基础词汇：解释网络、钱包、地址、私钥、合约、Gas、代币；画出"签名->广播->确认->到账"流程；分清原生币、代币、包装资产。
- 阶段 2 理解交易场所：分清 CEX、DEX、池子、聚合器、路由；看懂报价里的买入数量、预计到账、费用、最小到账；理解报价、滑点、成交不是一回事。
- 阶段 3 纸面练计算：做表输入买卖价、费用、Gas、桥费、滑点；净利 < 0 就标"不做"；给价格变化、延迟、单腿失败设压力测试。
- 阶段 4 学跨链与 Cosmos：查清一条链、一个桥、一个包装资产的完整路径；核对合约地址、发行方、流动性、赎回方式、等待时间；分清"用户无损"和"协议盈利"。
- 阶段 5 只监控再模拟：只读监控，不自动签名；保存每次机会的报价、成本和结果；能解释大多数失败原因后，再考虑极小资金测试。

## 十二、值得带着问题去查的内容

- LI.FI、OKX DEX、Jupiter、Uniswap、1inch、PancakeSwap 的功能边界和报价来源分别是什么？
- "虚报报价"到底是缓存延迟、流动性不足、模拟失败，还是界面展示问题？
- 某个桥是否真把沉淀资金投入 Aave/质押/挖矿？资金流在链上如何验证？
- axlUSDC、axlATOM、stkATOM 的发行方、合约地址、赎回方式和流动性在哪查？
- Cosmos 某条链是否还有真实用户：看活跃地址、交易量、流动性和费用，而不是听说。
- "解压 14 天、撸 30 个点"具体指什么资产、锁定期、收益来源和退出风险？

## 十三、最后背下这十句话

1. 看到价差，先算净利润；看到收益，先问风险来源。
2. 报价只是预计值，成交才是结果。
3. 手续费、Gas、滑点和等待时间，都会吃掉套利空间。
4. 同名资产不一定是同一种资产，先核对合约地址。
5. 跨链桥是风险放大器，时间和安全模型都要学。
6. 无损跨链不等于无手续费、无波动、无合约风险。
7. Cosmos 是多链生态，ATOM 不等于所有链的通用货币。
8. 套利通常有两条腿，一边失败就会变成单腿风险。
9. 程序化交易的核心不是发命令，而是监控、计算、执行和风控。
10. 小白先学逻辑、做纸面计算和只读监控，不要急着用真金白银追逐高收益。

学习目标：当你能用自己的话解释"资产在哪里、价格为什么不同、成本有哪些、两条腿如何完成、失败后如何退出"，就已经入门，可以进入深入研究阶段。
