# 期现套利成本模型：实测「可套利空间」（2026-08-09）

> 脚本：`scripts/basis_arb_model.py`（只读，ccxt 4 所）
> 方法论：Paxon 实战教训「跨所资费还是要做下过滤的」「1倍杠杆统一账户也能爆」
> 公式：`可套利空间 = 价差 - 资金费率成本 - 两腿手续费 - 滑点 - 提币费`

## 实测（2026-08-09 08:40 UTC，BTC/ETH/SOL × okx/bitget/kucoin/gate）

**12 组合全部不达标**（空间 -26.9 ~ -31.8bps，阈值 30bps）：

| 币种 | 所 | 价差bps | funding | 费用 | 滑点 | **空间bps** |
|---|---|---|---|---|---|---|
| SOL | kucoin | -0.9 | +1.0 | 20 | 5 | **-26.9** |
| BTC | kucoin | -3.6 | +0.6 | 20 | 5 | **-29.2** |
| ETH | gate | -5.1 | -0.3 | 20 | 5 | **-29.7** |
| ... | | | | | | 全部负 |

## 核心结论

1. **主流币期现套利空间恒负**：价差仅 -1~-6bps（永续还折价现货），两腿手续费 20bps 直接吞掉——**过滤前看似无风险，过滤后全是负的**
2. **这量化了「跨所资费要过滤」**：裸入场看价差（-1~-6bps）以为小亏，算上费用是 -27~-32bps 稳定亏损
3. **为什么 1 倍杠杆也会爆**：空间为负时，每次循环都是稳定失血 + 尾部价差背离风险——不是「赚得少」，是「确定性亏 + 尾部爆」的组合
4. **机会不在主流币**：要找「价差显著 > 费用」的场景——事件驱动（下架/清算/新币）才有，今天验证的下架套利 HFT 4.4% 就是反例

## 与 Paxon 观点咬合

- 「搬砖复利很快，前提是你得找到 alpha」：主流币没 alpha（空间恒负），alpha 在事件驱动
- 「cex套利分分钟等着被交易所收割」：费用结构就是收割机制——每轮 20bps+ 无条件扣
- 「检测到差价开进去 = 爆仓起点」：模型证明「看到价差就进」在主流币是稳定负期望

## 模型参数（可调）

- taker 两腿 10+10bps（VIP0）；滑点 5bps 固定近似；提币费 0（同所对冲场景）
- funding：正 funding 时做空永续付成本；负 funding 时反而收钱（模型已含方向符号）
- 年化：按 3 轮/天复利（8h 结算周期）
