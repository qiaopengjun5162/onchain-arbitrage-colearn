## 一句话

**研究拆解 = 把「这玩意儿是不是机会」这种模糊问题，切成 T0-T5 六个有明确证据产出的子任务，每个子任务跑出数字/事实，最后过决策闸门。** Hermes 负责执行取证，人负责定义问题和复核结论（判断力=方向盘）。

## 五步框架（观察 → 假设 → 证据 → 实验 → 决策）

| 步 | 做什么 | 产出形态 | 反例（不算产出） |
|---|---|---|---|
| 1 观察 | 一句话记录看到了什么 | 「这个 tx 看着像套利」+ 链接 | 只收藏不拆 |
| 2 假设 | 可证伪的猜想 | 「闪贷注入金库→借出→还贷，赚 oracle/DEX 价差」 | 「牛逼」「学习了」 |
| 3 证据 | 链上取证，只信数据 | token 流 + 合约身份 + 金额 + 手续费 | 看 Etherscan 页面标题 |
| 4 实验/模拟 | 把证据放进成本模型跑数字 | 净利 = 借出 − 买入 − 各费 − gas | 毛价差当净利 |
| 5 决策 | 过决策闸门五问（053） | 是/否可做 + 一次性 or 常驻 + 风险清单 | 「感觉可以」 |

## 六任务模板（T0-T5，可直接复用）

```
T0 问题定义：一句话问题 + 判定标准（是/否套利？模式？谁在做？）
T1 元信息：blockscout /transactions/{hash} → from/to/status/gas/时间/内部创建
T2 主干：/token-transfers 按时间画 token 流 → 找循环结构（借→买→卖→还）
T3 身份：logs 认合约（Swap 签名辨池型）；Morpho 用 idToMarketParams(bytes32) 读 loan/collateral/oracle/lltv
       （注意：新版 market(bytes32) 返回 6×uint128 头寸数据，不是市场参数）
T4 成本结构：闪贷费（还款/借款−1）· 池 fee · 借息（借出利率）· gas → 盈亏平衡线
T5 可复现性：一次性错价 or 常驻机制？猎物特征？被搬平即失效？
输出：交易画像 + 结论 + 风险 + 下一步（进证据流水线 or 归档）
```

## 实战实录：Morpho 闪贷灌金库 sNUSD 套利（08-14，从链接到结论 1 小时）

完整笔记 `notes/morpho-flashloan-vault-snusd-arb-case-20260813.md`，拆解过程对照：

| 任务 | 做了什么 | 关键动作 |
|---|---|---|
| T0 | 群友丢 tx 链接：「这个思路不错」 | 问题 = 是不是套利 + 怎么运作 |
| T1 | blockscout 三件套拉取 | 发现是合约创建型 tx + 全是 Morpho 系事件 |
| T2 | token-transfers 画主干 | 27.7M 闪贷 → 灌金库 → sNUSD 买入 → 借出 → 还贷 闭环 |
| T3 | logs 认身份 + eth_call 读市场 | **踩坑**：USDC 6 位/sNUSD 18 位小数混算错一个数量级 → 统一小数位后账才对 |
| T4 | 成本结构 | 闪贷 0 费 / 借息 105% APR / gas $0.87 → 净利 ≈ $297 |
| T5 | 可复现性 | oracle $1.0638 vs DEX $0.686 = 一次性低流动性错价；猎物特征=新生息代币+vault 模式 oracle+近空池 |

**拆解带来的一句话 edge 判断**：不是策略神，是池子标错价没人管——验证了「研究覆盖度=竞争拥挤度」，错价池被搬平即失效。

## Hermes 分工模式（L0010 上手落地）

- **人**：丢问题、定判定标准、复核结论、决定下一步（方向盘）
- **Hermes**：执行取证、跑数字、归档笔记、更新 README/daily/Obsidian（加速器）
- **沉淀**：取证动作固化成 skill（`evm-arbitrage-tx-forensics`），下次同类问题直接加载复用，不重新发明
