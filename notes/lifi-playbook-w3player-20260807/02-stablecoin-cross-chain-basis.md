# 模型二：稳定币跨链价差套利

## 一句话结论

利用同一稳定币在不同链之间的价差、原生与桥接版本之间的价差，或不同稳定币的短期偏离。价格波动通常小于 WETH 库存，但风险并未消失，而是转为发行方信用、脱锚、冻结、桥包装与赎回风险。

## 1. 模型与 LI.FI 的作用

策略在多链预置 USDC、USDT、DAI、USDC.e 等库存，捕获：

- 同一稳定币在不同链的价格差；
- 原生与桥接版本的折溢价；
- 不同稳定币的短期偏离；
- 桥接流动性不足和赎回不方便形成的价格差。

LI.FI 提供同链和跨链可执行报价，可指定使用哪些桥和交易所，并返回费用、网络手续费、最低到账量、中间资产和跨链状态。但 LI.FI 帮助识别代币并不等于替你完成风险调查；同名资产仍须按链 ID + 合约地址区分。

## 2. 推荐前提

| 维度 | 必须具备 |
|---|---|
| 资产 | 明确发行方、抵押、赎回主体与资格；区分原生、官方跨链和第三方包装；记录冻结、暂停、升级与治理权限；建立地址白名单和风险等级 |
| 市场 | 至少两处独立退出流动性；多金额档位仍覆盖全成本；实时监控脱锚、池深、桥状态与发行方公告 |
| 资金 | 分别限制每种稳定币、发行方、桥接版本和链最多可占策略总资产价值的比例；保留另一种风险来源不同的应急结算资产 |
| 系统 | 状态为 `PARTIAL`（只完成一部分）时，识别实际收到的中间代币；按真实可卖价而非固定 1 美元估值；明确什么价格停止买入、什么价格只允许卖出、什么价格必须紧急退出 |

## 3. 三种子模型

| 类型 | 示例 | 风险重点 |
|---|---|---|
| 同资产链间价差 | 链 A 买原生 USDC，链 B 卖原生 USDC | 发行方风险较一致，主要是交易深度、买卖只成功一笔与补库存 |
| 原生/桥接版本价差 | `USDC ↔ USDC.e`、`USDT ↔ 桥包装 USDT` | 价差可能是在补偿桥的信用风险，不保证以后回到原价 |
| 不同稳定币价差 | `USDC ↔ USDT/DAI/USDe` | 需分别分析中心化储备、超额抵押、合成或收益型资产风险 |

## 4. 执行流程

1. 按精确合约地址采集各链稳定币的双向可执行报价。
2. 计算真实可成交价、`toAmountMin` 和多金额深度。
3. 检查发行方、桥、赎回与当前脱锚原因。
4. 扣除网络手续费、交易费、补库存、赎回成本和脱锚损失准备金。
5. 在两条链上尽量同时成交相同数量的代币。
6. 按实际到账链、地址和数量更新库存。
7. 等待反向机会；库存达到预设上下限时再补库存。

## 5. 盈亏

```text
netPnl
= sellStableProceeds - buyStableCost
- gasAndTradingFees
- expectedRebalanceCost
- expectedRedemptionCost
- depegRiskReserve
- mismatchLoss
```

直白地说：净利 = 卖出稳定币收到的钱 − 买入成本 − 交易与补库存费用 − 赎回费用 − 脱锚准备金 − 两笔交易数量不匹配造成的损失。

无法直接向发行方换回底层资产的桥接版本，必须按 DEX 等市场上真实能卖出的保守价格估值，并进一步扣除大额卖出可能造成的损失。

## 6. 损失与控制

| 风险 | 如何亏损 | 关键控制 |
|---|---|---|
| 脱锚扩大 | 0.99 买入后跌至 0.90，损失远大于预期 1% 价差 | 分三级处理：停止买入、只允许卖出、紧急退出；压力测试极端价格 |
| 永久信用事件 | 储备、托管银行、抵押品、治理或赎回暂停使锚定永久破坏 | 汇总同一发行方的全部风险金额；不能因为“以后可能涨回去”就买入 |
| 桥版本信用 | 包装资产不可直接向发行方赎回，依赖桥储备、迁移合约和特定链 | 原生/包装分开估值与限额；准备无桥退出路径 |
| 冻结/黑名单 | 余额存在但无法转移、卖出、赎回或桥接 | 审查权限；限制每个中心化发行方的投入；异常时停止新增 |
| 流动性枯竭 | 脱锚时提供资金的人撤资、桥停用、DEX 可交易金额骤降 | 使用危机时期的交易深度而非平时平均滑点；保留第二退出场所 |
| 买卖只成功一笔 | 买入问题资产后卖出失败，或卖出成功但买入失败，之后价格反弹导致补回变贵 | 限制未匹配金额；自动补做失败的交易；必要时自动停机 |
| 赎回不方便 | 身份认证（KYC）、最低金额、银行工作日、地区限制、费用或暂停，会让理论上的 1 美元赎回价拿不到 | 只有真实拥有赎回资格时，才按赎回后能拿到的钱估值 |
| 跨链中间资产 | `PARTIAL` 后收到 USDC.e、axlUSDC 等，信用和可用性改变 | 核对真实地址并隔离，禁止自动并入可用库存；参见 [Intermediate Tokens](https://docs.li.fi/guides/intermediate-tokens) |
| 固定成本 | 正常价差很小，代币授权、两边交易、桥接与恢复成本可能吞噬利润 | 按较差 5% 的完整成本和不同交易金额的可盈利范围决定是否交易 |
| 合约/链 | 稳定币、DEX、桥、LI.FI、目标链和治理形成复合攻击面 | 链、协议、桥与发行方限额；单点失效仍有退出路径 |

## 7. 回测

采集各链每小时或每个区块的价格与资金池深度、不同交易金额的滑点、历史脱锚幅度/恢复时间、原生与桥接版本的兑换路径、真实赎回时间/费用、LI.FI 报价/网络手续费/使用工具/状态，以及危机期间“没有可用路径”和流动性消失的样本。

至少压力测试：`0.995`、`0.98`、`0.90`、`0.50` 和完全不可交易。这些是损失情景，不表示价格必然恢复。

## 8. 是否适合开始

### 可以开始（Go）

- [ ] 每个代币的发行方信用和桥接版本已分类。
- [ ] 策略真实拥有假设中的赎回通道。
- [ ] 严重脱锚损失不超过风险预算。
- [ ] 单桥/单池失效后仍有退出路径。
- [ ] 净收益覆盖较差 5% 情况下的成本和脱锚损失准备金。
- [ ] 中间代币可按真实地址识别和隔离。

### 不应开始（No-Go）

- 只凭代币简称（symbol）判断资产相同；
- 把稳定币当成无信用风险现金；
- 假设所有折价以后都会自动回到正常价格；
- 依赖自己无权使用的发行方赎回；
- 没有脱锚停机机制和资产白名单。
