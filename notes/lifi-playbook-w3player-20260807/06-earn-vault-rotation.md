# 模型六：Earn 收益轮动

## 一句话结论

把资金从低收益金库迁到高收益金库，目标是在持有期间多赚一部分年化收益。计算时要先给高风险机会打折。它不是立刻完成的无风险套利，而是长期资金配置；应优先研究同链、同资产、可以随时取出的成熟金库。

## 1. 模型与 LI.FI 的作用

```text
链 A / Vault A / USDC
  -> 提取 -> 必要时兑换与跨链 -> 存入
链 B / Vault B / USDC
```

LI.FI Earn 用于发现收益机会，读取当前预计年化收益率（APY）、锁仓总价值（TVL）、资产、链和协议，并查询用户已经存入的资金。Composer 可以把兑换、跨链、调用合约、存入和受支持的提取步骤组织在一起。

边界：

- 页面展示的年化收益率不是未来锁定收益，数据与实际可交易状态之间存在更新时间差；
- Composer 可以组织多个步骤，但不能保证跨链前后的所有步骤全部成功或全部失败；
- 可展示不代表同时支持自动存入和提取；
- 底层协议、金库策略、资产和链的风险不会被聚合接口消除。

## 2. 三种实施方式

| 方式 | 示例与收益来源 | 主要风险 | 推荐 |
|---|---|---|---|
| 同链同资产轮动 | 同链将 USDC 从金库 A 迁到金库 B | 年化收益率下降、协议故障与无法及时取出；成本较易估算 | 首选 |
| 跨链同资产轮动 | 链 A 的 USDC 金库迁到链 B 的 USDC 金库 | 桥延迟、资产版本差异、目标链故障、只完成一部分及未来返回成本 | 收益率差和持有期足够大时采用 |
| 金库凭证折价 / 奖励机会 | 奖励代币、积分、金库凭证折价或短期补贴 | 能否领取、需要等待多久、能否卖出、价格和估值都高度不确定 | 仅作额外收益 |

## 3. 推荐前提

| 维度 | 必须具备 |
|---|---|
| 可比性 | 本金相同或经济上确实等价；区分原生、桥接、封装和不同发行方；统一基础年化收益、奖励、收益是否继续产生收益（复利）和费用的计算方式；只比较风险相近的机会 |
| 可持续性 | 收益率差不是排行榜的瞬时变化；知道收益究竟来自哪里；能监控年化收益率、锁仓总额、资金使用率、奖励价格和容量 |
| 退出 | 核实 `isRedeemable`（是否可赎回）或同等能力；了解锁定时间、提取等待期、排队、额度、暂停和真实退出深度；预估回到基准资产的完整成本 |
| 资金 | 预计持有时间明显长于收回迁移成本所需时间；限制每个金库、协议、链和资产的投入；保留可立即使用的资金；交易金额不能小到被网络手续费吞噬，也不能大到超过金库容量 |
| 风险 | 审查协议、管理者、自动投资合约、价格数据来源、借款人和管理员权限；对新协议和管理员权限过大的合约，大幅降低收益估计并减少投入 |
| 执行 | 交易前重新验证报价、存入/提取能力和链上状态；目标链预留支付网络手续费的原生代币，并准备失败恢复路径 |

## 4. 执行流程

1. 定义基准资产，例如原生 USDC，并建立允许的等价资产白名单。
2. 计算当前已投入资金现在能取回多少钱、扣费后的年化收益率和完整退出成本。
3. 从 Earn 获取候选，按资产、链、协议、锁仓总额、存取能力和风险过滤。
4. 将页面年化收益率拆成基础利息、奖励、手续费和补贴。
5. 估算提取、兑换、跨链、存入，以及未来退出的全路径成本。
6. 计算保守收益率差、需要持有多少天才能收回迁移成本，以及极端情况下会亏多少。
7. 给高风险机会降低收益估计后，只有收益改善超过最低标准才执行。
8. 存入后核对实际拿到的金库凭证、真实投入成本和是否可赎回。
9. 持续监控收益、锁仓总额、资金使用率、奖励、协议状态与退出能力。

跨链版本应把“提取并到达目标链”和“目标链存入”作为两个状态阶段。前者完成、后者失败时，资金会停在目标链钱包或中间资产中。

## 5. 收益与盈亏平衡

设：

- `V`：迁移本金；
- `C_move`：进入新仓的全部成本；
- `C_exit`：未来退出的增量成本；
- `Δr`：新旧金库扣费后的保守年化收益率差。

```text
breakEvenDays = (C_move + C_exit) / (V × Δr) × 365

netPnl
= baseInterest
+ realizedRewardValue
+ vaultSharePriceChange
- withdraw/swap/bridge/deposit/futureExitCosts
- depegAndSlippageLoss
- protocolOrStrategyLoss
- capitalOpportunityCost
```

直白地说：先算迁入和未来迁出的总成本，再看新金库每天能比旧金库多赚多少，由此得到需要持有多少天才能回本。最终净利还要加上利息和已实现奖励，再减去全部迁移、脱锚、协议损失和资金占用成本。

`Δr <= 0` 表示新金库扣费后的收益没有更高，不应迁移；预计持有时间如果只比回本时间长一点，也没有足够安全空间。

保守估值：基础年化收益率使用历史上较低的水平，或主动打折；奖励根据能否领取、需要等多久和卖出时会压低多少价格进行折价；未上市积分不算核心收益；退出成本按较差情况估算；尚未拿到手的奖励不按页面价格全额计算。

## 6. 损失与控制

| 风险 | 如何亏损 | 关键控制 |
|---|---|---|
| 收益率下降 | 高收益吸引大量资金后下降，迁移完成时优势已经消失 | 要求收益至少提高到某个幅度；按保守收益估算；留出更长持有期；两次迁移之间设置等待时间 |
| 奖励贬值 | 奖励价格下跌、交易深度不足、需要等待才能领取，或者最终无法领取 | 基础利息和奖励分开计算；奖励价值打折；积分只算额外收益 |
| 本金/金库凭证贬值 | 自动投资策略亏损、坏账、强制平仓、价格数据错误、再次质押的资产被扣罚或记账错误 | 把本金变化计入最大亏损；限制每个协议、金库和策略的投入 |
| 合约/管理员 | 漏洞、合约升级、协议暂停、密钥泄露或治理攻击 | 检查管理员权限和安全审计；高权限或新协议只投入小额；分散到不同协议 |
| 无法提取 | 只能存入不能取出、交易深度不足、必须等待、需要排队或协议暂停 | 入场前确认可以取出；限制被锁定的资金；保留随时可用的资产 |
| 跨链只完成一部分 | 从旧金库取出后桥接退款，或桥成功但存入新金库失败；原来正在赚收益的资金已经取出了 | 分阶段处理每个状态、核对实际到账、准备目标链手续费和恢复路径 |
| 稳定币/包装资产脱锚 | 很高的年化收益率可能只是对更高信用风险的补偿 | 按地址分类资产；设置脱锚退出线，以及发行方和桥接版本的投入上限 |
| 锁仓总额造成错觉 | 锁仓总额高不等于随时能取出大额资金；太低又会让你的资金占比过高并拉低收益 | 同时检查可投入上限、资金使用率、真实退出深度和存入后的收益率 |
| 底层借贷/价格数据 | 抵押物突然下跌、强制平仓失败、坏账，或价格数据延迟/被操纵 | 了解资金借给谁、用什么抵押；压力测试坏账和错误价格 |
| 数据过期 | 大额资金流入、奖励调整或协议暂停后，页面仍显示旧收益和旧能力 | 执行前重新检查并持续记录；收益或锁仓额异常变化时自动暂停 |
| 频繁迁移 | 重复网络手续费、滑点、存取费与税务成本吞噬收益 | 两次迁移之间设置等待期；计算来回成本；规定最短持有时间 |
| 链/基础设施 | 网络拥堵、暂停、重组、节点接口或手续费余额不足，导致无法退出 | 设置每条链的投入上限；准备备用节点、手续费余额和退出预案 |
| 幸存者偏差 | 只回测仍存活金库，遗漏攻击、关闭、减值和锁仓样本 | 保留退市/失败样本和事件时间线 |
| 费用/税务 | 管理费、业绩分成、提前退出费、领取费和链上费用可能没有算进页面年化收益；税务也会降低净收益 | 使用包含全部费用的计算方式；按适用地区单独评估会计与税务 |

整个策略还应避免把资金过度集中在同一协议、金库、链、稳定币或管理者。锁仓总额骤降、资金使用率过高、奖励价格暴跌或协议暂停时，应停止新增或尽快退出。

## 7. 回测

不能用今天的 Earn 排名推断历史表现。需定期保存：

- 总年化收益、基础收益、奖励收益、锁仓总额、容量、资金使用率和存取能力；
- 底层资产与金库凭证价格，以及奖励价格、交易深度、能否领取、需要等待多久；
- 进入、退出、兑换和跨链报价；
- 协议暂停、攻击、减值、队列和退市事件；
- 实际份额、成本基础和可赎回价值。

回放必须模拟数据和执行延迟、资金进入后收益率下降、最短持有时间、两次迁移之间的等待期、来回迁移成本、奖励折价与卖出冲击、提取排队、跨链异常，以及已经关闭或消失的金库。

报告：

- 扣费后的年化收益；
- 按每笔现金进出时间计算的真实年化收益率（IRR）；
- 最大资金回撤和本金损失；
- 基础利息、奖励和资产价格各贡献多少收益；
- 迁移频率和迁移成本占扣费前收益的比例；
- 资金最长不可用时间；
- 收益率下降后，累计收益需要多久才能恢复；
- 各类风险金额，并与“完全不迁移”比较。

## 8. 是否适合开始

### 可以开始（Go）

- [ ] 本金资产相同，收益计算方式也可以直接比较。
- [ ] 给高风险机会降低收益估计后，新旧收益率差仍明显为正。
- [ ] 预计持有时间远长于保守估算的回本时间。
- [ ] 存入、提取和退出流动性均已确认。
- [ ] 进入、未来退出和跨链全成本已计入。
- [ ] 协议、金库、链和资产均在限额内。
- [ ] 奖励大幅贬值后，基础收益逻辑仍可接受。

### 不应开始（No-Go）

- 利润主要依赖不可估值积分或短期奖励；
- 不知道收益从哪里来，只看到页面年化收益率；
- 不可赎回、队列不透明或退出深度不足；
- 迁移后短期需要用钱；
- 收益率差不足以覆盖迁入和未来迁出的全部成本；
- 更高收益来自不可接受的信用或协议风险；
- 回测只保留当前存活金库。
