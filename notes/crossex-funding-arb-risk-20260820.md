## 结论先行

**资金费套利 = 卖保险：收确定的保费（资费），扛不确定的赔付（暴涨）。** 所有风控参数（蚂蚁仓、保证金厚度、1 倍涨幅强平线）都是在控制「赔付上限」。刚暴拉的币做 SF（现货+空合约）是风险最高的进场时点；**冲高回落→横盘后**吃资费才是「只收租、不赌方向」的稳窗口。跨所保证金平台（CrossEx）≠ 免死金牌，TUT 剧本下 2 倍杠杆照样爆。

- **社区信号**：币安广场 + X 上大量 KOL 推 BTW → 狗庄收割节奏的前兆（类比 TUT 剧本，见下）

### 为什么刚拉完做 SF 有风险
1. **基差虚高**：拉盘时合约涨得比现货凶，买现货+空合约先吃基差浮亏；基差收敛那一刻 SF 头寸反而亏基差
2. **高资费是过热信号不是安全信号**：多头拥挤到愿付 124% 年化，情绪极端，随时二次拉升或插针
3. **深度薄**：24h 成交额千万级，进出滑点大，SF 利润被滑点吃光

### 为什么横盘吃资费最稳
- 横盘 = 波动率下降 → 基差窄幅震荡 → **方向性风险≈0**
- 但多头仓位没走 → 资费维持高位 → **收租不变**
- 一句话：**资费高 ≠ 机会好，波动降下来资费还高才是机会好**

## CrossEx 实战框架（用户经验）

CrossEx = Gate 推出的跨所交易/清结算平台，单账户连 Gate + Binance + OKX，跨所保证金共享、盈亏互抵（2025-10 上线，机构/量化向）。

### 核心参数
| 参数 | 设定 | 理由 |
|---|---|---|
| 资金占比 | **蚂蚁仓** | 重仓尾部风险太大；蚂蚁仓爆了也不伤本金 |
| 保证金 | **抗 2 倍以上涨幅** | 数学见下：≈无杠杆，牺牲资金利用率换安全 |
| 强平监控 | **1 倍涨幅就平** | 在强平价（2 倍）之前手动跑路，留一倍缓冲 |
| 计价 | **U 本位** | 盈亏/资费/强平价全 USDT 计价，跨所对冲误差小；币本位空单暴涨时保证金价值缩水 |
| 进场 | **高价差再进** | 基差大=合约溢价高=多头 FOMO=资费高；但必须等冲高回落后再进 |
| 成交 | **买卖一价挂单，不市价** | 市价滑点高，吃掉套利利润 |
| 平台 | **CrossEx 跨所保证金** | 随时可平、资金协同；但注意其维持保证金率非常高 |

### 数学验证：抗 2 倍涨幅 = 几乎全保证金
做空 1 单位名义，价格翻倍时浮亏 = **100% 名义**。爆仓条件：

```
保证金 ≤ (涨幅 + MMR) × 名义  →  爆仓
```

- 要扛价格翻倍不爆 → 保证金 ≥ **(1 + MMR) × 名义** → 杠杆约 0.97x，**等于无杠杆**
- **CrossEx 维持保证金率（MMR）很高**（山寨币尤其）→ 强平价按 MMR 算，不是按名义保证金率算。若 MMR=5%（普通所 0.5-2%），同样保证金实际抗涨幅缩水近 5%：以为抗 2 倍，实际 1.6 倍就触发强平
- 用户「1 倍涨幅就平 + 抗 2 倍」的缓冲设计，恰好覆盖 MMR 误差余量——思路正确
- **缺点：资金利用率极低**（这是主动接受的代价）

## CrossEx 底层盈利点拆解（2026-08-20 群分析）

> 问题：CrossEx 靠什么赚钱？为什么 Gate 愿意做这套重基建？

**结论：CrossEx = Gate 用重基建换返佣流量入口的生意。用户免费/低价用跨所协同，Gate 赚交易量返佣。**

1. **返佣（主菜）**：Gate 在 Binance/OKX 的底层账户是高返佣做市商账户。用户经 CrossEx 下单 → 成交记在 Gate 底层账户头上 → 交易额返佣归 Gate。官方卖点「交易量合并统计」就是为提升底层账户 VIP 等级拿更高返佣——闭环证据。
2. **手续费（佐料）**：面向机构/量化，费率走 Gate VIP 档，单靠手续费撑不起系统成本。
3. **补充次要收入**：① 联合保证金池闲置资金吃利息/拆借差（一个资金池吃两边市场）；② 内部低延迟撮合可赚双边价差（非纯通道）。
4. **成本端**：跨所撮合 + 联合保证金清算 + 多所风控联动 = 重基建，小玩家做不了——所以只有 Gate 这类二线大所会做（聚合一线所流动性来竞争；一线所自身无动力）。

**对套利者的含义**：平台盈利靠交易量返佣而非用户爆仓 → 无恶意坑单动机；但插针风险依然来自市场本身（TUT 剧本下 CrossEx 照样爆仓）。

## BNC 实测评估（2026-08-20，真实数据否决）

> 用户计划用 BNC（妖币）做资金费套利实践。ccxt 实测三所 + Gate，结论：**当前不宜做，三个硬伤**。

**1. 无现货可对冲（SF 形态做不了）**
- Binance/Bybit 只有 BNC/USDT 永续（~$2.85）；三所现货均无 BNC
- Gate 的 "BNC/USDT" 现货 $0.0144 ≠ 永续 $2.85，相差 ~200 倍 = **同名不同物**（不同项目）
- → 只能纯永续空吃资费（方向敞口全裸，适用「抗 2 倍涨幅+1 倍强平」框架）

**2. 深度极浅（容量 $500-1,000 级）**
- Binance 永续前 10 档：bid $2,211 / ask $1,490，买卖价差 0.21%
- 开平仓各吃 0.2%+ 滑点；8h 资费 0.978% 可覆盖，但容量=玩具仓

**3. 资费历史被操控（诱饵特征）**
- 近 3 天 Binance 结算序列：+0.49% → +0.27% → **-0.42%** → **+1.09%**
- 一天内 -0.42% ↔ +1.09% 剧烈跳变 = 费率诱导，TUT 剧本第一步（制造费率差吸引套利者）

**4. 时机未到（违背用户自己定的入场条件）**
- 48h +12.9%、最近 12h +7.6%、振幅 13.8%、距高点 -3.5% → 拉升尾段，非「冲高回落横盘」

**决策**：BNC 三个硬伤（无现货/深度浅/资费被操控）→ 放弃。等「资费连续 3+ 次结算同向 + 横盘确认」后，在 Bybit Unified 上选**有现货**的币做跨所/同所资金费套利。
