## 结论先行

**资金费套利 = 卖保险：收确定的保费（资费），扛不确定的赔付（暴涨）。** 所有风控参数（蚂蚁仓、保证金厚度、1 倍涨幅强平线）都是在控制「赔付上限」。刚暴拉的币做 SF（现货+空合约）是风险最高的进场时点；**冲高回落→横盘后**吃资费才是「只收租、不赌方向」的稳窗口。跨所保证金平台（CrossEx）≠ 免死金牌，TUT 剧本下 2 倍杠杆照样爆。

- **社区信号**：币安广场 + X 上大量 KOL 推 BTW → 狗庄收割节奏的前兆（类比 TUT 剧本，见下）

### 为什么刚拉完做 SF 有风险
1. **基差虚高**：拉盘时合约涨得比现货凶，买现货+空合约先吃基差浮亏；基差收敛那一刻 SF 头寸反而亏基差
2. **高资费是过热信号不是安全信号**：多头拥挤到愿付 124% 年化，情绪极端，随时二次拉升或插针
3. **深度薄**：24h 成交额千万级，进出滑点大，SF 利润被滑点吃光

### 为什么横盘吃资费最稳
- 横盘 = 波动率下降 → 基差窄幅震荡 → **方向性风险≈0**
- 但多头仓位没走 → 资费维持高位 → **收租不变**
- 一句话：**资费高 ≠ 机会好，波动降下来资费还高才是机会好**

## CrossEx 实战框架（用户经验）

CrossEx = Gate 推出的跨所交易/清结算平台，单账户连 Gate + Binance + OKX，跨所保证金共享、盈亏互抵（2025-10 上线，机构/量化向）。

### 核心参数
| 参数 | 设定 | 理由 |
|---|---|---|
| 资金占比 | **蚂蚁仓** | 重仓尾部风险太大；蚂蚁仓爆了也不伤本金 |
| 保证金 | **抗 2 倍以上涨幅** | 数学见下：≈无杠杆，牺牲资金利用率换安全 |
| 强平监控 | **1 倍涨幅就平** | 在强平价（2 倍）之前手动跑路，留一倍缓冲 |
| 计价 | **U 本位** | 盈亏/资费/强平价全 USDT 计价，跨所对冲误差小；币本位空单暴涨时保证金价值缩水 |
| 进场 | **高价差再进** | 基差大=合约溢价高=多头 FOMO=资费高；但必须等冲高回落后再进 |
| 成交 | **买卖一价挂单，不市价** | 市价滑点高，吃掉套利利润 |
| 平台 | **CrossEx 跨所保证金** | 随时可平、资金协同；但注意其维持保证金率非常高 |

### 数学验证：抗 2 倍涨幅 = 几乎全保证金
做空 1 单位名义，价格翻倍时浮亏 = **100% 名义**。爆仓条件：

```
保证金 ≤ (涨幅 + MMR) × 名义  →  爆仓
```

- 要扛价格翻倍不爆 → 保证金 ≥ **(1 + MMR) × 名义** → 杠杆约 0.97x，**等于无杠杆**
- **CrossEx 维持保证金率（MMR）很高**（山寨币尤其）→ 强平价按 MMR 算，不是按名义保证金率算。若 MMR=5%（普通所 0.5-2%），同样保证金实际抗涨幅缩水近 5%：以为抗 2 倍，实际 1.6 倍就触发强平
- 用户「1 倍涨幅就平 + 抗 2 倍」的缓冲设计，恰好覆盖 MMR 误差余量——思路正确
- **缺点：资金利用率极低**（这是主动接受的代价）

## TUT 剧本互证：正资金费率 ≠ 安全

TUT 案例（见 `tut-funding-trap-20260809.md`）：拉盘期币安费率≈0、Bitget/Gate 每 4h 2%（日 8%）→ 吸引套利者币安做多 + BG/Gate 做空 → 最后一分钟插针爆掉做空腿 → 只剩单腿多单 → 狗庄爆砸补刀，两边都亏。

**关键教训：**
- 正资金费率可以是**诱饵**，不是安全信号——狗庄故意制造费率差钓鱼
- **用 Gate CrossEx 也不好使，照样爆仓（2 倍杠杆也会爆）**——跨所保证金平台解决的是资金协同，不是插针风险
- BTW 现在的高费率 + KOL 密集推广 = 与 TUT 诱盘期高度相似 → 观望或严格按框架小仓
