# 金融终端系统 4：套利监控模块设计思路（老孙 sunlc.ai）

> 来源：https://x.com/sunlc_crypto/status/2085578921320616081（Paxon 分享 2026-08-08）
> 关联：`scripts/funding_sentinel_v2.py`（我们的资金费率哨兵）、`scripts/oi_monitor.py`、`scripts/cex_spread_monitor.py`——老孙的模块化思路 = 我们的哨兵全家桶进阶版

## 套利监控模块的 7 个子功能

1. **正费率监控**：实时/历史资金费率 + 价差 + 交易量 + OI + FDV 全信息
2. **负费率监控**：还原每个交易所的资金费率公式 + **资金费率预测模型**找套利机会（负费率风险极大，人工因素多，仓位不能大）
3. **美股正费率监控**：逻辑同币圈正费率，但**无野庄风险**（风险小很多）；合约在币安，现货币安+bitget
4. **RWA 标的监控**：美股/黄金/原油合约跨所价差 + 资金费差
5. **币圈升水监控**：BTC/ETH 在币安/OKX/Deribit 当季次季合约升水（≈U 借贷利息 = 资金成本 + 行情热度指标）
6. **OI 异动提醒**：**「价格没变但 OI 显著放大 = 最明显的庄家入场特征」**——野庄慢慢建仓价格不明显，OI 变化明显
7. **自定义监控**：任意交易对价差/资金费（如强庄币 LAB）

交易所：binance/okx/bitget/bybit/gate/kucoin/hyperliquid/aster，**统一 CCXT 接入**

## 核心认知：野庄是套利者最大风险

- 主流币几乎无套利机会；山寨币被野庄操控
- **「做全自动套利策略 100% 会踩坑中招」**（老鸟自述：去年 10 月 bybit 被 seraph 爆 100W U 赔 78W；今年 bitget 又被搞赔一半）
- 野庄操控成本极低：**几百万 U 就能操控一个山寨币**，不需要技术含量，只要没底线
- 已形成流水线/产业链，藏在 HK/SG，部分交易所还有内应
- **OI 是最难造假的指标**：开仓前看 OI 4000W，1 分钟内被野庄 ADL 到 200W（95% 仓位是野庄对开的）

## 对我们最有价值的 4 个信号

1. **「全自动套利必踩坑」的现身说法**：老鸟都被野庄收割 → 印证「系统只筛机会，人扣扳机」的正确性；全自动 = 送人头给野庄
2. **OI 联合价格判断**：把 oi_monitor 升级为「价格平稳 + OI 放大」才告警（庄家入场特征）——比单纯 OI 异动更精准
3. **美股合约费率**：币安有美股永续合约？如果有，费率监控 + 时钟差可以打通（我们 gate 币股只有现货）
4. **升水 = 资金成本**：监控 BTC/ETH 升水作为行情热度和借贷利率的代理指标
