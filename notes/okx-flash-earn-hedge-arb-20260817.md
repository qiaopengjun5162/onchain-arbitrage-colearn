# OKX 闪赚 + 现货对冲套利评估（Paxon 实测数据）

> 来源：白云（@iBaiyun04）套利思路 #5（GitHub issue `w3player/arbitrage-playbook#6`，Bruce 收集，2026-08-12）+ Paxon 2026-08-17 实测
> 原贴：https://x.com/iBaiyun04/status/1998231642188763465
> 归档日期：2026-08-17（Hermes）

## 一句话

OKX 闪赚活动期本币给 100%+ 年化 → 现货买入参加活动 + 永续空等量对冲，delta-neutral 吃活动收益；**Paxon 实测 RE 单币：宣传年化 120% → 实际年化 34%**（gross vs net 又一个实证）。

## 机制

1. OKX 闪赚 = 交易所活动：某币（本币/相关币）活动期有高年化（100%+）收益
2. 套利玩法：现货买入该币参加闪赚吃活动收益，同时永续做空等量对冲价格风险
3. 收益来源 = 活动收益 − 资金费 − 对冲成本；价格风险被对冲，收益近乎确定

## Paxon 实测（RE 单币，2026-08-17）

| 项 | 数字 |
|---|---|
| 投入 | 8500U（现货买入 10000 枚 + 合约做空 10000 枚） |
| 闪赚收益 | 150 枚 ≈ 60U（宣传口径年化 120%） |
| 资金费损失 | ~20U（现货/合约价差基本可忽略） |
| **净利** | **40U / 5 天 ≈ 实际年化 34%**（宣传的 1/3.5） |

⚠️ 注：RE 单币实测，不代表每个闪赚币都这样（不同币年化/流动性/可借量差异大）。

## 结论与判断

- **为什么 120% → 34%**：宣传年化是活动期瞬时口径；摊到全额资金占用（8500U）+ 5 天持有 + 对冲成本后缩水。年化 120% 是 gross，34% 是 net（互证 `notes/gross-vs-net-three-cases-20260811.md` 五问：口径/成本占比/返佣依赖/样本窗口/最小规模）
- **机制成立但资金效率低**：8500U 赚 40U（5 天 0.47%），收益是**事件性**的（活动窗口几天），不是常驻策略——与「高费率是事件驱动」同构
- **风险**：① 空单提前平掉 = 脱离对冲变裸多（Paxon 实测自述「空单多拿了一会，不安全」）→ 对应 digest 053 ADL 剪刀仓/方向敞口；② 账本纪律：只记闪赚收益不记对冲成本是自欺欺人 → 对应 digest 062 五栏账本
- **定位**：适合手头闲钱多、低风险偏好的玩家；**不符合五阶段管线主攻方向**（资金占用高、收益事件性、无结构性 edge），但作为「事件驱动套利家族」成员值得记录
