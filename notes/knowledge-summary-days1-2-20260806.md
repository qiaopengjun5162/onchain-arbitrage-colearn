## 第 1 章 · 链上基础与跨链桥


#### 核心概念

- **区块链与区块**：区块链是一套公开记录系统（公开账本）。区块=账本的一页，交易=页内的一条流水；区块号=页码，区块哈希=本页唯一指纹，父哈希=上一页指纹，交易哈希=某条流水的单号。区块内包含交易数、内部交易数、Gas Used，父子区块靠哈希串联。
- **交易字段**：from、to、nonce、value、input、gas、gasUsed、effectiveGasPrice、status、Transaction Fee。Value=0 不代表没有资产变化——ERC-20 转移显示在 Token Transfers（All Transfers 是原始流水，Net Transfers 是净变化汇总）。
- **交易生命周期**：构造→签名→广播→进入 mempool→验证者排序打包→区块执行→确认→最终化。交易哈希只能定位签名数据，须再读回执核对 status、gasUsed、日志、区块号与区块哈希，才能证明入块与成功。
- **确认与最终性**：区块状态分 proposed、safe、finalized；最终性=交易不可逆转的时间点，各链差异巨大：

| 链 | 区块时间 | 实际最终性 |
|---|---|---|
| Ethereum | ~12 秒 | ~6 分钟（35 区块）|
| Arbitrum | ~0.25 秒 | ~10 分钟（等 L1 确认）|
| Solana | ~0.4 秒 | ~1 秒（但有 reorg 风险）|
| Bitcoin | ~10 分钟 | ~60 分钟（6 区块）|

- **钱包/地址/私钥**：钱包不是"装币的盒子"，资产记录在链上，钱包只是管理账户、签名交易的界面。地址可公开；私钥是控制账户的秘密，任何人拿到都能控制资产；签名用私钥证明授权但不公开私钥。助记词、私钥和授权权限是安全第一道防线。账户分 EOA（私钥控制，可发起顶层交易）与合约账户（执行中按代码行动）。同一 0x 地址可在多条链出现，但各链余额、代币、交易历史彼此独立；Chain ID 防止交易发错网络。
- **原生币 vs 代币**：原生币用于支付本链 Gas（如 ETH）；代币由智能合约按"地址→余额"记录发行。WETH 是符合 ERC-20 的包装版 ETH（1 ETH=1 WETH），因 ETH 是原生币不是 ERC-20，合约处理不便。同名代币不一定是同一合约，合约地址才是链上唯一身份。零地址（0x000...000）转出常代表 Mint 铸造，转入常代表 Burn 销毁。
- **智能合约**：部署在链上的程序，DEX、跨链桥、借贷、质押都靠合约按规则执行。
- **L1/L2/侧链**：主网、测试网、L2 是不同账本；L2 出块快（Arbitrum ~0.25 秒）但最终性仍等 L1 确认，且最终性时间可能不一致。Ethereum 的 mempool 公开、按 Gas Price 排序，可看 pending 交易并加价抢跑；部分 L2 的 mempool 私有、排序用 FCFS，抢跑方式不适用。

#### 关键机制

- **Gas 计费**：Gas 按实际使用计费，交易失败也须支付已消耗的执行成本；revert 回滚状态但不退回已消耗 Gas，Nonce 仍推进。实际 Gas 费 = gasUsed × effectiveGasPrice；须区分 gas limit、gas used、base fee、priority fee。"费用免费"≠Gas 免费。
- **报价/滑点/价格影响**：DEX 不是固定价格牌，金额变大成交变差（不是订单簿档位，而是池内资产比例被改变）。报价是系统按当前状态给的预计值，不等于成交；滑点是实际成交相对预计的偏离（金额越大、池子越浅、波动越快滑点越大）；价格影响是自己的交易推走池子价格。滑点是成交成功率与价格保护的平衡：太低交易易失败，太高可能以差价格成交甚至被 MEV 夹击。
- **套利净利润**（多条打卡共识）：

```
净利润 = 卖出所得 − 买入成本 − 交易费 − Gas − 桥费 − 滑点 − 失败/对冲损失
```

两个池子现价不同 ≠ 存在可交易净利润。V2 报价公式：

```
amountInWithFee = amountIn * 997
amountOut = amountInWithFee * reserveOut / (reserveIn * 1000 + amountInWithFee)
```

- **原子性与 MEV**：同链套利可原子——把"A 买入→B 卖出→minProfit 检查"放进一笔总交易，利润条件不满足整笔回滚，避免单腿风险；但回滚不等于免费，Gas 仍损失。三角套利满足 rate(A→B)×rate(B→C)×rate(C→A)>1 即有机会，同样可原子完成。MEV=通过调整交易排序提取价值；frontrun、sandwich（攻击者买入→你的交易→攻击者卖出）源于 mempool 公开透明。应对：更快发现、加 Gas、私有通道（Flashbots：rpc.flashbots.net 给钱包用户、relay.flashbots.net 给开发者）、滑点保护。Flashbots 链路：Searcher 找机会→Builder 组合并先模拟（条件不满足不进区块）→Relay 转交→Validator 上链；身份密钥与资金钱包分开。
- **跨链桥工作原理**：链之间隔离，资产不能直接"飞"到另一条链，必须通过桥：源链锁定（或销毁）资产→（等待桥确认，分钟~天）→目标链铸造/释放/映射等量资产。不同桥的安全模型和实现不同；跨链不是"点击一下马上换链"，等待时间本身就是套利风险。
- **常见桥**：Across（第三方流动性先垫付，快）、Stargate（基于 LayerZero，全链流动性）、Hop（Rollup 专用 L2↔L1/L2）、Wormhole（支持 Solana 等非 EVM）、官方桥（最慢但最安全）。LI.FI 是桥的聚合器（路由与执行层），聚合桥、DEX、求解器、收益协议，按价格/速度/Gas/可靠性算最优路径，支持 60+ 链。
- **跨链两种执行方式**（Flashbots 论文）：经 bridge（平均约 242 秒）vs 预先在两链都放资金（约 9 秒，66.96% 采用），后者须承受资金持续暴露风险。包装资产（axlUSDC、axlATOM 等）只是映射版；stkATOM 等质押凭证的价格、赎回时间、风险不能等同于现货。

#### 实操要点

- **链上数据读取**：Etherscan 是查证工具不是交易软件；JSON-RPC + ABI、viem 可读区块、交易、日志、合约状态。readContract 最终用 eth_call（只读模拟、不改变链上状态）；multicall 批量读取可指定 blockNumber，保证一次计算的所有状态来自同一区块；WebSocket 只负责及时通知，不保证数据正确或不丢失。The Graph（GraphQL 查 pool/swaps/liquidity）、Blockscout、eth_getLogs 作链上证据。链上整数一律用 bigint，不用 number。
- **钱包安全**：私钥不写入源码/命令历史/不提交 Git；RPC Key 放 .env 并配 .gitignore；用独立 Agent 钱包不用主钱包；approve 用精确额度，警惕无限授权；AI 不直接持私钥、不生成未核验合约地址、不决定金额。
- **跨链实操**：先用 LI.FI 拿 quote 再执行、对比不同桥报价；实测：100 USDC Polygon→Base 到账 99.75，费用 $0.27（Gas $0.02+桥费 $0.25），耗时约 7 秒；跨链 deposit 不原子（实测 2–7 秒）。
- **学习顺序共识**：基础概念→钱包/交易/Gas→智能合约→DEX/AMM→数据读取→模拟/测试网→小额实盘；先做只读监控，再逐步自动化。

#### 常见误区与风险

- 看到价差≠能赚钱：报价可能过时、流动性不足大单推价、费用吃掉利润、MEV/竞争者抢跑、一边失败。
- "无损跨链"≠无手续费、无波动、无等待、无合约风险，包装资产也不等于原生资产。
- 失败交易也扣 Gas；回滚≠免费；"费用免费"≠Gas 免费。
- 同名资产不一定是同一种资产：跨链后同名 USDC/USDT 不是同一份余额，须核对链名、合约地址、发行方、赎回路径、流动性。
- 跨链风险：①等待时间——价差可能在到账前消失或反转，时间就是成本；②桥安全——桥是 DeFi 历史上被黑损失最惨重的类别（Wormhole ~$3.2 亿、Ronin ~$6.2 亿、Nomad ~$1.9 亿，均 2022 年）；③单腿风险——一边成交一边失败，留下暴露于价格波动的头寸；④价格波动；⑤桥费+桥汇率损失。

| 维度 | 单链套利 | 跨链套利 |
|---|---|---|
| 执行时间 | 一个区块（~12 秒）| 分钟~天 |
| 原子性 | 可原子 | 通常不可原子 |
| 成本 | Gas+滑点+协议费 | 再加桥费+汇率损失+时间成本 |
| 风险 | 合约风险 | 合约风险+桥被黑风险 |
| 竞争 | 极高（MEV 毫秒级）| 中（门槛高）|

跨链套利是用风险和时间换竞争空间；桥的选择=速度/费用/安全性的权衡。实盘只投入可完全损失的小额资金，shadow run/模拟后再放大。

#### 社群共识

- 套利核心不是发现价差，而是判断价差是否真实、可执行、扣完所有成本仍有净利润；"理论净利润为正"不等于赚到钱。
- 报价只是预计，成交才是结果；一切以链上实际执行为准。
- 私钥/助记词/授权是第一道防线：不泄露、不入库、不用主钱包、精确授权。
- 先核对资产身份（链名+合约地址）再谈价差；跨链包装资产须查发行方、赎回路径与流动性。
- 学习路径：先纸面计算和只读监控，再模拟/测试网，最后小额实盘；AI 是辅助，思路与风控由人主导。
- 跨链等待时间与桥安全是跨链套利最大的两类风险；原子套利中的最终 minProfit 检查不能省。

## 第 2 章 · DEX 与 AMM 机制

### 2.1 基础篇


> 综合『链上套利残酷共学』学员打卡笔记第 1 部分提炼：AMM 基础、恒定乘积定价、滑点数学、v2/v3 对比、LP 经济与路由聚合。只收录笔记中出现过的结论。

#### AMM 基础

- **AMM（Automated Market Maker，自动做市商）**：不用传统订单簿，而是用数学公式自动定价的交易机制。你不需要等别人挂单，直接跟池子交易，**池子本身就是对手方**，像一个"自动售货机"。Uniswap 是最典型的 AMM。
- **x·y = k 是约束而非恒等式**：池中有 x 个 token0、y 个 token1，"任何交易都必须保持 x 乘 y 不变"——它是交易的约束条件，不是系统保证的数学恒等式。
- **价格 = 储备比例，无需预言机**：ETH 的价格 = USDC 数量 / ETH 数量（y/x）。池子里某种资产越多越便宜、越少越贵，价格完全由供求（池中比率）决定。价格也可理解为从原点到双曲线上该点连线的斜率；交易就是沿曲线滑动，连线不断变角。
- **双曲线永不与坐标轴相交**：有限输入无法把一种储备完全买到零，池子抽不空，安全性来自不变式本身而非 require。
- **AMM vs 订单簿**：订单簿靠买卖挂单撮合，价格由挂单深度决定（如 dYdX、Serum 等链上 CLOB）；AMM 的价格由储备比例实时决定、曲线上任意一点都可交易，深度由 k 和储备规模决定。AMM 优点是无对手方、始终有报价；缺点是任何交易都产生价格冲击，大单滑点明显，且链上撮合（订单簿类）成本高、延迟大。

#### 定价公式（含推导与计算示例）

设池子持有 x = reserve_in、y = reserve_out，守 x·y = k。**不含手续费**的兑换：

```text
x' = x + deltaX
deltaY = y - k/(x + deltaX) = y·deltaX / (x + deltaX)
```

**手续费扣在输入侧**，只有一部分真正上曲线（f 为费率，如 0.3%）：

```text
a_eff = amount_in·(1 - f)
amount_out = y·a_eff / (x + a_eff)
```

分子分母同乘 10000 消掉分数（n = 10000 − fee_bps），得到"只剩最后一个除法"的整数公式：

```text
amount_out = amount_in·n·y / (x·10000 + amount_in·n)
```

Uniswap V2 单跳、0.3% 输入手续费的精确公式（997/1000）：

```text
amountInWithFee = amountIn * 997
amountOut = floor(amountInWithFee·reserveOut / (reserveIn·1000 + amountInWithFee))
```

已知精确输出反推最少输入：

```text
amountIn = floor(reserveIn·amountOut·1000 / ((reserveOut - amountOut)·997)) + 1
```

末尾 +1 很重要：整数除法向下取整，少这一单位可能无法通过 K 校验。EVM 没有浮点，Solidity 的 `/` 直接截断，链上所有代币数量都是整数，手算验证也应全程用整数除法保持逐位一致。

**计算示例**（USDC-ETH 池，2000 ETH / 4,000,000 USDC，k = 8×10⁹）：按标价买 1 ETH 需付 2000 USDC，实际获得：

```text
deltaY = (2000 × 2000 × 0.997) / (4,000,000 + 2000 × 0.997) ≈ 0.996 ETH
```

想要 1 ETH 只拿到 0.996 ETH：一部分是 0.3% 手续费（给 LP），另一部分是价格冲击——交易本身把 ETH 价格推高了。

**quote vs getAmountOut 的区别**：`quote` 是不含手续费的同比例换算（amountB = amountA·reserveB/reserveA），用于加池；真实 Swap 必须用 `getAmountOut`，输出会因手续费和价格影响更低。例如 quote(100, 1000, 2000) = 200 只表示"加池时 100 A 应搭配 200 B"，不表示把 100 A 卖给池子能收到 200 B。

#### 滑点数学

- **滑点（价格冲击）产生的数学原因**：在 x·y = k 约束下，有限交易必然沿双曲线滑动。边际价格 = y/x（dy/dx = −y/x），交易后储备变为 x'、y'，平均成交价 = deltaY/deltaX。**交易规模越大，平均成交价与初始边际价格的差距越大**，这就是价格冲击（Price Impact）。本质是"你自己的交易改变了池子状态"，你是在为滑向新价格付费。
- **超线性增长**：买 10 ETH 的冲击远大于买 1 ETH 的 10 倍——每多买一点池子就更失衡，后面的每一口价格都更差。实测（4678 ETH / 878 万 USDC 池）：0.1 ETH 冲击 0.30%、1 ETH 0.32%、10 ETH 0.51%、100 ETH 跳到 2.43%。
- **精确恒等式**（V2，含 0.3% 手续费，非近似）：

```text
P_含费有效 / P_边际 = 1000/997 + amountIn/reserveIn
                      手续费项    价格冲击项
```

- **可推广法则**：交易额达到池子储备的约 0.3% 时，价格冲击才追上手续费。低于该量级成本由手续费主导（实测 887 万美元池子打 100 美元：手续费占比 99.63%、冲击仅 0.37%，比值 267:1）；高于它滑点开始主导。该池分水岭 ≈ 26,690 USDC。滑点只有在下单量占池深有意义比例时才成为约束条件。
- **浅池 vs 深池**：同样 1000 USDC，深池（1000 ETH/25 万 USDC）滑点 0.40%，浅池（100 ETH/2.5 万 USDC）滑点 4.00%。池子越浅，同样的单子冲击越大；TVL 越高池子越"重"，越难被一笔交易推动价格。
- **价格冲击 ≠ 滑点（狭义）**：冲击是你自己订单造成的；滑点是提交交易到被打包之间"别人/时间"造成的价格变动（常含 MEV 抢跑成分）。屏幕上看到 1% 价差不等于存在 1% 套利空间——你的套利交易在两个池子都会产生冲击，买入推高一个、卖出压低另一个，双向叠加后 1% 价差可能变成 0.1% 甚至亏损。

#### v2 vs v3

| 目标 | V2 | V3 |
| :--- | :--- | :--- |
| 池身份 | (token0, token1) | (token0, token1, fee)，同币对可多费率池 |
| 创建 | Factory.createPair | Factory.createPool + Pool.initialize(sqrtPriceX96) |
| 首次定价 | 首次按两币注入比例 | 必须显式初始化 sqrtPriceX96，一旦设置不可再次 initialize |
| LP 凭证 | Pair 发行同质化 ERC-20 | PositionManager 发行仓位 NFT（tokenId） |
| 流动性范围 | 全价格区间 [0, ∞] | [tickLower, tickUpper) 集中流动性 |
| 移除 | removeLiquidity → Pair.burn | decreaseLiquidity 后还要 collect |
| 报价 | Router view 公式 | Quoter/QuoterV2 模拟 swap 并 revert 返回结果，不应在链上业务中调用 |
| 收款 | 输入先转入 Pair | Pool 先算 delta，再在 callback 中要求付款 |

- **集中流动性**：V2 里 LP 的钱铺在 0 到 ∞ 的整个价格轴上，绝大部分永远用不到（没人会在 ETH 涨到 100 万美元时来成交）；V3 让 LP 指定价格区间，同样的钱在区间内深度厚得多、赚的手续费也多。**代价是价格跑出区间就一分钱不赚**，仓位逐渐变成单边资产。单边存入（如区间完全在现价下方且只存 USDT）等价于在区间内挂了一串限价买单，区别只是还额外收手续费。
- **Tick 是对数价格坐标**：price(token1/token0) = 1.0001^tick，Pool 保存的精确价格是 sqrtPriceX96 = sqrt(price)·2^96（方向严格是 token1/token0）。整数 tick 只能说明价格位于 [1.0001^tick, 1.0001^(tick+1))，tick 内部的精确位置必须用 sqrtPriceX96。tickSpacing 限制哪些 tick 可以作为区间边界；只有被 LP 选作边界的 tick 才需要初始化。
- **有效流动性 L**：L 不是 token 数量、不是 TVL，而是当前价格区间的交易深度，等于所有覆盖当前 tick 的仓位 liquidity 之和。L 越大，同样 amountIn 推动价格越少。区间内换算关系：

```text
amount0 = L·(sqrtB - sqrtP) / (sqrtP·sqrtB)
amount1 = L·(sqrtP - sqrtA)
```

- **逐格递推流动性分布**：跨过已初始化 tick 时应用该 tick 的 liquidityNet：L_after = L_before + liquidityNet(t)。liquidityGross 是所有以该 tick 为 lower/upper 边界的仓位绝对值之和，**不能**当区间流动性用。V3 没有描述整个 Pool 的固定全局 K，仅在单个有效区间内满足 x_virtual·y_virtual = L²。
- **手续费**：V3 由 Core 强制执行，直接调用 Pool 不能绕过；按 fee growth 为活跃仓位记账，可单独 collect。fee 为百万分比，3000 = 0.3%，常用档位 0.01%/0.05%/0.30%/1.00%。V3 没有 V2 的 getReserves/skim/sync。

#### 流动性池与 LP

- 流动性池是持有两种资产的合约；池子刚创建时可以为空，LP（流动性提供者）按比例存入两种资产后其他用户才能兑换。任何人可无许可 addLiquidity，LP 随时可撤资（按当时比例取回，拿回的是当前储备构成而非最初存入数量，差异来自交易、手续费、价格变化和无常损失）。项目方若抽干池子即 rug pull。
- **加池保持池价不变**：Router 先算 amountBOptimal = amountADesired·reserveB/reserveA，总是完整使用一侧、按储备比例减少另一侧（多余 Token 留在钱包）；空池由初始 LP 的注入比例定义初始价格。
- **LP 凭证铸造（V2）**：首次注入 liquidity = floor(sqrt(amount0·amount1)) − 1000（MINIMUM_LIQUIDITY 永久铸给零地址，使 totalSupply 永不归零）；后续注入取 min(amount0·totalSupply/reserve0, amount1·totalSupply/reserve1) 的较小值，多余一侧的投入实质上部分捐赠给全体 LP。撤池 amount0 = liquidity·balance0/totalSupply。
- **手续费分配**：V2 的 0.3% 手续费留在池中，使 k 微增（无手续费时交易 k 恒定，含费时每笔交易 k 单调递增，这是 LP 的全部收益来源）；LP 没有独立 collectFees，只能通过 burn LP 按比例取回。V3 中手续费按"仓位占全池有效流动性的比例"分给当前处于价格区间内的 LP（如 PancakeSwap V3 的 0.01% 档约 67% 的交易费分给有效区间 LP）。
- **LP 的收益与风险**：收益 = 交易手续费分成；风险 = 无常损失（价格剧烈波动时 LP 份额总价值可能低于直接持币）、LVR/逆向选择损失（被信息更快的人挑着打：机器人只在与 LP 交易有利时才来，赚走的是报价与真实市场价之差）、Gas/调仓成本、区间出界后的单边持仓损失。LP 净收益 = 手续费 − 无常损失 − LVR − 折溢价变化 − Gas − 进出滑点 − 单边持仓损失。
- **评估池子**：不能只看累计成交量，要看 Volume/TVL（过高可能刷量）、进入后的实际交易量、区间是否覆盖实际成交价、手续费能否覆盖 Gas/调仓/价格变化。页面显示的 2000%+ APR 是把最近数小时收益直接年化，反映短期速度，不代表长期维持。

#### 主流 DEX 对比

- **Uniswap**：V2 恒定乘积、0.3% 手续费、流动性铺满全区间；V3 集中流动性 + 多费率档（0.01%/0.05%/0.30%/1.00%）；V4 在同一 PoolManager 内以 currency/fee/tickSpacing/hooks 区分多个 Pool。
- **PancakeSwap**：BSC 生态主力。V2 手续费 25 bps（不是 30）；V3 有 0.01%、0.25%、1% 等费率档。实测高费率档几乎吃不到流量：Base WETH/USDC 四个费率档 24 小时成交，1% 档仅 $9,249，是 0.3% 档的 0.03%——聚合器路由只认最终到手金额，费率一高立刻被绕开。
- **Curve**：稳定币池（如 3pool），用于 USDC/USDT/DAI 等锚定资产的低滑点兑换；池内币种比例失衡会导致价格偏离 1 美元，产生稳定币套利机会。
- **Balancer**：多资产/不同曲线池，常见于三角套利路径（如 USDC→ETH→LINK→USDC 闭环多出 USDC）。
- **Sushiswap**：Uniswap 的 fork，独立流动性池，与 Uniswap 同币对可形成 DEX 间价差。
- **Aerodrome**：现货 DEX（与 Uniswap V3 同类），非托管、即时 Swap，支持同链原子化交易。
- **订单簿类 DEX**：dYdX、Serum 等链上 CLOB，价格发现更接近 CEX、深度可视，但链上撮合成本高、延迟大。
- 同一交易对会有多个池子（不同 DEX、不同费率档、不同链），**流动性割裂 = 价差来源 = 套利者的饭碗**；套利者通过交易使不同市场的价格重新靠近，其利润在经济上主要来自池子以落后价格成交产生的价值转移。

#### 聚合器与路由

- **Router 的作用**：DEX 里有很多 pool，同一资产往往有多条路径可达（持 USDC 可直接买 BTC，也可 USDC→ETH→BTC），不同路径最终得到的数量可能不同，Router 自动帮用户找到最有利的交易路径。聚合器路由只认最终到手金额，这正是高费率池没有流量的原因。
- **LI.FI 定位**：执行层（资金怎么走、成本多少、交易怎么构造），不是策略层（哪里有机会）。跨链时聚合桥 + DEX 报价；收取固定服务费（实测 LIFI Fixed Fee 25 bps，1000 USDC 收 $2.50）。/quote 接口限流 75 次/2 小时且 no-store，候选集应在宽松接口上做、/quote 只用于最终测量。
- **报价不能只看 toAmount**：toAmount 是乐观角读数，toAmountMin 才是保底数字——滑点容忍带宽可能比机会本身宽（实测 0.5% 带宽是 22 bps 优势的 2.25 倍），实际成交若落在保底端会从"赚少了"变成亏损。要比较 /advanced/routes 的多条候选路径，把耗时当一级指标（实测同参数下 Polymer 路线 1080 秒 vs Eco 7 秒，到手金额一样）；/quote 是时变的，同参数不同时点结果就不同。
- **与本地公式对账**：用 UniswapV2Router.getAmountsOut 做 Tier 1 整数精确对账（任何 delta 都是自己的 bug，没有解释空间）；与 LI.FI 的 gap 是路由价值本身（可能来自费率档差，如 V2 30 bps vs V3 5 bps 差 25 bps，残差 ≈ 聚合器抽成 + 池间偏离），记录并解释即可，不要调代码让它归零。注意同名资产不同版本（USDC vs USDC.e）价格可能差近 11 bps，搞错版本后续比较全部失真。
- **跨链非原子**：等资金跨过去机会早没了；务实打法是多链预置库存（双边库存模式）、两端先成交、事后用 LI.FI 做库存再平衡，把跨链从"抓机会的路径"改成"调仓的后勤"。

### 2.2 进阶篇（Curve / 多池 / 大单执行）


> 本部分综合学员打卡笔记，聚焦 AMM 定价与价格冲击的精确计算、Uniswap V2/V3 深入机制、流动性深度与价格冲击的关系、其他 DEX 机制、大额交易执行策略，以及与套利结合时价差产生与消失的机制。

#### 一、AMM 定价与价格冲击的精确计算

#### 1. 恒定乘积模型与 Swap 输出

DEX 没有订单簿，价格由池内两种资产储备量的比值决定。恒定乘积模型 `x·y=k` 中，x、y 是两个代币的储备量，k 为常数；用 Δx 换 Δy 后满足 `(x+Δx)·(y−Δy)=k`，价格由储备量比值决定（P=y/x），交易本身会改变池子比例从而改变价格。Swap 输出量：

```
无手续费：ΔY = y − k/(x + ΔX)
有手续费：ΔY = y − k/(x + ΔX×0.9975)   // 先按费率扣除投入，再按恒定乘积结算
```

#### 2. 价格冲击的公式与非线性

价格冲击（price impact）=「这笔交易的成交均价」相对「成交前现价」的偏离，可以精确计算而非大概估计：

```
成交均价 = ΔX/ΔY = (x+ΔX)/y ≈ 现价 × (1 + ΔX/x)
精确公式：PI = Δx/(x+Δx)     // 由池子深度 + 你的下单量共同决定
```

价格冲击是非线性的：冲击成本 ∝ Q²/pool_depth，交易量翻倍、冲击成本翻四倍。真实数据验证：$4M TVL 的池子 1 ETH 冲击仅 0.1%、10 ETH 冲击达 1%，而 $400K 浅池 10 ETH 冲击高达 9%；深池（4,651 ETH × 8,851,010 USDC）买 100 ETH 单价从 1,903 涨到 1,945，浅池（50 ETH）买 10 个单价飙到 2,378（+25%）。

#### 3. 价格冲击 ≠ 滑点

- **price impact**：自己这笔交易对池子状态的影响，由「池子深度 + 你的下单量」决定；
- **slippage（滑点）**：成交前状态被他人/环境改变——别人插队的交易、区块内排序、抢跑、网络延迟；
- 套利战场真正吃利润的是滑点（区块内排序、抢跑等 MEV 因素），而不只是价格冲击。

#### 二、Uniswap V2/V3 深入

#### 1. V2 vs V3 核心差异

- **V2**：固定费率 0.3%，全区间均匀流动性；
- **V3**：集中流动性 + 费率分档（fee tier，如 0.25% 池），流动性可集中到指定价格区间；
- **V4**：费率等参数可自定义（经链上验证 PEPE 主池是 V2）。

V3 集中流动性让小额套利的滑点更小，但流动性分布不再均匀；V3 多 tick 区间的滑点需链上合约查询，纯公式算不出来。

#### 2. Tick 与 sqrtPriceX96

V3 用 int24 的 tick 定位到 0.01% 的价格档位，用 Q64.96 定点数 sqrtPriceX96 承载精确价格，每个设计选择都是为了省 gas：EVM 没有浮点故用定点数；Δx、Δy 对 √P 线性，链上可用加减法代替开方；tick 用于 O(1) 的区间边界判断，sqrtPriceX96 用于精确定价，两者分工而非冗余。

#### 3. Flash Swap / Swap Callback：无本金套利

V2、V3 都有「先获得资产、后完成结算」机制，可为套利临时提供 financing token，无初始 ERC-20 本金即可原子套利：

```
V2 Flash Swap：pair.swap(amount0Out, amount1Out, to, data)，data 非空触发
  uniswapV2Call，回调中用资产做其他池交易，再归还本金及费用
V3 Swap Callback：pool.swap() 后触发 uniswapV3SwapCallback，
  正数 amountDelta 表示需支付给 Pool 的数量，收到的输出 token 可作临时融资
V3 Flash：pool.flash() 直接借 token0/token1，按该池 fee tier 计费归还
```

类似 AAVE 的 Flashloan：临时借币、付费用，同一笔交易内完成买入—卖出—偿还—利润结算。

#### 4. 集中流动性的真实案例：高 APR 的真相

PancakeSwap V3 的 MARS/USDT 0.25% 池约 $17.5 万流动性，却有约 $725 万/24h 成交额、约 5 万笔交易，日换手约 41 倍；0.25% 费中约 68% 进入活跃 LP，粗算 LP 费池 ≈ $7.25m×0.25%×68% ≈ $12.3k/天。短期 APR 数千 % 的本质是「极高成交额 / 很少的近价活跃流动性」，不是协议补贴。风险同样真实：MARS 上涨时 LP 持续卖出吃不到完整上涨，下跌时持续买入，跌出区间后接近全仓 MARS 且停止赚费；截图 total fees $2,536 但 total PnL 仅 $2,226，手续费之外已有无常损失；还有新 LP 稀释份额、热度退去 APR 下降、代币自带买卖税与 anti-farmer 逻辑等风险。无常损失是 LP 特有风险：价格偏离越大损失越大，回到原点则消失；对套利者不直接影响，但会左右 LP 行为——低流动性池 IL 高，LP 不愿做市。

#### 三、流动性、深度与价格冲击的关系

- 订单簿的流动性体现在不同价格档位上有多少挂单，AMM 的流动性体现在池子里有多少资产；小币种成交量高也不代表池子深，按页面价格下单可能根本无法成交。
- **池子深度比价差更重要**：浅池再大的价差也可能被价格冲击吃掉；多池路由需建立价格冲击叠加模型。
- **套利规模必须匹配池深**：模拟「币安 1,930 vs Uniswap 1,903」的 1.4% 价差，买 5 ETH 赚 $125、买 20 ETH 赚 $375、买 100 ETH 倒亏 $1,485、买 300 ETH 亏 $31,274——买得越多，价格冲击越把利润吃掉。
- 存在数学上的**最优套利规模**，由两边池子的流动性共同决定，可用闭式解求出。
- **单边 vs 双边冲击**：单边模型显示 +$12，计入进出场双边冲击后真实为 −$53；只算进场冲击、忽略出场冲击会系统性高估利润，这是模型设计问题而非精度问题。

#### 四、其他 DEX 与交易机制

- **订单簿模式**（CEX 与 Perp CLOB DEX）：买卖双方挂单、价格匹配成交；买一/卖一价只代表最接近成交的价格，大额买入要逐档吃单（100.1、100.2…），最终均价高于页面价格，只看买一卖一容易看到「虚假价差」。真实成交价用 VWAP：买入 VWAP = 实际花费 USDT ÷ 实际买到的基础币；卖出 VWAP = 实际收到 USDT ÷ 实际卖出的基础币。
- **Polymarket**：基于订单簿但有弹性供给（订单簿无单也能成交），价格恒在 [0,1]；1 pUSD → 1 YES + 1 NO，可随时反向兑回；曾存在「同一市场内同时买 YES 和 NO 使总成本 < 1」的互补套利。
- **三角套利三种形态**：单 DEX 三池（如 Uniswap V3 内 USDC→WETH→ARB→USDC，状态来源统一、可原子执行）；多 DEX 三段（Uniswap→Camelot→Sushi，池子多、理论机会多，但 RPC 查询、Gas、合约调用与失败点同步增加）；聚合器路由中的隐含三角（表面三段路径内部可能涉及多个池，聚合器会自动拆单，研究时必须展开每个 swap step，不能把聚合器报价当单一价格）。
- 聚合器报价工具（如 LI.FI /quote）需确认 included=true 的费用已从 toAmount 扣除，避免双重计算；聚合器 API 容易限流（429），需管理好 key。

#### 五、大额交易的执行策略

- **控制单笔规模、优先大池子**：规模超过池深承受能力会自我毁灭式吃掉利润。
- **路由与拆单**：多池路由分散冲击；聚合器自动拆单；路径越长失败点越多。
- **订单簿侧按穿透深度逐档执行**（从 asks 向上吃、从 bids 向下吃），按 VWAP 计算真实成交价。
- **进场前核对检查表**：代币合约与税费、池子 fee split、TVL/成交额/活跃流动性份额、仓位上下沿、价格出区间后的库存、撤仓滑点与 gas，并用「总 PnL vs HODL」而非 fee APR 做判断。

#### 六、与套利结合：价差产生与消失的机制

- **价差如何产生**：大额交易把某个池子的价格瞬间拉高，或流动性被抽走使池子稀薄拉出区间，同一资产在不同池/平台出现价差；脱锚也制造机会（如 stETH 因 Lido 有刚性兑换通道、背后有 ETH 资产支撑，脱锚后可视为套利机会）。但「名称相同不代表同一种资产」：桥接版 USDC.e 与原生 USDC 不是同一现金流（前者含桥信用风险），价差不全是套利空间，一部分是风险定价；期货合约价格还包含利率、股息预期与期限因素。
- **实际案例**：币有拉盘导致 SPYB 主池流动性被抽干，SPYB 一度从约 $750 被打到 $1,118（溢价约 49%），套利窗口持续一个多小时，直到有人加 V4 池稳定币价才落幕——拼的是信息差与反应速度；应对方式包括持币高价卖、CEX 搬砖、新币配对池加 LP、RFQ/Intent 模式找货源、借入脱锚资产高卖低买。
- **价差如何消失**：套利机器人看到大额交易拉高的价格会立马跟进抹平价差；主流资产被抹平后，摩擦成本系统性大于价差——实测 Uniswap ETH $1,868.33 vs Aerodrome $1,869.59，扣除协议费、Gas、滑点后净利润 −$52.83，主流币 DEX 间套利的公式从不成立，机会在长尾资产或剧烈波动窗口。
- **无套利带**：有交易成本时价格不必等于理论值，只需落在 [理论值 − 成本, 理论值 + 成本] 的带内，带外才是机会，核心工作是估算带宽（一价定律、复制、无套利基本定理是推导机会的骨架）；动态套利的利润全部来自对调仓成本估计的准确度。

### 3.1 成本构成与净收益公式

---


#### 成本构成全景

套利机会的本质不是"两个页面价格不同"，而是**扣除全部成本后仍有净利润**。链上摩擦成本可分为七大类：

1. **Gas 费**：执行交易消耗的计算资源费用，付给网络。不同链差异巨大（L2 约 5–50 gwei，L1 以太坊 10–200+ gwei）。交易越复杂 Gas 越高，多池套利合约常消耗 200k+ Gas。
2. **协议/DEX 手续费**：付给池子与 LP 的兑换成本，如 Uniswap V2 固定 0.3%，V3 分 0.05%/0.3%/1% 费率档；还包括聚合器费、介绍费。与 Gas 是两回事，不可混为一谈。
3. **桥费**：不是一个数字，包括存款费、中继费、赎回费。LI.FI 实测 1,000 USDC 跨链稳定币损耗约 26 bps（LI.FI 固定费 25 bps + Relayer 费 + 源链 Gas）；**0.25% 比例费构成跨链成本硬下限**，任何小于 0.25% 的跨链价差在这条路线上永远无利可图，金额再大也没用。
4. **滑点与价格冲击**：滑点是报价到执行间的总偏差，价格冲击是自己的交易改变池子价格。二者不能重复计算。
5. **延迟成本**：检测→提交→打包之间的机会成本；跨链还要算源链确认、桥接传输、目标链到账、退出交易、资产可重新部署的全部时间点。套利窗口常只有几秒，18 分钟到账的桥对套利是致命的。
6. **失败交易成本**：回滚时已执行的计算仍需支付 Gas，每次回滚 = 全部 Gas 损失；多步交易失败概率更高。非原子套利中一次失败可能抹掉约 20 次成功交易的利润。
7. **资金占用成本**：资金在执行/跨链期间被锁定（数分钟到数小时）的机会成本，约为 `资本 × 年化率 × 锁定时间`；预置库存策略的收益率分母应包含两条链上全部预置资本。

此外还有排序费用（bribe/区块位置竞价，MEV 场景下需将利润的 80%–90% 作为 tip 给 Builder）、授权成本（Approve + Swap 是两笔交易、两次 Gas）和库存再平衡成本。

#### 净收益公式

多条打卡给出了同一公式的不同表述，核心完全一致——**屏幕价差只是线索，实际成交结果才是答案**：

```
净收益 = 价差收益（卖出收入 - 买入成本）
      - DEX/协议手续费
      - Gas
      - 桥费与跨链费用
      - 滑点与价格冲击
      - 延迟成本
      - 失败交易成本（失败概率 × 失败损失）
      - 资金占用成本
      - 排序费用（bribe）/借贷费用/再平衡成本
```

BSC 套利者的实例化版本：

```
NetProfit = ΔP - F_fee - S_slippage(x) - G_gas - p_fail × G_failed - B_bribe
```

更形式化的写法（把每腿看作随数量与状态变化的函数）：

```
Π(q0) = q最终 - q0 - C外部 > 0
q_{i+1} = F_i(q_i, S_i)
```

**盈亏平衡价差（Break-even Spread）**：最低所需价差 = LI.FI 服务费 + Bridge/DEX/Solver 费 + 源链与目标链 Gas + 两端交易滑点和价格冲击 + 延迟、失败与资金占用成本。实测：跨链套利真实门槛约 57 bps（LI.FI 25 + DEX 25 + 滑点 5 + Gas），BSC 同链套利仅 31 bps；25 bps 服务费就能吃掉几十 bps 的套利边际。**Gas 是固定成本，制造了最低本金门槛**：$100 → 35.38 bps、$1,000 → 26.18 bps、$10,000 → 25.10 bps。

#### 滑点详解

**AMM 定价**：恒定乘积公式 `x × y = k`，池中资产比例决定价格，交易改变储备即改变价格。屏幕显示的是**边际价格**（无限小交易的价格），实际成交均价一定更差。例：100 ETH + 300,000 USDC 的池，30,000 USDC 买入 ETH，实际均价约 3,300 USDC/ETH，而初始价格是 3,000。

```
价格冲击 =（实际成交均价 - 交易前价格）÷ 交易前价格
滑点 ≈ 交易量占池子深度的比例（交易额是池子的 1%，滑点约 1%；10%，滑点约 10%）
```

**价格冲击 vs 滑点**：价格冲击是自己的订单改变池内价格（由订单规模和市场深度决定，市场状态不变也会产生）；滑点更多来自报价之后其他交易/市场变化导致的状态偏离。滑点容忍度是保护阈值，不是必然成本：预计得 10 ETH、容忍度 1%，最低可接受 9.9 ETH，低于此值交易回滚而非强制成交。滑点也不能设得过低，否则市场稍变就失败浪费 Gas。

**池子深度**：深度指当前价格附近可成交而不大幅改变价格的资金量。池子总价值大不代表当前价格附近深——V3 集中流动性把资金集中在一定价格区间，价格跳出区间后深度瞬间枯竭；v3 滑点是阶梯状的，跨 tick 时流动性断崖式变化。判断方法：同一交易对分别输入 $1,000/$10,000/$100,000 观察 Price Impact 跳变，大池对小额报价更优，但深度决定套利规模上限。

**订单簿滑点**：大单逐档吃穿盘口，均价用 VWAP 计算：

```
VWAP = Σ(价格 × 数量) ÷ Σ数量
```

**最优交易规模**：套利是一条关于交易规模的利润曲线，不是固定价差：

```
q* = argmax Π(q)
```

太小覆盖不了固定 Gas，太大价格冲击超过价差。实例（两池 LP 费各 0.3%）：500/1,000/2,000/5,000 USDC 扣 Gas 后净利润 10.25/24.40/37.65/-37.91，峰值约在 2,172 USDC。三角套利筛选条件 `r1×r2×r3 > 1`（已扣费），但必须逐腿传递真实输出计算，不能只用页面价格相乘。

#### Gas 详解

- Gas 是计算/网络资源单位，不是独立代币；以太坊以 ETH 支付，gwei 是小计价单位。
- **实际交易费 = Gas Used × 实际每单位 Gas 价格；实际单价 ≈ Base Fee + Priority Fee**。Base Fee 由协议决定并销毁，Priority Fee 是争取打包顺序的小费。
- Gas Limit 是允许消耗的上限；Limit 不足会 Out of Gas 并回退。成功交易按实际 Gas Used 结算；**失败/回退交易仍消耗已执行的 Gas**。
- Gas 波动直接影响执行：Gas 战（100+ 机器人竞争导致 Gas 超过价差）、PGA（优先 Gas 拍卖：提交初始报价→监听竞争→加价替换→重复直到确认）。
- L2 之间 Gas 几乎可忽略（$0.02 量级），真正大头是桥/协议的比例费；但以太坊 L1 单次 Gas 可达 $10–50，能直接吞掉价差。

#### 报价 vs 成交

核心链条：**看见价差 ≠ 获得同口径可执行报价 ≠ 两腿都能成交 ≠ 扣除完整成本后赚钱 ≠ 可以长期重复**。Displayed Price（显示价）、Quoted Price（报价）、Executable Price（可执行价）、Realized Price（实际成交价）不能混用。

- **边际价格不等于成交均价**：AMM 沿曲线成交，页面显示 3,000、实际均价 3,300；订单簿则逐档吃单。计算必须用固定输入数量、真实可执行报价，不能用中间价或"最新成交价"。
- **报价有时效性**：实测同样参数相隔一天的 Quote 完全不同（工具 Eco→Relay、7s→2s），报价会过期，必须实时查询 + 重新确认（Re-quote），不能把历史 Quote 当现价。
- **报价可能被污染**：某报价源自报买价卖价交叉 +44.5 bps（"低买高卖自己"），toAmount 系统性高估；聚合器的"最优路由"可能被乐观报价源污染。验证手段：**同链买入后立刻卖出的往返必然亏掉双边成本，任何正值都意味着报价体系自相矛盾**。
- **费用是否已含在报价里**：LI.FI 的 toAmount 已含 DEX 手续费、价格冲击与协议费，不可重复扣除；交易页面的 Transaction Fee 只是 Gas 费，不会单独列出 LP 费。
- **广播 ≠ 进入区块 ≠ 确认 ≠ 最终化**。钱包显示"已发送"不代表成功；Mempool 不是全球唯一订单簿，各节点看到的待处理交易集合不同；交易失败也会扣 Gas。跨链要分别确认源链交易成功、桥消息确认、目标链到账，不能只看源链。

#### 执行要点

**交易顺序与抢跑**：区块生产者/构建者可决定排序、插入或取消交易。三种典型排序方式：

```
Frontrun：机器人 → 用户（抢先拿走已有机会）
Backrun：用户 → 机器人（利用用户交易后产生的新机会）
Sandwich：机器人买 → 用户 → 机器人卖（利用用户的价格冲击）
```

理想位置是"目标交易之后、其他竞争者之前"。抢跑手段：监控待确认交易（mempool），提高 Gas 费争取先打包；清算场景先于他人调用清算接口。**MEV 竞争成本**：Searcher 净收益 = 套利毛收益 - Swap 手续费 - Gas - 区块位置竞价 - 其他执行成本；Priority Fee 是竞争排序的成本，MEV 是特定顺序下可争夺的总机会价值。

**原子执行**：同链套利应打包为同一笔原子交易（内部多次 Swap，一次签名、一个 Nonce、一笔 Gas 结算）：

```
若最终收入 ≥ 本金 + 费用：全部执行；否则：整笔回滚
```

回滚避免持仓亏损，但**失败交易仍消耗 Gas**。两笔独立交易不具备共同回滚能力；同一区块里的两笔交易也不天然原子。外层合约捕获子调用失败不等于自动重试。

**失败与单边风险**：非原子套利最危险的失败路径是"CEX 腿已成交、DEX 腿回滚"，为消除方向性敞口需反向成交，承担两次手续费、额外价差和不利波动。跨链两端独立交易，任何一边失败、滑点或延迟都会形成单边敞口（如只买未卖则多持 ETH）。跨链套利更实际的做法是**预置库存**：两端各持资产与 Gas，同时完成两边交易，再用桥做库存再平衡——注意 Opportunity PnL ≠ Cycle PnL，后者必须包含恢复目标库存的成本。

**执行纪律**：操作前核对网络/代币/合约地址（同名资产可能是桥接版本）、比较多 DEX 真实报价、查流动性深度、看价格冲击与最低可获得数量、加总全部费用、将利润与最坏情况成本比较、设置合理滑点和交易截止时间、大单考虑 MEV 保护（私有交易通道、Flashbots Protect）、最小必要授权、签名前核对钱包弹窗、成交后在区块浏览器核对 Success/Reverted、实际到账与 Gas，并记录真实收入与失败成本。**只有净利润为正且能覆盖价格变化、MEV、合约和跨链风险时，才存在真正可执行的机会。**

### 3.2 盈亏平衡与实测


> 提炼自《链上套利残酷共学》学员打卡分片 2（20 余条笔记），综合多条打卡的共同结论并去重，仅收录文件中出现的内容。

#### 一、成本构成与「拆账」意识

成本项全集：Gas、协议费/DEX 手续费、桥费、滑点与价格冲击、延迟成本、失败交易成本、资金占用成本（含库存再平衡、对冲成本）。

- **费用必须拆到明细再下结论**：LI.FI 对所有 API 报价加收 0.25%「LIFI Fixed Fee」（feeCosts 明细实证，同链与跨链均有）。曾有人把 0.25% 当成「桥费」，实为平台费——桥真实费率仅约 0.01% + 中继 Gas，真实往返摩擦约 0.02–0.05%。差一点就把错误的成本模型刻进策略。
- **平台费按比例（约 0.25%），Gas 基本固定（约 0.25 美元）**，所以交易越小越不划算；一笔交易总成本约吃掉 0.5%，价差低于 0.5% 做了也是白做。
- **资金占用是隐性最大成本项**：0.3% 的跨链价差若需在两条链各预置全额资金、6 小时才周转一次，年化会被稀释到聊胜于无；真正的杠杆点在抵押品能否复用。

#### 二、净收益公式的多种表述

主线公式（多篇打卡一致）：

```text
预期净收益 = 价差收益 − Gas − 协议费 − 桥费 − 滑点/价格冲击 − 延迟成本 − 失败交易成本 − 资金占用成本
```

其他表述：
- 简化版：净收益 = 表面价差 − 手续费 − Gas − 滑点 − 价格冲击 − 失败风险 − 时间/资金占用成本
- 路径成本口径：路径成本 = 输入资产价值 − 预计到账资产价值 + 未包含在报价中的额外 Gas；成本率 = 路径成本 ÷ 输入资产价值
- 规模门槛口径：本金 ×（价差 − 费率）> 固定成本（主要是 Gas）——价差 1%、费率 0.5%、Gas 2 美元时本金需 > 400 美元
- 跨链保守下界：净利润下界 = 目标链 minOut − 源链 maxIn − 两边 Gas − 再平衡摊销 − 对冲成本 − 失败与滑点缓冲
- 完整式：净收益 = 可执行价差收益 − 全部显性成本 − 隐性执行成本 − 风险缓冲

**防重复扣费**：每个成本项在账里只能出现一次。聚合器到账量已含 DEX 手续费、桥费与部分价格影响，feeCosts 等字段是归因拆解，不是再减一遍；不同聚合器口径不同。

#### 三、滑点详解

- **AMM 定价**：x×y=k，价格由池子储备决定；手续费先扣——10,000 USDC 按 0.3% 扣 30 USDC 后，约 9,970 USDC 才参与定价。交易越大 → 池子比例变化越大 → 平均成交价越差（价格冲击）。
- **价格冲击 vs 滑点**：价格冲击是自己的交易改变市场价格；滑点是预期成交与实际成交的差异（含报价后他人抢先、区块拥堵、机器人抢先改变池子状态）。
- **屏幕价是边际价格**：必须用准备实际投入的金额取报价；小资金能赚的机会，大资金未必能赚。
- **池子深度**：深度越浅、交易越大，滑点越大；屏幕有价差不代表能成交足够金额。深度要看「净深度」——扣掉自成交、循环挂单与窄价带 JIT 流动性，TVL 与可执行深度常差 5–10 倍。
- **最优交易规模**：金额太小利润盖不住 Gas；金额太大滑点与深度吃掉利润。
- **滑点容忍度 ≠ 固定成本**：0.5% 只是允许偏离的上限，超限交易通常失败，但仍可能损失 Gas。

#### 四、Gas 详解

- **概念**：gasUsed（实际消耗）、gasLimit（上限，不足则失败且已耗费用不退）、gasPrice、effectiveGasPrice；交易费 = gasUsed × effectiveGasPrice。发送方总支出 = Value + Transaction Fee。
- **失败交易也耗 Gas**：链上已尝试执行并消耗计算资源。
- **L1 vs L2**：以太坊主网 DEX 间套利 Gas 约 $15–30，L2 明显更低；盈利资金门槛约为 L1 > $100,000、L2 > $10,000。
- **其他**：Gas 随跳数线性上升（三角套利三次手续费 + 三次滑点叠加）；跨链需在目标链预留 gas token，否则可能失败；approve、两边链的原生 ETH 需单独记账。

#### 五、报价 vs 实际成交

- 报价是**瞬时快照**：2 分钟后重新请求金额就变，套利窗口很短；「锁定报价」= 可成交快照（有 TTL），不是永久锁价。
- **报价 ≠ 成交**：证据链分四层——观察 → 报价 → 结算 → 重复；提交成功 ≠ 最终到账 ≠ 净收益。聚合器报价含路由 spread，不等于市场真实执行价（「连屏幕成本都可能是假的」）：LI.FI 比 Curve 直达贵约 0.68%（规模无关，≈3× 固定费复利），用 eth_call 直读合约可拆穿报价水分。
- 同币种跨链必须用 **token 口径**而非 USD 口径：同一 USDC 两条链的预言机价差 8.37 bps 是噪声，不是成本也不是机会。
- `toAmountMin == toAmount` 表示确定性报价（intent/RFQ），滑点风险为零，但存在不成交风险；AMM 路由的 to_min 严格小于 to_amount。
- 最优报价 ≠ 最高净收益；路径随交易规模动态变化。

#### 六、执行要点

- **抢跑与排序**：DEX 内/间机会常被 searcher 在同一区块抢先；三明治攻击先插队推高价格再卖给你，滑点设大等于送钱。Mempool 是待确认交易的公开暂存区（约 12–15 秒一个区块、约 200 笔容量），按 Gas 竞价排序，是 MEV 温床。Flashbots 私有通道把公开抢跑变成「密室拍卖」（Searcher/Builder/Proposer 生态），私密性有价格且非绝对。
- **原子性**：同链可一笔原子交易闭环（全成或全败，不留单边仓位）；跨链非原子，须考虑到账时间、目标链价格变化、桥可靠性。闪电贷借-用-还须在同一笔交易内完成，还不上整笔回滚（Aave 费用约 0.05%–0.09%）。
- **失败控制**：明确失败条件与最大可承受损失；检查失败后是否留下单边仓位。区块确认拆四段：信号观测 → 决策 → 打包 → 最终性，跨链中对手链 finality 常是最大项。
- **执行检查表**：源/目标链、token 地址、路由池、两边 block number、amountIn/minOut、gas 估算、报价年龄、库存状态、再平衡摊销、保守净利润下界。真正的壁垒是精确报价、低延迟、Gas 管理、库存管理与失败控制。

#### 七、盈亏平衡分析与实测数据

- **27.34 bps 门槛**（LI.FI 费 25 bps 占 91% + Gas 2.34 bps 占 9%）：USDC 跨链偏离通常只有个位数 bps，意味着该路径稳定币套利结构性不成立。
- **三角环实测**：LI.FI 聚合净收益约 −0.72%，Curve 直达仅 −0.045%；Across 往返摩擦约 0.02–0.05%，跨链盈亏平衡线低一个数量级。
- **跨链三资产实测**（2 小时 × 5 链）：WETH 价差均值 0.19%，仅 19% 采样点过 0.25% 桥费阈值，净利始终为负；WBTC 价差 0.36% 但无桥可走（NO QUOTE）；LINK 价差 1.11%→1.49%，理论最大净利 +1.15%，窗口约 1 小时即被抹平。三种失败模式：价差 < 桥费、有价差无桥、窗口太短。
- **Gas 淘汰率**：毛正收益 2,169 条，扣 Gas 后仅 531 条，Gas 淘汰约 75.5% 的「机会」。
- **算例**：屏幕价差 0.30% − 手续费 0.10% − 滑点冲击 0.12% − Gas 与失败 0.06% = 净收益仅 0.02%，不足以覆盖模型误差；另一例 100 USDC 毛收益扣 30+15+25+20 后只剩 10 USDC。
- **经验阈值**：表面价差 20 bps 光服务费就亏，40 bps 扣完也可能没利润；表面收益小于 Gas + 滑点 + 桥费两倍时不做（需留失败与延迟缓冲）。盈利资金门槛 L1 > $100,000、L2 > $10,000。

### 3.3 策略成本测算案例


> 综合分片 3 打卡（Day 1–2：LI.FI 跨链报价、AMM、成本账本、跨所套利、接针/狙击等案例）共同结论，去重整理。核心主线：**屏幕价差只是候选信号，扣除全部成本后仍为正的闭环交易才是可执行机会**。

#### 一、成本构成：完整清单与分类

#### 1.1 完整成本清单

综合多条打卡，成本项包括：

- **交易费用**：DEX/聚合器/协议费（如 LI.FI 固定服务费 0.25%）、跨链桥费、交易所双边开平仓手续费、代币买卖税、Router 费用；
- **Gas**：双链/三段 Gas，单独用原生币支付；
- **滑点与价格冲击**：含 MEV 夹心滑点、给区块构建者的小费；
- **执行相关**：执行延迟、报价过期、到账期间价格变化、失败交易成本（失败仍耗 Gas）；
- **资金相关**：资金占用与对冲、融资/借币利息、资金费率（净息差）、再平衡损耗、异常敞口损失、调仓/库存复原成本；
- **尾部风险准备金**：安全垫（haibian-slowly）。

#### 1.2 成本分层与"不重复扣费"

- **三类摩擦成本**：手续费、滑点、Gas 是三个不同的东西，构成成本模型三大件。
- **显性 vs 隐含**：聚合器固定费是"明确收的"；Gas 单独用原生币付、不从换币产出里扣；价格冲击（+池子手续费）**已含在 toAmount 报价里**。
- **已包含不重复扣**：已包含在 LI.FI 到账估算/Quote 输出中的费用不能重复扣除。
- **账本纪律**：Cost Ledger 是 PnL 的唯一 Owner；缺失成本标记 incomplete；不同 Token 无 FX Evidence 时拒绝相加。
- **CEX vs 链上**：CEX 订单簿零 Gas，主要成本是 Taker/Maker 手续费；链上需扣 Gas、MEV 夹心滑点及 Bridge 手续费。

#### 二、净收益/经济利润公式的多种表述

- **通用净利润**（cfanboy）：

```text
净利润 = 最终资产价值 - 初始资产价值 - 交易手续费 - Gas - 滑点 - 跨链成本 - 融资成本 - 失败成本
```

- **预期净收益**（Quinn）：

```text
预期净收益 = 价差收益 − Gas − 协议费 − 桥费 − 滑点与价格冲击 − 延迟成本 − 失败交易成本 − 资金占用成本
```

- **可执行净收益**（Zhou Junjie）：`理论价差 - Gas - 滑点 - 协议费 - 桥费 - 执行延迟成本`。
- **可实现净利润**（haibian-slowly）：`最终可变现收入 - 买入成本 - dex/借贷/跨链等费用 - gas - 滑点与价格冲击 - 资金占用与对冲 - 失败期望成本 - 尾部风险准备金 > 最低利润阈值`。
- **Break-even**（Paxon Qiao）：`最低所需价差 = LI.FI费 + Bridge/DEX费 + 双链Gas + 滑点 + Price Impact + 延迟/失败成本`。
- **跨所价差套利**（jinnzy）：

```text
价差收益 = 入场两腿价差 - 离场两腿价差
净息差 = 两腿收到的资金费 - 支付的资金费 - 借币利息
净收益 ≈ 价差回归收益 + 净资金费 - 借币利息 - 双边开平仓手续费 - 滑点 - 再平衡损耗 - 异常敞口损失
```

- **三层 PnL 口径**（Nothing）：Gross → Atomic/Local → Inventory Cycle PnL。

#### 统一计价单位与计算口径

- 必须**固定状态和输入规模**，把 Gas、未嵌入输出的费用、滞留资产和失败损失**统一到一个计价单位**后才能判断净值；可选某资产为唯一计价单位，确认输出已含池手续费与价格影响、避免重复扣费。
- 金额与盈利判断用整数最小单位 + `Decimal`/`U256/I256` 有理数汇率，**不用浮点数判断盈利**（Nothing、Neo.Yun、Liang）。
- 先确认 decimals：BSC USDT 18 位、Ethereum USDT 6 位，`fromAmount` 必须是最小单位整数，搞错差 10^12 倍。
- 对真实历史交易，把 receipt、logs、余额差和固定区块分开记录，区分直接事实与推导结论，正确计算实际 Gas。

#### 三、滑点与价格冲击

- **机制**：AMM 无订单簿、无对手方，恒定乘积 `x·y = k`；`amountInAfterFee = amountIn·(1-fee)`，`amountOut = y·amountInAfterFee/(x + amountInAfterFee)`。大额交易沿曲线移动更远，平均成交价变差。
- **流动性决定滑点**：池子越浅、成交额占池规模比例越大，滑点越高；"页面便宜、买进去价格马上被推高"是假机会典型来源。
- **分批不减少滑点**：池子不变且无其他交易时，分批交易不会自动减少最终滑点。
- **滑点没有凭空消失**：多付的价值重新分配给 LP——手续费归 LP，价格冲击体现为池子价值变化，之后由套利者把价格拉回。
- **滑点容忍度是执行边界**：可获得资产低于最低可接受值时交易回滚；容忍度设过大会放宽最差成交结果、增加被夹（sandwich）风险；回滚仍消耗已发生的链上计算 Gas。
- **两次独立 quote 的陷阱**：第二次 quote 往往基于买入前的池子状态，而真实卖出发生在买入已改变池子状态之后；应连续模拟买入+卖出。

#### 四、Gas

- **定义与支付**：Gas 是购买区块链计算和区块空间支付的费用，单独用原生币支付。
- **Gas 与失败**：交易回滚撤销状态变化和日志，但**已消耗的 Gas 不退还**；失败通常也耗 Gas；顶层回执成功不代表所有子调用都成功。
- **Gas 与延迟**：Gas 设置过低造成的等待可能间接放大价格变化；交易要经历发送→打包→区块确认，期间别人可能已先完成套利吃掉价差。
- **跨链多段 Gas**：候选计算要扣三段 Gas（买入、跨链、卖出）；双链 Gas 是盈亏平衡价差的一部分。
- **Gas 竞争**：闪电贷路径机会可能被同行出更高 Gas 抢走；有案例把 max priority fee 设成与项目方一致（0.0011025 Gwei）逆向建模对方行为并抢先狙击。

#### 五、报价 vs 成交

- **报价是可执行样本**：由时间、链、资产、交易规模、流动性和路由共同决定；不同规模可能走不同路由、产生不同价格冲击。
- **聚合器不保证成交**：Quote 只是某时点、金额和约束下的预计路线；报价生成到被打包之间，池储备、市场价格和网络拥堵都在变化。
- **verified ≠ 可成交**：bNVDA vs NVDAx 表面 7% 价差经 quote 验证为无流动性假价差；假机会还包括报价更新慢、目标链缺卖出流动性、过期报价、低流动性、资产不等价。
- **单腿报价不能证明套利**：必须补齐卖出腿、看完整两腿闭环和净收益，并用保守到账 `toAmountMin` 检查。
- **跨链 Quote 不是结论**：目标端要有高于已知成本的可成交净溢价才算数；报价是否过期是必查项。
- **同币异名先核验资产**："映射资产"≠"可直接吃的价差"；需交叉核验合约绑定与改名历史，扣两端滑点、代币税、跨链费、双端 Gas 与资金占用。
- **数据时效性**：不同数据源的 DEX 价格时间不一致，难以精准对比实时价差。

#### 六、执行要点

- **原子 vs 非原子**：原子套利在一笔交易内完成——不担长期价格风险、只需 Gas 或闪电贷、失败不部分成交但耗 Gas、竞争激烈易被抢先；非原子套利需多链预置库存——承担价格变化与到账延迟风险、资金周转低，竞争较小但复杂度高。
- **多链预置库存 + 事后再平衡**：价差出现再临时跨链往往赶不上窗口；成熟做法是两端先持仓，LI.FI 只用于低频库存再平衡。难点不在发现价差，而在**价格窗口关闭前完成跨链到账并落袋**。
- **出手量优化**：闪电贷不关乎本金，出手量可经 Quote 多次探价择优；路径覆盖度与扫描成本存在权衡。
- **可执行系统模块**：链上数据/RPC → 池/账户/预言机/桥状态索引 → 资产身份映射 → 机会发现 → **最优输入量+全成本+风险调整EV** → **本地fork/目标区块精确仿真** → 交易或bundle构造与多路提交 → 包含/回滚/跨链最终性跟踪 → 库存、PNL、风险限额、告警与复盘。
- **监控流程**：监听新区块/池状态 → 读取池状态 → 计算具体金额闭环路线 → 扣除 Gas 等成本 → 模拟交易 → 记录信号和失败原因；第一版追求"小而准确"，能解释每个信号、识别假机会。
- **证据标准**：阶段性盈利只是候选信号；数据链、执行链、成本链都闭合才谈可重复的 edge。
- **候选机会十问**：是否同一资产/合约地址？报价对应多大金额？流动性是否足够？能否原子完成？否则承担多久价格风险？报价是否过期？扣完全部成本还剩多少？失败最大损失？为何未被其他机器人消除？我的优势是什么？——最后一问最重要。
- **风控前置**：即时退出成本越高，入场阈值应越高，并限制最大单腿亏损；无法可靠模拟的币直接排除；接针是逆向选择——针与暴跌事前无法区分，需小资金撒网、只做有锚定的热门币、单边止损。

## 第 4 章 · 套利策略类型


#### 套利的本质

**定义**：同一资产在不同市场（DEX/CEX/链/交易对）或不同时间存在价格不一致时，低买高卖、把价格拉回平衡的行为。利润有真实出处：大额交易者快速成交付出的滑点溢价（套利者替他把价格抹平、分走一部分），或非理性恐慌者的割肉钱（如 UST 脱锚 0.9 买入等回归）。

**价差为什么长期存在**：链上不是统一市场——流动性割裂、信息传播有限、用户行为不同、链间摩擦（桥延迟、Gas、提币成本）；套利者还没修复时，价差就在那里。

**链上套利 vs 传统套利**：从"无风险"到"高度对抗"（发现价差→提交交易→被抢跑/被夹击/Gas 战争→大概率失败）；从"信息优势"到"执行优势"（mempool 公开，谁执行最快谁赚钱）；从"人工监控"到"算法战争"。

**核心公式**：

```
净收益 = 价差 - DEX手续费 - Gas - 桥费 - 滑点(Price Impact) - 执行延迟损失 - 失败成本
```

屏幕价差是"毛价差"，扣完全部成本仍为正才是机会；等于它白干，小于它越套越亏。套利本质 = 价差 + 时间窗口（窗口只有几秒时，慢就是死）。社群核心洞见：**套利不是"找价差"，而是"找摩擦"**——价差会被竞争压缩到成本附近，能长期存在的收益背后是某种无法自由套利的约束（信息摩擦、做空限制、机械订单流、资本门槛）。

#### 各策略详解

#### 1. DEX 内套利
- **原理**：同一个 DEX 内，同一资产在不同池/不同费率档位（如 Uniswap V3 0.05% vs 1%）定价短暂偏离，或多跳合成路径与直接池价格不一致（USDC→ETH→DAI vs 直接 USDC→DAI）。
- **利润来源**：大单打了 A 池、B/C 池还没反应；各池流动性深度、价格更新速度不同。
- **执行**：多跳路径可在**同一笔原子交易**内完成，执行风险相对低，但机会稍纵即逝。
- **风险/死法**：池子浅→价格冲击大，理论利润装不下交易量；单池利润极薄需高吞吐；被抢先、滑点、Gas 白付。
- **适合谁**：理解门槛低，适合新手建立概念，靠它赚钱则需高频竞争能力。

#### 2. DEX 间套利（含原子套利）
- **原理**：同一链上不同 DEX（Uniswap vs SushiSwap）同一交易对价差，便宜池买、贵池卖，即 A-B-A 双边环。价差来源：流动性不同 + 交易流向不均（某 DEX 被大买推高、另一 DEX 没动）+ 套利者没来得及修。
- **利润来源**：两 DEX 报价不一致；同链可打包成**一笔原子交易**（闪电贷或无本金），不成功整体回滚。
- **风险/死法**：双向 price impact + 双边手续费，0.5% 屏幕价差大概率亏；广播后会被 mempool 里的 searcher 抢跑，必须经 Flashbots 等私有通道发送；主流币价差 <0.1% 已被毫秒级吃完，只有长尾资产（小市值、新 LP 对）3-15% 才可能有机会；0.3% 以下价差基本不赚钱。
- **适合谁**：三层竞争——毫秒级（自建节点+Flashbots）、秒级（量化团队）、秒到分钟级（公共 RPC 个人）。公共 RPC 抢主流价差"基本是送"，个人只在长尾/新 DEX 未被机器人接入的窗口有戏。

#### 3. CEX-DEX / 跨所套利
- **原理**：中心化交易所与链上（或两个 CEX 之间）同一资产价差。典型流程：CEX 现货买入+做空对冲（套保单）→ 链上买入 → 交易所卖出 → 重复（链上买入量不可超过开空量）→ 最后冲回交易所卖出现货并平空。
- **利润来源**：价差（如美股上新、新闻驱动的新上所价差 >2%，约 10 分钟收敛）；典型利润率约 5-50 bps。
- **风险/死法**：转账/提币延迟与手续费；需足够保证金防强平；价差收敛前资金在途。对敲/冲提本质是两边仓位管理，资金占用大、容量不大。
- **适合谁**：需要 CEX 订单流数据能力；新手可从小额、简单跨所价差开始练手。

#### 4. 跨链套利
- **原理**：同一资产在不同链（ETH on Arbitrum vs Base/Polygon）价差，低价链买入→桥→高价链卖出（搬砖）。价差来源：用户群、流动性、资金分布不同 + 桥延迟。
- **利润来源**：跨链价差，前提是价差 > 桥费 + 时间成本 + 滑点。
- **风险/死法**（四大风险）：
  1. **时间风险**：跨链不具原子性，桥确认要 1-5 分钟甚至更久，期间价差可能已被抢走甚至反转为负——"Quote 盈利"≠"资产到达时机会还在"；瓶颈不是桥费，是等待期间的价格波动。
  2. **资产身份风险**：USDC 与 USDC.e、原生 vs 桥接 vs 包装是不同资产；须核对地址、decimals、所在链、版本，否则价格比较失真。
  3. **路径选择风险**："输出最多"的 Route 不一定最合适——可能更慢、步骤更多、失败后更难恢复。
  4. **库存风险**：发现价差再临时跨链注定输在起跑线上。
- **正确打法**：把"抓机会"和"跨链调仓"拆开——提前在多条链预置资金，价差出现时两端同链交易（几秒），之后用 LI.FI 做库存再平衡（选不要求低延迟的时段）。
- **适合谁**：难度最高的一类，但桥的 finality 按分钟算，竞争烈度低于 DEX 间，是个人"有机会但依赖工具"的方向。

#### 5. 三角套利
- **原理**：A→B→C→A 闭环，利用三种资产两两汇率环路不平衡：

```
r1 × r2 × r3 > 1（扣费后）即有套利空间
```

典型路径：USDC→ETH→WBTC→USDC；任何多角环都必然存在一个三角套利；可在单笔原子交易内完成（同一 DEX 路由器），可用图搜索发现路径。
- **利润来源**：汇率环不闭合（绕一圈不等于 1）。
- **风险/死法**：三次 swap fee + 三次滑点 + Gas 叠加；V3 集中流动性之后"几乎绝迹"（三笔摩擦成本必然大于微弱价差）；必须原子执行否则中间持仓被夹；公式只是初筛，需按池子实际报价测试。利润率约 1-10 bps。
- **适合谁**：认知价值高、赚钱难度大；纯算法驱动，无 MEV 经验者多作为理解练习。

#### 6. 稳定币脱锚/回归套利
- **原理**：稳定币（USDC/USDT/DAI/FRAX）短暂偏离 1 美元时低买、等回归高卖。三种形态：①脱锚套利——折价买入后经官方兑换通道（如 Maker PSM）1:1 换出硬锚资产；②池失衡套利——Curve 3pool 某币占比异常→折价，存入低估币、取出高估币（常配闪电贷单笔完成）；③利率/收益套利——借低息存高息；生息稳定币（Ethena USDe：持现货+做空永续赚基差）。
- **利润来源**：市场恐慌情绪 + 锚定回归机制（本质是赌稳定币不违约）；跨链稳定币价差几十 bps。
- **风险/死法**：⚠️ 最大陷阱——脱锚可能是**真的**（挤兑、暴雷），此时"价差"是真实风险折价不是套利，买入=接飞刀；必须区分"暂时性偏离"与"真实破产"（UST 永远不回锚；usd1 案例赚钱的是打旧预言机窗口而非接脱锚）。竞争最激烈，散户无法规模化。
- **适合谁**：波动低、数据易获取，社群推荐为新手第一研究方向，但只宜小参与、事件驱动。

#### 7. 清算套利
- **原理**：借贷协议（Aave/Compound/Maker）中抵押品跌破门槛（健康因子 <1）时，清算人替借款人偿债，以折扣价（常 5-8%，3-15%）拿走抵押品；可结合闪电贷借钱→清算→还钱，零本金。
- **利润来源**：清算奖励（协议发的"链上赏金"），利润 = 清算奖励 - Gas - 竞争成本。
- **风险/死法**：本质是 **Gas 竞拍**，谁出价高谁拿下；需极低延迟监控+自动化；抵押物本身可能是坏资产、价格反弹、被抢跑。
- **适合谁**：需监控能力，竞争烈度略低于 DEX 间套利，但仍属专业 MEV 领域；新手宜观察复盘。

#### 8. MEV：三明治与抢跑
- **原理**：交易先进 mempool 再被打包，排序产生价值。三明治：监控大额买单→高 Gas 抢跑买入推高价格→受害者高价成交→尾随卖出收割；抢跑套利：克隆别人的套利交易并加 Gas 抢先截走利润；backrun：大额交易后反向操作吃价格回归（相对温和）。
- **利润来源**：受害者的滑点损失 + 排序权。Gas 战：相同 nonce + 更高 gas 替换交易形成 Priority Gas Auction；现代竞争转向私有 relay/builder 的 bundle 竞价。
- **风险/死法**：与顶尖 searcher 拼低延迟基础设施；绝大部分利润归验证者和头部搜索者，个人买现成 MEV 工具往往沦为"接盘"（服务器+订阅费却不盈利）；sandwich 是掠夺性的，有伦理红线，社群不建议做。
- **适合谁**：专业玩家领域；个人理解机制即可（防御视角价值高），不建议作为入场方向。

#### 9. 统计套利与进阶类型
- **统计套利（配对交易）**：两标的汇率围绕中轴波动，偏离即交易、回归平仓，靠"概率+重复"赚钱。案例：存储赛道 MU 回调 10% 以上做多 MU、做空其他，等回归中轴；弱势标（Skhynix）偏离阈值更大、仓位更小。方法论 = 研究汇率波动规律 + 叠加仓位管理（纯信号不构成策略）。
- **汇率对套利**：XAUT-CL 战争时做多（CL 涨→汇率变小→做多等回归）；MU/SKHNYX 均值回归。
- **币股套利**：传统金融上链初期（蓝海、深度大、可大仓位）：正股 vs 杠杆 ETF、不同发行商（UNITREE 的 PARA vs XYZ）、ADR 价差（SKHYNIX vs ADR SKHY：-3%→-35%）。
- **可赎回资产折价套利**：固定赎回价 vs 市场价差异：stETH/ETH、stATOM、sUSDe/USDe；质押代币（ETH/stETH）池兑换比 vs 合约兑换比。
- **资金费率/期现套利**：正费率：做空永续+买现货；负费率：做多永续+借币卖；跨所费率差（A 所 +0.05% 开空、B 所 -0.02% 开多，多空等价值对冲价格波动）；结算周期不同（8h vs 2h）选在非结算周期开仓。**delta-neutral（等价值对冲）是费率套利的生死线**。
- **暗池套利**：协议自开未开源池，聚合器不计算其路径，价格与其他池不一致。
- **闪电贷**：无抵押借款，同一区块内连本带息归还否则整体回滚；零本金放大收益，成熟 MEV 机器人的标配。
- **策略三分类**：资金费率赚时间差、LI.FI 赚空间价差、solver 赚信息+执行优势（统计套利高频可重复=已被竞争压缩杀死；结构性 Alpha 低频长尾+有约束=可持续，见"找摩擦"）。

#### 策略选择建议（社群观点）

- **新手路径**：一个个学、先搞透一个；首推 DEX 套利、稳定币套利、三角、清算、Funding 套利（偏策略/分析取胜，不拼基础设施）。
- **竞争格局**：专业 MEV 团队（Flashbots/Eden/bloXroute，个人胜算≈0）→ 量化基金做市商（Jump/Wintermute，胜算极低）→ 独立开发者（有限，聚焦长尾）→ 新手（大部分在亏，Gas>收益）。
- **个人可能的优势**：长尾市场（利润 <$100 大玩家不屑）、新兴链/新 DEX 上线 2-4 周窗口、组合创新策略（闪电贷+跨 DEX+清算）、垂直细分（只做稳定币/只做某条链）、时区差。
- **时间窗口较长的方向**：跨链（分钟级）、清算（需监控但竞争不极端）、稳定币脱锚（低频但持续久）、数据分析。蓝海：新公链、创新 AMM、GameFi、RWA/币股、社交代币、Intent-based 交易。
- **普遍建议**：先建监控体系再谈执行，先看清战场再上；第一年目标是不亏钱，长期目标是建立细分市场的信息优势；"大部分人在前 6 个月是亏钱的，不要指望暴富"。

#### 常见误区

1. **屏幕价差 = 可执行机会**：毛价差必须扣光手续费、Gas、桥费、滑点、延迟、失败成本仍为正才成立。
2. **价差为正就能做**：双向 price impact + 双边手续费会把 0.5% 的价差吃掉；主流币 <0.1% 价差基本无利可图。
3. **稳定币脱锚就是送钱**：脱锚可能是真出事（破产、挤兑），那是风险折价不是套利，买入是接飞刀。
4. **"Quote 盈利" = 资产到达时还盈利**：报价单只证明过去那一刻可行；跨链慢就是死。
5. **输出最多的 Route 最好**：可能更慢、更容易失败；要选"扣完时间成本后真正最赚、最不容易失败"的。
6. **三角套利环乘积 >1 就能做**：公式只是初筛，池子非线性报价与三次摩擦往往让理论利润归零。
7. **忽略失败成本与资金效率**：大部分机器人失败正因忽略滑点、Gas、失败成本、资金占用；"现在有机会"不是有效信号，应输出"可执行规模"（如 $3k 以内有 2.1% 净空间）并连续 N 点越线确认，否则多是 stale price 假信号。
8. **套利是"无风险"的**：链上套利从"无风险"变成了"高度对抗"，本质没有无风险套利。
9. **买现成 MEV 工具就能赚钱**：公开简单机器人已基本赚不到钱，利润被低延迟+高资本+私有通道的专业玩家拿走。

## 第 5 章 · 工具、工作流与风险风控


> 综合自『链上套利残酷共学』打卡笔记（06 工具与工作流 / 07 风险风控与经验 / 08 其他），仅收录笔记中出现过的知识。

#### 工具链详解

#### LI.FI（跨链聚合器）
- **用途**：跨链 Swap 时提供最优路由、报价及每一跳执行细节；可类比 web2 的携程聚合平台，是"免费的成本结构教材"——观察它"什么规模选什么桥"就是在学成本模型。
- **用法**：API 用 `/v1/quote` 和 `/v1/advanced/routes`（只读探针脚本即可，不签名不发交易）；注册 API Key 后频率限制放宽（无 key 约限速 1.2s/次）；可用 MCP 接入 Agent；对比同一资产、不同金额、不同链的 Quote/Route，观察桥、DEX、中间资产、费用变化。
- **技巧与实测**：① 路由随规模切换——ETH→ARB 在 $100 档走 across，$1k 以上全走 eco，每条路径有各自的经济规模区间；② eco 桥费线性约 0.25%，不随规模摊薄，能摊薄的只有 Gas（L1 出发 Gas 约 $0.08–0.11）；③ 往返闭环净收益 ≈ 单程费率×2，稳定币搬运要等价差 > 2× 单程成本；④ 实测 USDC 跨链显性成本约 26bps（服务费 25bps + Gas）；⑤ 跨链 Route 实时变化，速度与成本需权衡，套利窗口只有几秒，成熟团队预置多链资金而非临时跨链。
- **局限**：通过它直接发现套利机会概率不大，更多用于利润最大化/数据对比；`/v1/tokens` 列出的币种常有价无路（查 quote 无可兑换路径），需再筛选；有同学认为跨链 swap 机制复杂，建议两条链分别 LI.FI 报价、自己跨链，更符合套利流程。

#### Hermes Agent
- **定位**：自主 AI Agent，适合通用性工作（研究、监控、自动化、复盘），区别于偏编程执行的 Codex；内置闭环学习引擎、上下文微压缩、编程式工具调用、事实核查引用、多端 Gateway（Telegram/Discord/CLI）。可部署在 VPS/服务器长期运行。
- **用法**：① 研究：找资料、解释概念、拆任务；② 监控：定时任务每小时扫描、信号推送 Discord/Telegram；③ 自动化：写数据采集/回测/Paper Trading 脚本；④ 沉淀：学习记录、信号告警、例行检查统一走同一 Agent 工作流（如接入 Intensive CoLearn API 自动打卡、用 Telegram Topic 分区管理"套利学习/数据/打卡"）。
- **配置技巧**：独立 Profile（如 `camp`）+ 独立工作区（inbox/learning/outputs/handoffs/scratch）+ `AGENTS.md` 划定边界；审批模式 manual，不用 sudo/--yolo；memory 的"工具启用"与 `memory_enabled` 配置是两套机制（Blank Slate 会一并关闭）；在 memory 写明边界（"已有计划、不要排路线图"）能显著约束行为——设边界比加能力更影响 Agent；可调大最大会话轮数/预算减少打断。
- **安全架构实践**：AI 与执行权限分离（advisory、不签交易不转资金）、Registry 与 Policy 分离、默认关闭模型服务、Docker 隔离（非 root、只读根文件系统、删 capabilities、no-new-privileges、不挂 socket/.ssh/.env）、服务间隔离网络、未注册/未启用 Domain 拒绝调用。

#### 链上数据工具
- **The Graph**：基于"图"结构对链上事件预索引，类似 Dune；比直接扫 RPC 方便按金额/时间维度聚合筛选，查询性能好、聚合度高。
- **Dune**：MEV/套利流数据分析常用路径为 Flashbots/mev-inspect 数据 + Dune 或自建；MEV 实时流公开站有 eigenphi.io、info.zeromev.org 等（Ethereum 走 PBS+builders+private orderflow，实时公开流少于 Solana）。
- **DefiLlama**：查各链 TVL、Net Inflows、Chain Fees、Chain Revenue、App Revenue、DEXs Volume、Perps Volume、Transactions。
- **其他**：ccxt（统一对接 CEX）、hyperliquid-python-sdk、web3.py、ib_insync（IBKR）、DEXScreener/GeckoTerminal（支持批量查价）、coinglass（资金费率）、taoli.tools（半自动对冲/提醒下单）、QQQ.BOT（跨所对冲执行引擎）、SlowMist MistEye-DepScan（依赖投毒扫描）。

#### RPC 节点
- 公共节点常有死节点且无提示（实测 22 轮挂 2 轮、9%），需健康检查与重试；公开 RPC 对 `eth_getLogs` 范围有限制、易 429 限流——逐区块查时间会触发限流，可用大区块间隔的 timestamp 锚点分段插值。
- 可用 RPC 直读池子 reserve 算价格与滑点（如 Raydium SOL-USDC：滑点=0.30% 手续费 + ~0.0015% 价格冲击）；Jupiter quote API 被墙且 v6 弃用，可改 Helius 等 RPC；基础设施建议 Alchemy/Infura。

#### 监控与信号
- **把一次性观察变成可重复流程**：固定节奏的采集器（如 LI.FI 报价每 60 分钟一轮，失败询价也记录——负样本同样是数据）；报价无异常的一天=没有窗口的一天，基线数据本身是有效信息。
- **最小信号管道**：先跑通"发现→记录→通知"（signal 模式、公共行情 API 不下单、每小时扫描、推送 Discord/TG），再谈策略。
- **常见监控指标**：资金费率（fundingHistory、正负费率、年化）、价差（双向、扣全部成本后净收益）、TVL/池子深度、成交量、仓位健康度（清算监控用官方 API 轮询+阈值，比 subgraph 稳定实时）、funding/OI 异动。
- **指纹法**：把假设缩成窄、便宜、可检测的信号（框架：假设→机制→区别特征→过滤器→探测→诠释），过滤器（对机制的深度理解）才是护城河。案例：周末（美股休市）+ 冷门股票永续 + funding 量级骤变/符号翻转 = 老鼠仓指纹；需链上异动→K 线→新闻三源交叉验证。
- **数据陷阱**：universe/ctx 数组按索引对应，zip 盲配对会标反；快照是时点数据；事件唯一键用 chainId+txHash+logIndex；fills 数≠去重交易数（一笔聚合交易可含多个 fill）；数据覆盖不全时监控系统要显示 backfill 起点/block lag/错误状态，查不到写 Unknown/Partial 而非 0。

#### 回测与模拟
- **四级验证**：回测→监控→Paper→小额实盘；先 testnet 后主网、先小额后大额。
- 用演示模式注入内存库只读运行；交易循环用环境变量开关显式开启，不开只跑行情不下单；空跑环境与真实资金完全隔离。
- 回测要含成本压力：手续费、滑点、价差再扩大 2 倍的压力情景；观察 30 分钟至一个结算周期，区分瞬时噪声与持续错位。
- 实测结论：纯资金费率套利扣成本后年化可能不到 3%；套利成立条件是候选收益在手续费、滑点、借币成本、资金占用、尾部风险之后仍为正——"屏幕价差"不等于"可执行净收益"。

#### 风险清单
- **跨链桥风险**：桥接 Gas+时间成本、资金沉淀周期（如 14 天解押）、桥机制复杂、流动性限制把大资金挡在外面。
- **单腿风险**：一腿成交一腿被拒（如 IOC 零成交拒绝），敞口暴露于单边波动；必须程序化阈值自动平仓，严禁手动扛单；单腿恢复不是备用功能而是核心能力。
- **价差发散**：极端行情（插针/宕机）下价差可能不收敛反发散；纯赌收敛属方向性投机。
- **资金占用**：费率套利持仓周期长、资金利用率低；跨所套利双边资金门槛高；利润缩水至牛市 1/10，冷门池容量小进场即破坏价差（策略具排他性，不可公开）。
- **滑点/MEV**：滑点容忍度越高越易被 MEV 收割（案例：74% 滑点巨亏）；大额交易前必须查池子深度；加滑点不能解决 IOC 拒单。
- **平台与宏观**：稳定币脱锚、CEX 暂停提币/下架、平台改规则（费率突变）、交易所信用、汇率错配（USDT 结算 vs 本地货币，案例亏 $6 万）、负费率难借币、ADL/强平破坏对冲（组合中性≠账户安全，另一所盈利无法补本所保证金）。
- **止损与仓位**：全局硬止损（如当日亏损/回撤达阈值即降级 OBSERVE_ONLY）；单腿恢复窗口"前 120 秒保收益、后 120 秒优先消风险"，分档余量（7.5bps 目标/20bps 恢复/50bps 紧急）；熔断按币种独立；减仓单永远发出、否决只压制开仓单；成交确认超时绝不重下（重下=对冲静默翻倍）；用联合 lot 步长与迟滞带防止在噪声上反复调仓。

#### 安全要点
- **钱包/密钥**：专用钱包、练习钱包与真实资金隔离；制定资金与授权红线；API Key 不开提币权限；必须留 Kill Switch。
- **授权风险**：approve 只改权限不移动资金；可结算上限受 min(钱包余额, allowance, 虚拟余额) 约束；虚拟余额可重复登记是资本效率来源也是回滚风险来源，授权与成交需对账。
- **假币/rug**：先核对标的合约（DEXScreener 查 ca）、处理交易所币种名称冲突（同名不同资产）；了解代币发射/迁移流程再参与。
- **供应链与服务器**：npm 依赖可能投毒，用 lockfile 锁版本、只装发布超 60–90 天的包；服务器装 fail2ban、关密码登录、最小暴露（实测 24h 被暴力破解约 6000 次，Lynis 55/100）。
- **AI/Agent 边界**：AI 不能调用钱包、签交易、转资金（执行权限默认 false）；Docker 隔离、审批 manual、AGENTS.md 约束；先用非主力机熟悉再上云。

#### 实操踩坑经验
1. 收益达标却不平仓：条件冲突（收益连续保持 1000ms、盘口年龄<250ms、被动盘口更新慢）——候选成熟后主动拉一次权威盘口重算再发单；实测 44 次确认仅 12 次成立，多数"机会"是旧行情幻觉；行情暂时不新鲜应跳过本轮而非停策略。
2. IOC 拒单后卡死：明确返回零成交拒绝是确定性终态，应直接进入恢复；请求超时/未知则必须继续查单查仓位；别用 client order ID 回查阻塞恢复；程序应以真实仓位/真实成交为最终依据。
3. 单笔金额太小 = 给 gas 打工（gas 占比 0.196% 吃掉全部利润空间）；利润必须覆盖 gas。
4. 公共节点死节点无日志提示；轮询实际耗时比设想慢一倍（1.9–3.9 秒/轮）；余额归零报"找不到余额"误导排障。
5. 限频与地区限制：LI.FI 无 key 限速、Binance API 用美国 IP 报 451、Jupiter API 被墙；数据服务商可能缺美股夜盘数据，接入前先测试。
6. 统计口径：fills≠交易数；逐区块查时间会限流，用大跨度 timestamp 锚点插值（仅用于匹配历史价格）。
7. AI 协作：给 AI 塞 ZIP/长上下文是 token 黑洞（烧光额度），用轻量脚本处理数据、AI 只做 review；AI 给的是基础能力，独特视角仍需自己把关；安装类踩坑：Hermes 网络安装失败、TelegramAdapter 崩溃 bug、memory_enabled 未开、Codex 适配层超时并误改 ~/.codex/config.toml（先备份可回滚）。
