## 一句话价值链

**独有订单流 → 构建者保留价值 → 利润 = 区块真实价值 − 次优出价**

## 四层供应链

```
订单流层 → 路由层 → 构建者层 → 中继/最终确定
```

### 1. 订单流层（交易从哪来）
- 组成：用户/钱包、dApps、求解器（solvers）、MEV 搜索者
- **两个定价市场**：
  - 纳入市场（inclusion）：交易能否进区块，EIP-1559 基础费（销毁）——所有用户付
  - 位置市场（position）：交易在区块的位置，优先费——只有争夺顺序的人付
- **位置市场是 MEV 的根源**：对共享状态的优先访问始终有经济价值；理性套利者愿付 ≈ 全部可捕获利润
- 普通转账付纳入费，套利者付位置费——优先费 = MEV 利润的显式报价

### 2. 路由层（谁能看到交易）
- 公共内存池：可见 = 可被复制/backrun/三明治
- 私有 RPC / OFA：减少信息泄露，**返还部分被提取价值**（Part I：OFA 固定返 90% 优先费）
- Builder RPC 直连：细粒度排序约束、条件执行、延迟、回扣（只有构建者能给）
- 趋势：92% DEX 交易量已走私有 mempool → 公共池机会减少但竞争也减少

### 3. 区块构建者层（谁组装区块）
- 理论工作：组装价值最高区块（每 slot 模拟数千候选）
- 实际：**公共池构建者永远赢不了独有订单流构建者**——独有订单流 = 胜负手
- 构建者 = 订单流提供方的服务提供商（被迫创新：回扣/延迟/隐私/条件执行）

### 4. 中继/最终确定（利润从哪来）
- 中继：模拟验证，防验证者窃取 + 防构建者提交无效区块
- **利润公式：构建者利润 = 区块真实价值 − 获胜出价**（只须胜过次优）
- 公共订单流 → 竞价激烈 → 出价趋近价值 → 利润趋零
- 独有订单流 → 无竞争者 → 保留全部价值
- 验证者：只选出价最高且有效的区块（PBS 轻量化）

## 与套利研究的对接（今天讨论的完整闭环）

| Greenfield 概念 | 套利应用 |
|---|---|
| 位置市场 | 盲套利付位置费（优先费），不是纳入费 |
| 私有路由 | 盲套利上链要走私有通道，否则探测被 backrun |
| 独有订单流 = 胜负手 | edge = 独有路径（模拟器发现别人没看到的路径） |
| 利润 = 价值 − 次优出价 | 竞争少 = 保留全部价值（冷门池机会更肥） |
| 验证者只选最高出价 | 出价策略：略胜次优即可，别付全部利润 |

## 核心认知沉淀

1. **排序权 = 最稀缺资源的经济控制权**（全文立意）
2. **MEV 存在原因**：对共享状态的优先访问永远有经济价值；链上定价 = 优先费（TradFi 定价 = 延迟投资）
3. **信息不对称是结构性的**：多数用户对供应链无意识 → 公共 mempool 永远有可提取价值
4. **盲套利是快链的必然**：链下模拟再上链有延迟窗口，快链（RHC/Solana）必须链上 staticcall 计算
