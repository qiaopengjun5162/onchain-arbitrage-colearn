# 期权入门三步曲：Sell Put → Sell Call → LEAPS Call（Rounder）

> 来源：https://x.com/CryptoRounder/status/2085567945510625329（Paxon 分享 2026-08-08）

## 为什么学期权（作者观点）

**因为可以适应震荡行情——金融市场大约 80% 的时间都在震荡。**（与市面上「期权=杠杆赌方向」的说法相反）

## 第一步：Sell Put（卖看跌）

- 巴菲特、段永平等大佬最常用；「要么赚现金，要么用折扣价买到好股票」
- **铁律前提**：如果股价真跌到行权价，你是否 100% 心甘情愿买入并长期持有？有一丝犹豫就别碰
- 实例：CRCL 260618 到期 $75 Put 收 $4 权利金——不跌破赚 $4；跌破以 $71 折扣价买入

## 第二步：Sell Call（卖看涨）= 车轮策略（Wheel）

- 前提是你已用满意价格买入标的 → 对部分仓位做短期止盈计划
- 实例：CRCL 9/4 到期 $90 Call 再收权利金，若交割卖出 = 波段获利
- 哲学：**等待是投资中最可贵的**（芒格）——等不到就每天收权利金
  - 不 FOMO、不羡慕天才一天赚百万
  - 市场大部分时候**高估未来波动率** → 卖期权长期有溢价（这就是 edge）
  - 不再被多巴胺绑架、不频繁交易（频繁交易=给平台贡献利润）

## 第三步：LEAPS Call（远期看涨期权）

- 低买高卖是本质；做多优势大于做空
- 选宽基指数（SPY）或行业龙头（BTC），在**周期底部 + 波动率收缩**时用 LEAPS + 安全杠杆
- 关键信息：年化成本约 18%；价格超过 65K 后近似现货；**不会爆仓，最大损失=权利金**

## 核心结构拆解（对我们套利研究的意义）

1. **「卖期权长期有溢价」= 波动率溢价收割**——与资金费率、保险、做市商收费是**同类结构**（承担尾部风险换定期现金流）。这和我们研究的「吃手续费/吃资金费」是同族策略
2. **80% 震荡时间** = 我们 MA 复盘里「作用区间思维」的期权版表述（策略只在特定市场状态下有效）
3. **风险不对称**：文中说 Sell Put「稳赚不赔」是**营销话术**——卖期权是负偏度收益（长期小赚、偶发大亏，如 2020 3 月、2024 8 月）。真正的风险控制是：只卖「心甘情愿持有」的标的（仓位管理 + 心理准备代替止损）
4. **Wheel 策略** = Sell Put 接货 → Sell Call 出货的循环，本质是「把震荡市变成现金流的定价工具」

## 与用户当前研究线的关联

- 币股研究（NVDAX 等）：若未来币股有期权，Wheel 可直接套用（币股有开闭市时钟差，卖权正适合闭市震荡）
- 资金费率哨兵：费率高 = 市场高估波动率 = 卖权/收费率窗口（同类信号的两种载体）
- 信息差偏好：规则变更（如 Polymarket TWAP）改变波动率定价结构 = 新机会源

## 待验证/风险标注

- [ ] 「年化成本 18%」的 LEAPS 成本结构未展开（theta/时间损耗拆解）
- [ ] 卖权尾部风险需显式建模：2020-03 / 2024-08 类事件下 Sell Put 的实际回撤
- [ ] 期权卖方 edge 的量化验证：IV 是否系统性高于已实现波动率（RV）？
