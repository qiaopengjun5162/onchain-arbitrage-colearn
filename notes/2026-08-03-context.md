但小机会总会有。慢的时候适合准备基础设施、心智模型、数据源和脚本。行情活跃时，机会出现得快，消失得也快。如果数据管道和判断框架已经准备好，验证就能更快开始。

## 套利现实

套利是薄利高频、低回撤逻辑，不是自动印钱。

模拟盘和 Paper Trading 经常高估收益，因为它们容易少算：

- 盘口深度变化
- 实盘达成率
- API 延迟
- 链上确认时间
- 滑点
- Gas 波动
- 失败交易
- MEV 暴露
- 价格不收敛
- 心态和仓位错误

实盘下单达成率不可能和模拟盘一样。

### 补充：收敛交易的死法（2026-08-05）

群里的实践总结：

> 套利实践下来也是赌，做不好风险管理同样会被一波带走。比如你做价差收敛，庄猛猛拉盘，差价猛猛扩大，就能把你干死。

这是收敛交易（convergence trade）的经典死因：

- 赌收敛 = 做空价差的波动率。价差可以先扩得非常大，再大，然后才收敛。
- 死因往往不是判断错了，而是杠杆 + 价差扩大 -> 保证金撑不住 -> 在收敛之前被强平。"市场保持非理性的时间，可以长过你保持有偿付能力的时间。"
- 有庄 / 有操纵的市场里更狠：拉盘方知道收敛头寸的爆仓线在哪里，价差扩大可以是针对性的猎杀。

风控推论：

- 仓位大小按"价差再扩 N 倍我还能活"来定，不是按"正常价差波动"来定。
- 预设最大亏损线，到了就认赔出场，不赌"马上就收敛"。
- 有操纵嫌疑的标的（低市值、筹码集中），收敛交易要降档或不做——对手可能看得见你的底牌。
- 回测里"最终都收敛"的历史，掩盖了路径上可能致命的中间过程。这和资金费套利风险 #5（基差即成本）是同族问题。

## Edge 问题

核心问题：

> What is my edge?

如果答案是速度，很多团队比我更快。

如果答案是技术基建，很多团队比我更强。

所以搜索方向应该包括：

- 市场选择
- 信息差
- 新资产
- 新路径
- 新协议规则
- RWA/币股
- 链上 perp
- 预测市场 LP
- 把零散信息变成可验证假设的工具

如果一个策略已经需要从 Python 卷到 Rust 才能跑出来，对当前阶段来说，edge 可能已经太薄。工程当然重要，但策略优先；在策略证明值得投入前，基建够用就行。

### 补充：偏门套利的启发（2026-08-05）

群里的体感："有些套利真的是不走寻常路的，很偏。"

这句话其实是 edge 搜索方向的正面印证：越偏的路，竞争者越少，窗口期越长。常规路径（跨所价差、主流币资金费、DEX 原子套利）之所以难做，是因为它们写在教科书上，所有人都盯着。

共学期间已经见过的"偏"例子：

- 收过路费：不抢价差，在机器人必经之路上放高费率池（`notes/case-toll-fee-pool.md`）
- 溢价买入加池子：用已知上限的溢价成本换高利差（`notes/case-premium-buyin-lp.md`）
- 币股 LP：在新资产类别里做 LP，吃早期红利（backlog #4）

共同点：都不在"套利 = 低买高卖赚价差"的标准框架里，而是在生态位、规则差、时间差、新资产里找位置。这给 backlog #1 的能力盘点加了一个筛选标准：优先研究那些"讲出来别人要先愣一下"的方向。

### 补充：分享出来的策略是滞后信息（2026-08-05）

群里的判断：

> 套利，其实就是干中学。真正赚钱的，不会轻易分享。能分享的，最多就是思路，而且是已经差不多赚好了。

这是对一切"公开 alpha"的校准原则：

- 策略被分享的时间点，通常就是它的 edge 衰竭点附近——分享者已经提取了大部分价值，或者竞争已经把利润磨薄了。
- 所以看到分享的策略（包括"收过路费"这种好思路），默认当作历史案例研究，而不是可直接进场的活机会。
- 真正可迁移的是"他是怎么找到的"，不是"他找到了什么"。研究分享者的发现路径：看了什么数据、注意到什么异常、怎么验证的。
- 看到分享时多问一句：他为什么现在分享？赚完了、卖铲子（工具/课程/社群）、还是建立声誉。三种动机的信息价值完全不同。
- 反过来也成立：自己跑出来的 edge 要保护。这次共学笔记不公开到 GitHub、仅限学员内部，就是这个道理。

对共学方式的印证：打卡要求"做了什么、失败什么"而不是"收藏了什么"，正是因为套利能力只能从干中学长出来，收藏一百个思路不如自己跑通一个。

### 补充：共学的两种生产资料（2026-08-05）

群里的总结：

> 其实就是找 AI 根据自己情况脑暴一个学习大纲出来，每天大佬们的笔记也是精华。

这说的是共学的两种生产资料，用法不同：

- AI 脑暴大纲：解决"路径个性化"问题。每个人的基础、时间、目标不同，固定课表注定不合身。大纲的关键输入是"自己情况"——给 AI 的上下文越具体（会什么、每天几小时、想验证什么），大纲越可用。这正是 `hermes/prompts/` 里各模板的设计意图。
- 大佬笔记：精华不在结论（按上一条的校准原则，结论是滞后信息），而在三样东西——发现路径（他怎么注意到这个问题的）、证据习惯（他拿什么数据支撑判断）、失败记录（他踩了什么坑）。读笔记要带着这三个过滤器读。

两者结合的使用方式：AI 大纲负责"我自己该做什么"，大佬笔记负责"校准我的判断框架"。用 AI 生成路径，用人校准方向。

### 补充：能力缺口在数据发掘（2026-08-05）

群里的自我诊断：

> 套利的思维我感觉群里每个人都接触过。只不过从 数据发掘 -> 理论实现 -> 项目落地 这条链路上来说，数据发掘是我们缺少的。

这个判断很重要，因为它指出了共学投入的重心：

- 理论实现：两个原型、概念坐标轴、AI 陪聊就能补——可压缩，不稀缺。
- 项目落地：监控脚本、回测、Paper Trading，AI 写代码大幅降低了门槛——也在变得不稀缺。
- 数据发掘：知道该盯什么、把原始数据洗成信号、积累自己的历史数据集——这才是稀缺能力，也是 edge 的真正上游。

数据发掘缺的不是数据源清单（清单已经有了），而是三层功夫：

1. 知道盯什么：什么异常值得报警（价差、费率突变、新池子、路由变化、规则变更）
2. 洗信号：原始数据 -> 对比基线 -> 噪音过滤 -> 可验证假设
3. 攒数据：现在开始保存的时间序列（报价、费率、价差），三个月后就是别人没有的私有数据集

Bruce 文章里"保存不同时间、链、资产和规模的 LI.FI 报价，不只在网页上看一次"，做的就是第三层。共学 21 天每天攒一点，结束时第一版私有数据集就有了。

对行动的指导：监控 Bot（backlog #8.5）不只是告警工具，它是数据发掘能力的第一个载体——告警规则 = "知道盯什么"的显式表达，CSV 日志 = 私有数据集的第一块砖。

## MEV 判断

MEV 有很高的基建门槛。很多机会接近无风险，所以竞争会很激烈。已有搜索器如果有历史基建、节点、模拟系统、私有订单流、builder 连接和更快执行，自然会吃掉大头。

这次共学里，MEV 更适合作为：

- 市场结构研究主题
- AMM 和交易排序安全主题
- 理解链上透明市场为什么会快速变卷的材料

它不应该作为新手默认的赚钱目标。

## 当前感兴趣的方向

### 链上 perp / Hyperliquid 类市场

这类市场可能比传统跨所更开放。数据、仓位、资金费率、清算和订单流更可观察。

### RWA / 币股

币股和 RWA 路由可能在路由、流动性、执行和市场理解上产生新的差异。关键不是“有没有这个资产”，而是碎片化流动性和新规则能不能产生可验证机会。

### 预测市场 LP

预测市场 LP 和自动挂单值得研究。edge 不一定来自预测准确，而可能来自做市、库存控制、手续费、价差管理和风险边界。

## Hermes 角色

Hermes 不是用来猜明天买什么。

前期用途：

- 找资料
- 解释概念
- 拆每日任务
- 对比官方文档
- 总结协议和工具

中期用途：

- 写数据采集脚本
- 设计监控工作流
- 跑分析
- 辅助回测和 Paper Trading
- 审查每日打卡

长期目标：

训练一个专门的链上套利 Hermes Agent。当给它一个候选机会时，它能：

- 核对来源
- 计算成本
- 检查流动性
- 评估执行限制
- 调用数据工具
- 运行模拟
- 生成监控脚本
- 给出有证据的判断

这必须从人和 AI 协作开始。人负责设边界和复核结论，Agent 随着框架被不断校对而变好。

## 可复用表达

- 大机会没有，小机会总有。
- 策略第一，基建够用。
- 需要卷基建的，往往说明 edge 已经太薄。
- 链上套利最残酷的一点，是它太透明了。
- Paper Trading 不是收益证明，只是初筛工具。
- 暴涨暴跌都不影响你的系统，那就是好策略。
- 不要只收藏信息，要把信息变成可验证的机会假设。
- 看到价差，先算净利润；看到收益，先问风险来源。
- 报价只是预计值，成交才是结果。
- 同名资产不一定是同一种资产，先核对合约地址。
- 套利通常有两条腿，一边失败就会变成单腿风险。
- 套利的本质是在低风险下赚取收益，风险是第一位。
