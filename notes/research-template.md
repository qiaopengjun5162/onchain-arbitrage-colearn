## 0. 一句话总纲

**套利不是「看见两个价格不同」，而是「扣除全部成本、锁定全部必要交易后，仍剩正收益」。** 任何一步答不上来，就是「看得见吃不到」的假机会。

净收益公式（统一口径，缺一不可）：

```
净收益 = 价差收益（卖出收入 − 买入成本）
      − Gas
      − 协议 / DEX 手续费
      − 桥费
      − 滑点 与 价格冲击
      − 延迟成本
      − 失败交易成本
      − 资金占用成本
      − 排序费用（MEV tip，利润的 80%–90%）
      − 授权成本（Approve + Swap 两笔两 Gas）
      − 库存再平衡成本
```

## 1. 四道检查（价差变利润之前的门槛）

看到价差，先逐条过这四条。**任何一条答不上来 = 看得见但吃不到。**

| # | 检查 | 要回答的问题 | 本项目里的对应坑（已验证） |
|---|---|---|---|
| 01 | 比较的是**同一价值**吗 | 同名代币是否同一合约地址、兑付权利、风险？跨链包装资产 / 脱锚稳定币 / 带转账税代币是否等价？ | `bnvda-nvdax`：bNVDA 无流动性 = 假价差；包装资产脱锚是经典陷阱 |
| 02 | 报价对应你的**成交规模**吗 | 边际价格 / 界面展示价 / 真实可成交均价是否一致？交易越大是否改变池内价格？ | fly 报价源污染（"低买高卖自己 +44.5bps" 幻觉）；120 轮报告：成本地板优先于波动率 |
| 03 | 两条腿能**一起锁定**吗 | 是否原子交易（任一步失败整体回滚）？还是买入后要等跨链到账 / 人工下单 / 交易所确认？ | `mempool-and-ordering.md`：捆绑原子性（tx 绑 target，同区块相邻） |
| 04 | 扣完**所有代价**还剩什么 | Gas / 协议费 / 桥费 / 价格影响 / 对冲 / 资金占用 / 失败交易，是否都进了同一计价口径？ | LI.FI 真实成本 26.5–27.5 bps；Break-even = 费 + 双链 Gas + 滑点 + Price Impact + 延迟失败成本 |

> 这里的「锁定」≠ 绝对不会亏：合约漏洞、链重组、预言机异常、错误建模都可能破坏结论。它只意味着——在你**明确声明的模型边界内**，收益不依赖未来价格朝有利方向移动。

## 2. 成本口径表（七大类 + 度量方法 + 链上现状）

来自 Tiya 成本模型表 + 知识总结成本全景，按「怎么度量 / 链上现状」双列整理。填机会卡片时直接照抄此表。

| 成本项 | 度量方法 | 链上现状 / 量级 |
|---|---|---|
| 1. Gas 费 | `gasUsed × effectiveGasPrice`；区分 gas limit / used / base fee / priority fee | L2 ~5–50 gwei，L1 以太坊 10–200+ gwei；多池套利合约常 200k+ Gas；**失败也扣 Gas** |
| 2. 协议 / DEX 费 | 池子 fee tier × 成交额 | Uniswap V2 固定 0.3%，V3 分 0.05% / 0.3% / 1%；聚合器另收服务费 |
| 3. 桥费 | 存款费 + 中继费 + 赎回费 | LI.FI 实测 1000 USDC 损耗 ~26 bps（25 bps 固定 + Relayer + 源链 Gas）；**0.25% 比例费 = 跨链成本硬下限**，小于此的跨链价差永远无利 |
| 4. 滑点 & 价格冲击 | 冲击 ∝ Q² / pool_depth；**冲击与滑点不可重复计算** | 交易额达储备 ~0.3% 时冲击追上手续费；浅池同样单子冲击可放大 10× |
| 5. 延迟成本 | 检测→提交→打包全时间链；跨链叠加源链确认+桥传输+目标链到账+退出 | 套利窗口常只有几秒；18 分钟到账的桥对套利致命 |
| 6. 失败交易成本 | 回滚 = 全部已耗 Gas；多步失败概率叠加 | 非原子一次失败可抹掉约 20 次成功利润 |
| 7. 资金占用成本 | `资本 × 年化率 × 锁定时间` | 预置库存策略分母须含**双链全部预置资本** |
| + 排序费用 | MEV 场景 tip 给 Builder | 常占利润 80%–90% |
| + 授权成本 | Approve + Swap 两笔两 Gas | 每次交互先授权再交易 |

**关键判据（来自实测，优先于直觉）：**
- **成本地板优先于波动率**：LI.FI 120 轮实测，零费率重算也无资产超过 +10 bps；选标的先看成本地板，再看波动。
- **桥 0.25% 硬下限**：任何 < 0.25% 的跨链价差在这条路线上永远无利，金额再大也没用。
- **主流币 DEX 间套利公式从不成立**：Uniswap ETH $1,868.33 vs Aerodrome $1,869.59，扣费扣 Gas 扣滑点后净利 −$52.83；机会在长尾资产或剧烈波动窗口。

## 4. Quote 字段体检单（bizleung，LI.FI / 聚合器报价必查）

调任何聚合器 `/quote` 时，逐字段体检。**重点关注 toAmount vs toAmountMin 的鸿沟。**

| 字段 | 查什么 | 坑 |
|---|---|---|
| `toAmount` | 乐观角读数（理想成交） | 只能当上限，不能当真实收益 |
| `toAmountMin` | 保底数字（滑点容忍带宽内最差到手） | 带宽可能比机会本身宽——实测 0.5% 带宽是 22 bps 优势的 2.25 倍，落到保底端从「赚少了」变亏损 |
| `feeCosts` | 聚合器 / 桥 / DEX 各项费 | LI.FI 固定 25 bps；同名资产不同版本（USDC vs USDC.e）可差近 11 bps |
| `gasCosts` | 各链 Gas | 多池合约 200k+ Gas，别用界面默认 |
| `executionDuration` | 预计耗时 | **当一级指标**：同参数 Polymer 1080s vs Eco 7s，到手金额一样但窗口天差地别 |
| `transactionRequest` | 实际要签的交易 | 与本地 `getAmountsOut` 整数精确对账，任何 delta 都是自己的 bug |

**Quote 使用铁律（99hansling 实测 + 知识总结）：**
- `/quote` 限流 75 次 / 2 小时（非文档说的 100/60），`no-store`；候选集在宽松接口上做，`/quote` 只用于最终测量。
- `/quote` 是时变的，同参数不同时点结果不同；比较 `/advanced/routes` 的**多条候选路径**再定。
- **报价不是承诺**：聚合器 quote 只是某时刻某 solver 的意愿（eventXhorizon）。

## 5. 机会分类维度（Prousty Wu，先做减法）

四个维度给机会分类，再决定要不要碰：

| 维度 | 取值 | 含义 |
|---|---|---|
| 位置 | 单链 / 跨链 | 跨链风险大、竞争小，用风险和时间换空间 |
| 路径 | DEX 内 / DEX 间 / 三角 | 池子越多理论机会越多，失败点同步增加 |
| 来源 | CEX / DEX / 聚合器 | 报价口径不同，乐观偏差不同 |
| 排序竞争 | 公共 mempool / Jito bundle / 私有通道 | 决定能否抢到排序、是否要付 tip |

**5 个核心认知升级（Prousty Wu）：**
1. 原子交易 ≠ 同一区块——跨合约调用链任一段失败都可能留半截头寸。
2. 外层合约捕获失败 ≠ 自动重试——回滚不替你重跑。
3. 付费 RPC 不赋予订单流优先权——只买更快的传输，不买排序。
4. （其余两条见原笔记）机会分类先想「死在哪」，再想「怎么赚」。

## 6. 数学建模视角（0xFeyoma，避免屏幕汇率陷阱）

- 资产 = 节点，池子 = 带方向的边，输出 = 随数量变化的函数：`q_{i+1} = F_i(q_i, S_i)`。
- **屏幕汇率相乘只能发现候选机会，真实收益必须逐腿传递实际数量**——每腿的实际到手，不是边际价格。
- **最优路径随规模改变**：小单走 A 路径，大单可能走 B；用函数而非比率思考。

## 7. 5 问研究模板（统一入口，每个机会必填）

下次看到机会，先写完这五句话，再决定要不要投入：

1. 我比较的两个价值是 ________，它们等价的条件是 ________。（→ 检查 01）
2. 我的真实可成交规模是 ________，不是界面上的边际价格。（→ 检查 02）
3. 必要交易能通过 ________ 锁定；不能锁定的部分是 ________。（→ 检查 03）
4. 利润至少还要扣除 ________。（→ 检查 04 / 成本表）
5. 这个价差仍然存在，最可能因为 ________（市场摩擦的哪一种）。（→ 第一性原理）

**掌握证据**：不使用「看起来」「应该」「无风险」这类词，仍能完整解释为何一个新案例属于 / 不属于套利候选。

## 8. 第一性原理（机会为何仍存在）

价格差异不会凭空出现，它说明市场间存在**摩擦**，套利者的收益正是承担和处理这些摩擦的报酬：

- **市场被分隔** — 不同 DEX / 链 / 账户的资金不能瞬间自由移动
- **定价机制不同** — AMM 曲线、订单簿、预言机、清算规则对同一信息反应不同
- **执行能力稀缺** — 原子合约、低延迟基础设施、库存、优先排序都需要真实成本
- **风险尚未定价** — 桥接、合约、代币限制、失败损失可能正是价差较大的原因

「为什么这个机会还存在？」不是一句怀疑，而是**必须回答的研究任务**。找不到原因时，先假设自己遗漏了条件——而不是假设市场是傻的。

## 9. 实战判据速查（来自本仓库实测，直接可用）

- **成本地板优先于波动率**：先算成本下限，再看波动是否有空间。
- **报价 ≠ 成交**：toAmount 是乐观角，toAmountMin 才是保底；聚合器 quote 是意愿非承诺。
- **无套利带**：有交易成本时价格只需落在 `[理论值 − 成本, 理论值 + 成本]` 带内，带外才是机会；核心工作是估算带宽。
- **三口径对照法**（LI.FI 120 轮）：现状 / 零费率 / 含污染三套数字对照，识别报价源污染。
- **冲击 ∝ Q² / pool_depth**：交易量翻倍，冲击成本翻四倍；深池才扛得住大单。
- **四行为辨析**：套利（锁定价差）/ 相对价值（赌收敛）/ 投机（赌方向）/ 做市（赚价差覆盖库存风险）——每次都标明未被锁定的风险，名称不能替代风险说明。

## 10. 使用手册（标准动作）

1. 发现候选 → 填 **5 问模板**（第 7 节）一遍，存进对应笔记。
2. 用 **四道检查**（第 1 节）当 checklist，缺一条标记「待验证」。
3. 按 **成本口径表**（第 2 节）+ **Quote 体检单**（第 4 节）量化净收益，套用净收益公式。
4. 填 **机会卡片**（第 3 节），落到机制 / 信号 / 数据源 / 风险。
5. 复盘失败时回到 **第一性原理**（第 8 节）找哪类摩擦没被定价。
6. 实盘前：人复核 + 明确标注研究 / Paper Trading / 实盘阶段。
