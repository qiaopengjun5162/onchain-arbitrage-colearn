# TUT 价差窗口回测：两因子（价差+爆仓量）能否预判窗口期？（D6，2026-08-09）

> 待办来源：D5 打卡待办「TUT 价差窗口回测：下载币安/bitget 历史数据，验证『价差+爆仓量』两因子能否预判窗口期」
> 回答的问题（Paxon 2026-08-09）：**搬砖的时候怎么知道窗口期会有这么长？风险是刚开始搬价差就收敛了并且进一步一起下跌。**
> 数据：币安 + bitget TUT 永续 5m 全历史（2025-03-20 → 2026-08-09，509 天，~14.6 万行/所）+ 币安 OI（metrics 5m）+ 双边 funding
> 脚本：`scripts/tut_backtest/download_tut_data.py` / `analyze_tut_windows.py`（数据在 `data/tut_backtest/`）

## 一句话结论

**价差深度能预判窗口期（r≈+0.5），爆仓量代理（OI 降/量能）在 TUT 数据上不显著；窗口期长短的真正决定因素是插针后的价格路径——企稳则窗口长（TUT 08-09 的 150 分钟），继续崩则窗口短且危险（2025-10-10 的 35 分钟，双边同跌）。**

## 数据与口径

- 价差 = (币安 close − bitget close) / bitget close，5m 粒度
- 窗口 = |价差| 连续 > 阈值（默认 1%），冷却 3 根
- 爆仓量代理：① 币安 OI 骤降%（窗口前 2h 均值 vs 窗口内最低）② 插针量能倍率（窗口内最大 5m 量 / 基线）
- 诱盘判别：窗口启动时跨所 funding 差（bg−bn）

## 统计结果（26 个窗口 @1% 阈值，≥20min）

| 因子 | 与窗口期的相关 r | 解读 |
|---|---|---|
| **mean_spread** | **+0.505** | 价差越深窗口越长 ✅ |
| **max_spread** | **+0.477** | 同上 ✅ |
| spread_at_start | +0.319 | 进场时价差就有预示力 |
| oi_drop_pct | −0.072 | OI 骤降无预测力 ❌（代理受污染，见局限） |
| vol_spike_x | −0.036 | 量能无预测力 ❌ |

**窗口期分布**：中位 35 分钟，25% 分位 25min，75% 分位 50min；深价差档（>1.44%）中位 50min vs 浅档 30min。

**Paxon 担心的两条风险路径，数据回答**：
- 「刚开始搬价差就收敛」：**69% 的窗口价差会继续扩大**（diverged_further=1）——进场后立即收敛是小概率
- 「进一步一起下跌」：**双边同跌只占 19%**——但注意两个大事件（TUT 08-09、10-10 崩塌）都是双边同跌，尾部事件的危险与频率不成比例

## 案例对比：两个极端窗口

### 2026-08-09（TUT 插针，Paxon 亲历）——窗口 150min，价差 16.2%
- 07:00 UTC（北京时间 15:00）启动：币安 5m 从 0.19 冲到 **0.3373**（+75%）再砸到 **0.0927**（−52%），量能 5.8x
- 插针后价格**剧烈震荡但未单边崩**（0.09 → 0.34 → 0.15 → 0.18 反复），价差持续 150 分钟
- **为什么窗口长**：bitget 对崩盘的跟随滞后 → 价差维持；价格在插针后进入高波动横盘，没有继续单边下行
- 注意：OI 数据当天缺失（vision 次日发布，cron 自动补），诱盘视角见 `tut-funding-trap-20260809.md`

### 2025-10-10（归零级崩塌）——窗口 35min，价差 8.3%，双边同跌
- 币安 5m 从 0.089 崩到 **0.0085（−90%）**，15 分钟内，量能 42-75x
- OI 从 ~1.9 亿骤降至 ~0.7 亿（**−62.7%**——真正的爆仓潮）
- 价差在崩盘中**反转**：21:15 +1.1% → 21:20 +2.2% → 21:25 **−8.3%**（bitget 滞后补跌）
- **为什么窗口短**：价格单边崩 → 两边一起跌 → 价差快速收敛（没人敢接，价差存在但吃不到肉）
- 结论：**爆仓量最大（OI −62.7%）的窗口反而是最短最危险的**——爆仓量因子在这里是反向信号

## 核心发现：窗口期由「插针后价格路径」决定

```
插针 → 价格企稳（V 型/高波动横盘）→ 价差窗口长（30-150min）→ 可从容双边进场 ✅
插针 → 价格单边崩（归零/阴跌）  → 价差窗口短（20-35min）且双边同跌 → 进场=接刀 ❌
```

两因子（价差+爆仓量）的价值在于**识别「插针事件发生」**，但**窗口长短**要靠插针后 5-15 分钟的价格行为判断：
- 插针后 15 分钟价格不再创新低 + 价差维持 >2% → 窗口大概率 ≥30min
- 插针后继续破位 + 量能不减 → 立即离场，不要接

## 对搬砖策略的落地建议（D6 可执行）

1. **进场信号**：插针事件（价差 >3% 或 5m 波动 >20%）+ 插针后 15min 价格企稳
2. **预期管理**：中位窗口 35min，深价差（>3%）期望 50-70min——按 30min 可完成双边开单设计执行流程
3. **止损纪律**：窗口内若币价继续破位（双边同跌场景），立即平仓——19% 的概率，100% 的尾部
4. **诱盘过滤**：仍依赖 funding_sentinel_v2 的「疑似诱盘」检测（funding 差 >0.5%/期），回测无法覆盖（bitget funding 只有 16 天历史）

## 局限（诚实声明）

- 样本仅 26 个窗口（1% 阈值）/ 5 个（1.5%）——统计功效有限，r 值仅作方向参考
- **爆仓量无直接历史数据**（币安/OKX 均无公开接口），用 OI 骤降 + 量能代理；OI 骤降被「合约迁移/退市」类事件污染（10-10 疑似含此成分）
- bitget funding 历史仅 100 条（~16.6 天，API 忽略 since）→ 诱盘判别无法回测
- 08-09 当天 OI 缺失（vision 次日发布）→ 已挂 cron 自动补数重跑
- 价差用 5m close 而非 bid/ask 或盘中极值——真实可成交价差更小，阈值需上调 ~0.5-1%
