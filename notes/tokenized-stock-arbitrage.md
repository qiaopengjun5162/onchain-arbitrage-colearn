# 币股套利：多发行方锚定同一股票的定价差

日期：2026-08-05（群讨论）

## 群友原话

> 有没有人做币股套利的，这么多发行方都和股票锚定，感觉和稳定币套利思路应该很像。
> Binance Web3 API 支持 bstock、Ondo、xStocks 各种，感觉机会很大啊。
> 文档：https://web3.binance.com/zh-CN/dev-docs/products/trading-api/introduction

## 为什么说"和稳定币套利思路很像"

稳定币套利的经典结构是：多个发行方各自承诺 1:1 锚定美元（USDT/USDC/DAI/...），但二级市场价格会短期脱锚，价差 + 赎回通道 = 套利空间。

币股（tokenized stock）是同构的：

- **同一底层，多个发行方**：比如 AAPL 同时有 Ondo 版、xStocks（Backed）版、bstock 版，各自有各自的铸造/赎回规则、支持链、费用和门槛。
- **各自的锚定机制不同**：有的可赎回（KYC 门槛）、有的只在二级市场流通、有的背后是 ETF 持仓。锚定越硬（赎回通畅），价差收敛越快；锚定越软，价差越大越持久。
- **价差来源更丰富**：稳定币基本 7x24 交易，而股票有开闭市。闭市期间链上币股还在交易，价格纯靠做市商和情绪定价，经常出现漂移；开盘瞬间向真实股价收敛。这是稳定币套利里没有的"时钟差"维度。

## 机会结构拆解（初步假设，待验证）

1. **发行方间价差**：同一只股票的不同代币版本在同一时刻价格不同，流动性碎片化导致。
2. **币股 vs 真实股价**：链上价格相对美股实时价（开盘时）或上一收盘价（闭市时）的溢价/折价。
3. **开闭市时钟差**：闭市漂移 -> 开盘收敛，是可预测的均值回归结构，但要承担隔夜基本面风险（财报、宏观）。
4. **跨链价差**：同一发行方在不同链上的部署，定价不同步。

## 群里问的"是哪一种"：四条路线的对照

群友问：币股套利是指期现套利、股票与链上币股套利、还是组 LP 吃手续费？拆开看是四条不同的路：

### A. 期现套利（币股版）

结构：链上现货 + 合约做空（如 xStocks 在 Bybit/Kraken 的合约），锁定价差、吃资金费。

关键坑：合约标记价锚真实股指，闭市期间链上价格漂移而合约腿不动，对冲阶段性失效——时钟差风险在这里表现为对冲失效。

### B. 股票 vs 链上币股（跨市场，最"纯"）

结构：链上买折价币股 + 券商做空真股票（或反向），价差扣除费用即利润。

门槛：可做空美股的券商账户（IBKR 类）、借券成本、双边资金占用、赎回 KYC。大多数人"看得懂但够不着"，适合作为定价参照系而不是主战场。

### C. 组 LP 吃手续费

严格说不算套利，是做市收过路费。收益来自 fee + 激励，风险是闭市漂移的无常损失——开盘跳空时 LP 仓位会被套利者搬穿。LP 损益不对称（`notes/case-toll-fee-pool.md`）在币股上被时钟差放大。

### D. 发行方间价差（门槛最低，稳定币套利的直接平移）

结构：同一只股票（如 AAPL）的 Ondo 版 / xStocks 版 / bstock 版同刻价差，三腿全在链上，不需要券商和做空权限，Binance Web3 API 一个入口看多家报价。

## 建议的推进顺序

先做 D 的数据监控（纯观察不交易）-> 用 B 当定价锚理解 D 的价差成因 -> 数据跑出规律后再判断 A 和 C 值不值得进。

## 关键风险（和稳定币套利不一样的地方）

- **赎回门槛**：稳定币赎回相对开放，币股赎回大多要 KYC + 合格投资者认证，散户可能只能做"单腿"（链上买卖，无法一级市场平掉）。单腿 = 赌收敛，不是真套利。
- **流动性薄**：币股整体 TVL 和成交量远低于主流币，进出都有冲击成本。
- **企业行动**：拆股、分红、并购时代币如何处理，各发行方规则不同，是"规则差"的来源也是坑。
- **合规风险**：币股在不同司法辖区的合法性差异很大，这本身就是 Bruce 说的"规则套利"的一部分，但也意味着政策变化可能直接归零某条路径。

## 为什么现在值得看

这正好落在共学的核心叙事上：**新资产、新规则、路由未固化，正面竞争还没卷到**。群里之前说"蓝海在币股"、"币股 LP 稳健"，和这里的套利视角是同一类判断的两个侧面。Binance Web3 API 把多个发行方的行情和交易聚合到一个入口，显著降低了数据接入成本——符合"用现成基建，把精力放在策略上"的原则。

## 币股产品形态对照（Paxon，2026-08-06）

| 类型 | 映射方式 | 交易时段 | 说明 |
|---|---|---|---|
| **ADR** | 完全映射 | 与美股同步 | 传统存托凭证，1:1 锚定 |
| **bStock** | 底层映射 | 7×24 | 非交易时段也可交易，闭市漂移是套利窗口 |
| **合约** | 不映射 | 7×24 | 永续合约，对赌价格，无实物锚定 |

**套利意义**：bStock 的 7×24 交易在美股闭市期间产生"时钟差"——链上价格纯靠做市商和情绪定价，开盘瞬间向真实股价收敛。这是 bStock 相对 ADR 独有的套利维度。

## bStock 本质澄清（群讨论，2026-08-06）

bStock（Binance）不是交易所自己发行的"山寨股票"，也不是传统券商账户里的正股，而是**正股的链上代币化映射（tokenized stock）**。

```
NVDA 正股 → NVDAB bStock（1:1 经济挂钩）
```

价格目标跟正股 1:1，但交易机制不同——bStock 7×24 链上交易，而正股只在美股时段交易。这个"机制差"是套利空间的来源。

## Binance Web3 Trading API 实测要点（D3 广度，2026-08-07）

来源：https://web3.binance.com/zh-CN/dev-docs/products/trading-api/introduction （兑换 API 介绍，Last modified 2026-08-06）

### 功能概览（DEX 聚合器）

| 接口 | 用途 |
|---|---|
| `GET /api/v1/dex/aggregator/supported/chain` | 支持的链 |
| `GET /api/v1/dex/aggregator/quote` | 报价（SWAP + RFQ 双模式） |
| `GET /api/v1/dex/aggregator/swap` | 生成兑换交易数据 / RFQ 待签名数据 |
| `GET /api/v1/dex/aggregator/quote-and-swap` | Flash API：单次调用报价+构造交易（少一次 HTTP 往返） |
| `GET /api/v1/dex/aggregator/approve-transaction` | 授权交易 |
| `GET /api/v1/dex/aggregator/history` | 按 txHash 查状态 |
| `POST /api/v1/dex/aggregator/order/submit` | 提交已签名 RFQ 订单（仅权益代币） |
| `GET /api/v1/dex/aggregator/order/{orderId}` | 轮询 RFQ 结算状态 |

### 执行模式

- **SWAP**：普通代币（含 BStock 的 LiquidMesh 路由），签名后广播。
- **RFQ**：权益代币（Ondo、BStock 的 PcsXRfq 路由），EIP-712 签名 → `/order/submit` → 轮询到 FILLED/FAILED。

### 权益代币集（对套利最重要的部分）

- **Ondo（type=1）**：NKEon/NVDAon/EEMon 等，始终 3-vendor RFQ（InchFusion + CowSwap + PcsXRfq）。
- **BStock（type=3）**：PALLon/TSLAB 等，LiquidMesh（SWAP）+ PcsXRfq（RFQ）混合，同一次询价可能同时返回两条路由。
- Ondo 与 BStock 代币集**严格互斥**。

### 关键约束（套利窗口的硬限制）

- `userWalletAddress`：RFQ 路由 /quote 必填，作为订单接收方。
- **quoteId 有效期仅 30 秒**——/quote 后必须 30s 内 /swap，否则 QUOTE_EXPIRED(40401)。
- EIP-712 签名钱包必须与 userWalletAddress 一致。
- **交易时段**：Ondo 美股非交易时段不可用（40367），BStock 同理（40369）——与"闭市漂移"套利窗口直接相关：非交易时段 API 直接拒绝，套利只能靠别的手段。
- 幂等：重试 /order/submit 复用同一 UUID。

### 自定义手续费（Add Fee/分佣）

- 按百分比从兑换扣费打入指定钱包：EVM (0,5]%、Solana (0,10]%，最多 2 位小数。
- feeSource=FROM_TOKEN（卖出币扣）/ TO_TOKEN（买入币扣），referrer 二选一。
- RFQ 路由忽略 fee 参数。

### 对币股 D 路线的意义

1. **数据接入已确认可行**：Binance 官方 API 一个入口覆盖 Ondo + BStock 双发行方，含 RFQ 报价 → 多发行方价差监控的底层数据源落实。
2. **30 秒 quoteId 有效期**：D 路线"折价买入 → 等待收敛"的持有型套利不受影响；但"同资产瞬时换发"型受 30s 限制。
3. **非交易时段 API 拒绝**：Ondo/BStock 在美股闭市时不可交易 → "闭市漂移"窗口内无法用官方 RFQ 套利（只能走其他路径或纯观察）。
4. **执行链路复杂**：RFQ 需要 EIP-712 签名 + 订单提交 + 轮询，比普通 swap 多 3 步——自动化门槛更高，但也意味着竞争者少。
