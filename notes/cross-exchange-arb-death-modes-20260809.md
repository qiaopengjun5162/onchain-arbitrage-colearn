# 跨所价差套利的死亡方式：事件还原与核心逻辑（2026-08-09）

> 来源：Paxon 群讨论结构化整理（2026-08-09 深夜，含多位群友观点：老宋/零下/梦/xtest）
> 状态：群聊共识记录（未全部验证），与 tut-funding-trap / aster-funding-arb 交叉印证

## 1. 「吃尸体」阶段的跨所价差套利（TUT 案例）

**现象**：TUT 币安 vs Bitget 价差 20%，维持半小时；可吃到 15%，开仓资金量可到几百万 U，确定性高。

**本质**：极端行情下的「捡漏/吃尸体」——大所（币安）与小所（Bitget）的深度、用户结构、合约机制不同，剧烈爆仓/插针时**价格修复有时间差**。

**风险警示**（群友零下）：
- 「容易死」，「套利群一片哀嚎」——很多人价差收敛前冲进去
- **二次暴跌**：第一波插针后还有第二波，冲进去的被埋
- **交易所规则反杀**：标记价格差异、ADL 自动减仓

## 2. 资金费率套利与「出生币」陷阱（TRB / 妖币）

**现象**：TRB 等币种极高资金费率 → 吸引「现货买+合约空」吃资金费 → 庄家拉爆空单 → 现货跌成废纸 + 合约被爆仓。

**本质**（群友梦回忆 TRB 事件）：**庄家「设好的套利陷阱」，专门收割想吃资金费的人**。

**与妖币的对照**：
- xtest：妖币起来后杠杆受限（1-2x），踩踏风险低，资金费率套利看似安全——**但这是「出生币」阶段的特征**
- **小所「开盘第一波」红利期已过**（Lbank/BiKi 时代），现在更多是「万人骑」的局
- 零下：「去小所做空套利，生死难料」「**赢了不一定给提走**」（提币限制）

## 3. 交易所规则杀与黑天鹅

**案例**：Bybit 大 V（沫沫/mmt）做空套利被爆几百万，交易所后来赔了——**但这是例外**（大 V 舆论压力），散户不赔。

**规则风险三件套**：
1. **ADL（自动减仓）**：对手盘资金不足时，盈利仓位被强制平仓——你赚的钱可能被「再分配」
2. **标记价格差异**：不同所标记价格算法不同（BG vs BN 差异大）→ 看似有价差，实则无法盈利甚至亏损（**你的套利价差可能只是标记价差幻觉**）
3. **提币限制**：小所/大所极端行情可能关闭提币 → **套利资金被困，价差收敛后无法出场**

## 核心逻辑提炼

1. **跨所价差的来源决定生死**：
   - 真实失衡（下架结算/自然爆仓潮）→ 修复有确定性时间表 → 可套
   - 人为设计（资金费诱盘/出生币局）→ 修复时间由庄家定 → 陷阱
2. **套利的「无风险」是幻觉**：ADL/标记价差/提币限制是交易所规则层面的隐藏风险，比市场风险更难预测
3. **容量与对手**：几百万 U 的确定性高 ≠ 安全——**你的对手是知道你在套利的人**
4. **「赢不一定给提走」**：流动性风险（提币）是最后一道闸——价差对了、方向对了，钱拿不出来
