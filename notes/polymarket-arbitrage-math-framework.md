## 一句话

专业量化团队 2024.04-2025.04 从 Polymarket 累计提取约 **4000 万美元套利收益**（单市场 1058 万 + 全 YES/NO 篮子 2901 万 + 组合 9.56 万 ≈ 3969 万）；第一名单人 **2,009,632 美元**（4049 笔，单笔均值 ~$496）。靠的不是看到 YES+NO≠1，而是一套优化系统：**整数规划 + Bregman Projection + Frank-Wolfe**。

## 第一部分：为什么简单相加不够——Marginal Polytope（边际多面体）

**基础认知**：YES + NO = 1 是最底层检测。真正的套利来自**市场之间的逻辑依赖**。

- n 个条件 → 理论 2ⁿ 种结果组合；Marginal Polytope M = conv(Z)（所有合法结果的凸包）
- **例子**：「共和党赢 5%+」⇒「特朗普赢宾州」——A 市场 2 结果 × B 市场 2 结果 = 4 种，但「共和党赢 5%+ 且特朗普输宾州」不可能 → 有效结果只有 3 种 → 市场按 4 种定价就是系统性错误 = 套利机会
- NCAA 63 场比赛：2⁶³ ≈ 9.22×10¹⁸ 种可能；2024 总统大选：1,576 对潜在关联市场
- **整数规划**（Z = {z∈{0,1}ᴵ : Aᵀz ≥ b}）：用 3 条线性约束替代 16,384 次暴力计算（Duke vs Cornell 例）——把指数级搜索压缩到毫秒级

**论文实测**：17,218 个市场条件，**7,051 个存在单市场套利（41%）**，中位价格 0.60（理论应接近 1）——**市场约 40% 定价偏差，远没想象中高效**。

## 第二部分：Bregman Projection——如何算出最优套利方案

**问题**：把当前价格投影到「无套利价格空间」，同时保留市场信息。

- **为什么欧氏距离不行**：0.50→0.60 和 0.05→0.15 都是 +0.10，但信息量完全不同（价格 = 隐含概率）
- **Bregman Divergence**：D(μ‖θ) = R(μ) + C(θ) − θ·μ
  - LMSR 做市下 R(μ) = Σμᵢln(μᵢ)（熵）→ Bregman 散度 = **KL Divergence**——衡量概率分布的信息差异，符合预测市场定价逻辑
- **核心结论**：最大套利收益 = 当前价格到无套利集合的 Bregman 散度；投影同时给出：
  - μ* = 无套利价格向量（该交易什么）
  - D = 理论最大可提取利润（能赚多少）
  - ∇D 梯度 = 最佳交易方向（怎么下单）
- 第一名玩家的系统就是反复解 μ = argmin D(μ‖θ)

## 第三部分：Frank-Wolfe——让复杂优化落地

**问题**：Marginal Polytope 顶点指数级，直接投影算不动。

- **Frank-Wolfe**：不一次处理整个空间，从少数可行点开始，逐步扩展——每次迭代只新增一个点（100 次迭代 = 维护 100 个关键点，而非 2⁶³）
- **耗时点**：每步要解整数线性规划（ILP，NP-Hard）——但预测市场的结构化约束让 Gurobi 能高效求解
- **实测速度**（Gurobi 5.5）：比赛开始 <1s/次；中期 10-30s；接近结束 <5s（结果确定 → 可行解减少 → 更快）
- **Barrier Frank-Wolfe**：LMSR 梯度 ∇R(μ)=ln(μ)+1 在概率趋近 0 时发散 → 在收缩空间 M'=(1−ε)M+εu 优化（ε 渐减），收敛 O(1/(ε·t))，大型市场 50-150 次迭代
- **效果**：FWMM vs LCMM，45 场比赛后 30 分钟内完成投影，预测精度中位数提升 ~38%

## 第四部分：非原子执行——订单簿才是真正的难点

**发现套利 ≠ 赚到钱**（CLOB 每笔订单独立撮合，不能保证同时成交）：

- 例子：买 YES 0.30 ✓ → 价格被推高 → 买 NO 变 0.78 ✗ → 总成本 1.08 > 兑付 1.00 → **亏损**
- **论文只统计利润 ≥0.05 美元的套利**：低于此被滑点/波动/撮合延迟/Gas/手续费吃光
- 用 **VWAP**（非盘口价）统计：按 Polygon 每区块（~2s），|YES+NO−1|>0.02 记为一个机会
- **流动性 = 木桶效应**：多市场套利，最短的木板决定规模（120 美元的池子限制整个 500+800+120 组合）
- 1 小时窗口（950 区块）归因同一次策略，75% 订单在此窗口内撮合

**执行数据**：
- 单市场套利：7,051 机会，87% 成功；失败 = 48% 流动性不足 / 31% 价格变动 / 21% 被抢
- 组合套利：13 对机会，仅 45% 成功；失败 = 71% 流动性不足 / 18% 速度竞争

**速度差距**（都等 Polygon 出块 ~2s，差距在决策→mempool）：
- 普通用户：API 50ms + 撮合 100ms + 出块 2000ms + 传播 500ms ≈ **2650ms**
- 专业系统：WebSocket <5ms + 计算 <10ms + RPC 15ms + 提交 10ms ≈ **2040ms**（30ms 内全订单进同一区块）

**跟单快钱包几乎赚不到**：专业系统 Block N-1 发现 → 30ms 提交 → Block N 确认 → 你 Block N+1 才看到开始跟 → 只是给别人提供退出流动性（真实例子：高手 VWAP 0.322 买 50000，你 0.344 买 5000，原本 10 美分空间变你的亏损）

**资金规模决定策略成立**：第一名管理 >$50 万；$5000 跑不动（滑点吞噬、机会参与不足、一次失败抹几天利润、Gas 占比过高——四腿 Gas $0.02，利润 $0.08 时占 25%，$0.03 时占 67%）

## 第五部分：完整系统架构

1. **数据层**：CLOB WebSocket（订单簿/成交/新市场/结算，实时推送）+ Polygon 链上历史（合约 0x4D97DCd97eC945f40cF65F87097ACe5EA0476045，监听 OrderFilled/PositionSplit/PositionsMerge；8600 万笔链上交易）
2. **依赖分析**：总统大选 305 市场 = 46,360 对组合；用 **DeepSeek-R1-Distill-Qwen-32B** 自动判断市场依赖（输入描述 → JSON 合法结果组合）；40,057 对独立 / 1,576 对依赖 / 374 对满足条件 / 人工确认 13 对；模型准确率 81.45%（第一轮筛选够用）
3. **优化引擎**（三层）：
   - LCMM 快速线性约束（概率和=1、A⇒B 则 P(A)≤P(B)，几毫秒清明显错误定价）
   - Frank-Wolfe + Gurobi 整数规划（α=0.9 提取≥90% 空间、ε=0.1、50-150 次迭代、1-30 秒）
   - 仓位管理：改进 Kelly f=((b·p−q)/b)·√p，下单量≤订单簿深度 50%，回撤>15%/成交率<30% 熔断
4. **执行层**：毫秒级决策 → 同时提交所有订单进同一区块（20-30ms 内完成）

**收益构成**：单市场 1058 万（买 YES+NO<1：590 万；卖 YES+NO>1：468 万）+ 篮子 2901 万（买全 YES 1109 万 + 卖全 YES 61 万 + 买全 NO 1730 万）+ 组合 9.56 万 ≈ **3968.9 万美元**
