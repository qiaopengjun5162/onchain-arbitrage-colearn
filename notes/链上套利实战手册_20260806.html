第一章 套利世界观

1.1 套利的本质

“套利的本质是在低风险的情况下赚取收益吧，风险是第一位” —— ingram

套利 = 同一资产在不同市场/形态间的价差，低买高卖赚差价。关键认知：

  • 无风险套利很少（成员177）；套利也有风险，只是敞口大小不一样（海雅慕容）
  • 套利是”一条腿 + 另一条腿”（Marlboro）：把 LP 当一条腿，找到另一条腿才叫套利，单腿都是在赌方向
  • 有风险的套利和合约没区别（人生海海）——要区分”套利”和”赌博”

1.3 五大幻觉（Paxon 思维模型）

“幻觉价差、成本低估、规模错觉、模拟盘陷阱、执行失控” —— Paxon

  • 幻觉价差：看着有价差，实际成交时没了
  • 成本低估：手续费/滑点/资金成本吃光利润
  • 规模错觉：回测小规模 OK，上规模被价格冲击打穿
  • 模拟盘陷阱：模拟盘盈利 ≠ 实盘（滑点/成交/卡单）
  • 执行失控：策略对但执行出错（订单失败/gas不够/卡单）

成本-规模是 U 形关系：太小被固定成本吃掉，太大被价格冲击和容量吃掉——中间最优（Paxon）。

第二章 入门三件套（新手必做）

2.1 资金费套利（最推荐入门）

原理：永续合约按资金费率多空结算，费率极端时：现货买入 + 合约反向开仓 → 锁定方向吃费率。

  • 前提：统一账户（同所现货+合约自动对冲）——蝈蝈
  • “正资金费太少见了”（hm910705）——机会不多但机制简单
  • 没发币的 DEX 可以做（ONDO 等）（王生）

2.2 CEX-DEX 价差发现 MVP（第一个练手项目）

“建议都给自己定个目标，比如做个 cex-dex 价差发现和自动搬砖的 mvp 版本，这应该算比较简单的了” —— Shen

做法： 1. 币安 API + DEX 报价（Uniswap/OKX DEX API）拉价格 2. 计算价差，超过阈值告警 3. 先做”发现”不做”执行”，跑通再加自动下单

要点：链上链下价差消失快——监控要快；“写脚本，先写个监控，写了用了就知道了”（王生）。

2.3 小资金 LP 与无常损失

“回测了一下，LP是这个逻辑吧” —— 飞天小蟑螂

  • LP 本质是做多（王生），套保意义不大
  • 牛市 LP 划算（去年 BSC 牛市很爽），熊市”一不小心就接盘”（高致林泉）
  • 风险控制：监控大额撤池（跑路信号）+ 跑得快（王生）
  • JLP 是少数能套保的 LP（海雅慕容）；普通 LP”赚的基本是机器人的钱”
  • 练手：博饼/Uni 组个 LP 理解无常损失（风一阵）

第三章 基建与工具

3.1 节点/RPC 选择

“你们都是理论强的一批，做一做就知道了，我都是用的公用 RPC” —— 海雅慕容

场景 用什么
CEX-CEX / CEX-DEX 套利 公共 RPC 够用（傻子爱思考）
链上抢跑（MEV 类） 私有节点/自建（捡到一个橙子）
实时性要求高的 慢一步 = 机会没了（cfanboy）

原则：先跑通，再考虑增强基建（傻子爱思考）。

3.2 监控系统（群里共识的第一个需求）

“我们的第一个需求应该是，能监控和识别出市场的异动信号” —— qq124670461

  • LP 大额撤池监控（跑路信号）——王生实战经验
  • 链上异动/大额交易监控
  • 王生的跨所差价脚本踩坑：“单是订单成交问题就已经让我头疼了”

3.3 桥聚合器：LI.FI 与 CrossEx

  • LI.FI（jingwentian）：聚合多池流动性，链下计算最优执行路径（相当于链下预言机）；价格好不好看索引广度和路径算法；Bruce 当天写了教程（x.com/brucexu_eth）
  • CrossEx（Gate 产品）（零下/蝈蝈）：跨所资费套利+合约价差产品化；底层 = Gate 垫钱在不同交易所下单，内部算法算爆仓价
  • 对比：kyber 吃正向滑点（海雅慕容）；“多转一遍就慢很多，只能搞对实时性要求低的市场”（ingram）

  1. 敞口管理：套利也有风险，敞口大小自己控制（海雅慕容）

  4. 容量意识：机会容量小就小仓位（q97531x：“就投入了 1000u”）
