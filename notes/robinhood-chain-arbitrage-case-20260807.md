### 手续费视角的核心洞察（Paxon 强调）

1. **盈亏平衡**：跨池价差必须 > 0.5%（闪铸费）+ 两池 CLMM fee + gas，机器人才有利润——**闪铸费是最大摩擦项**
2. **CLMM 的含义**：集中流动性池的 fee 是分档/动态的，套利者需要知道每档 fee；**滑点由 tick 区间流动性决定**，不是 V2 的均匀曲线
3. **链上无做空/做多/一级市场**（Paxon 原话）→ RHC 纯现货生态，**三角套利是唯一玩法**，而三角套利的生存空间完全由"池子手续费 vs 跨池价差"决定
4. 0x8366 回款 = 闪铸本金（毛利趋近于 0）→ 机器人靠**闪铸零本金 + 高频跑量**活着，单笔利润极薄——这正是"手续费夹缝"生态的典型形态

## 综合总结（2026-08-07，Paxon 要求）

### 它是怎么做的（机制拆解）

1. **零本金启动**：WETH flash mint（闪铸）0.0282351 → 不占用自有资金，费用 0.5%
2. **三池三角**：CLPool (WETH→USDG) → RamsesV3 (USDG→FRONG) → PoolManager (FRONG→ETH)
3. **闭环平账**：卖 FRONG 得 ETH 0.0282351 = 闪铸本金 → 还本金 + 0.5% fee
4. **技术特征**：50 条内部调用（多池 staticcall 比价）→ delegatecall 代理执行；匿名合约隐藏策略
5. **生态前提**：RHC 纯现货（无做空/做多/一级市场）、gas $0.03、新链流动性碎片化 → 跨池价差窗口

### 它能活的三个条件

- **新链流动性碎片化**：刚上线的链，USDG/FRONG 这类新资产在不同池价格不一致
- **零本金 + 低 gas**：闪铸不占资金，$0.03 gas 让单笔毛利哪怕 $0.1 都值得跑
- **CLMM fee 分档**：选低 fee 池（如 0.05%）控制摩擦

### 我们能学的经验（方法论）

1. **交易还原三件套**（已实战验证）：`token-transfers + internal-transactions + logs` 三个 blockscout API 端点即可完整还原任意 EVM 套利交易——这是「蒸馏别人交易方法」的基础设施（Solana 侧 = solscan/Helius 对照）
2. **手续费 = 套利生死线**（Paxon 强调）：评估任何机会先算摩擦成本（swap fee + 闪铸/闪电贷费 + gas + 滑点），价差必须盖过摩擦才有意义
3. **闪铸 = 零本金杠杆**：Solana 对应闪电贷；但清算竞拍/闪电贷抢跑是 bot 主场（我们边界内不碰），可借鉴的是"零本金验证机会"的思路
4. **新链红利**：新链 = 流动性碎片化 = 价差窗口——与「上币公告监控」联动，新链/新资产上线是最佳监控时点
5. **CLMM vs V2**：定价模型不同（tick 区间流动性 + 分档 fee），现有 `pool_price` 脚本需支持 CLMM
