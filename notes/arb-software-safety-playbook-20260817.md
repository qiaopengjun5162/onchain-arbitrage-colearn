## 一句话

「一键套利软件」越是不需要学习、下载即自动盈利，越要弄清它的利润从哪来——**它是靠套利赚钱，还是靠使用它的人赚钱**（私钥/签名 = 钱包全部控制权）。判断工具先看五问：只读还是可交易？连钱包还是要私钥？策略逻辑公开吗？开发者怎么赚钱？要求关杀毒/管理员权限吗？

## 五个部分要点

### 一、自己搭监控 vs 下载「一键套利」是两回事
- 自己搭监控 = 只读公开行情（价格/资金费率/盘口），不连钱包、不填私钥 → 安全
- 「一键套利软件」要自动交易就必须有发起交易和签名能力；填私钥 = 交出钱包**所有**资产控制权，不只是本次交易权限
- 判断工具五问：① 只读数据还是可发起交易？② 连钱包还是直接索要私钥？③ 策略逻辑是否公开？④ 开发者通过什么方式收入？⑤ 是否要求关杀毒/管理员权限/复制看不懂的 PowerShell 命令？（⑤ 任一命中直接停）

### 二、开源 ≠ 安全，但公开逻辑值得学习
- GitHub 开源的价值 = 能读代码学策略，**不是安全证书**；主程序正常 ≠ 依赖包/安装脚本/下载物正常
- 用 GPT 拆解代码（**只分析不执行**）提示词模板：
  > 只分析代码，不执行任何命令。解释策略的完整盈利逻辑，列出依赖、外部请求、合约地址、私钥读取位置、授权对象和可能发起的交易。无法确认的地方单独标记，不要默认安全。
- 让 GPT 回答七问：利润从哪来？调用哪些合约？私钥在哪被读？连哪些外部地址？安装依赖时执行什么？运行后还下载文件吗？最终发起哪些授权/签名/交易？
- 能自己重新实现，就没必要运行别人打包好的程序；**交给 GPT 前先删 .env/私钥/助记词/RPC Key/真实钱包信息**
- 局限：恶意内容藏在依赖/混淆代码/二进制里，GPT 也可能看不出来

### 三、私钥不是普通配置项
- .env 不是加密工具——程序能读，恶意代码同样能读
- 值得小额测试的话：**独立钱包**（新助记词 + 独立浏览器环境 + 只存少量 Gas 和测试资金 + 不导入主钱包 + 不和长期资金共用私钥）
- ⚠️ 同一助记词在 MetaMask 新建地址 ≠ 真正隔离（同环境，一个程序读到钱包数据其他账户也受影响）
- 测试钱包的作用是限制最坏损失，不是证明软件安全；**私钥交给过不可信软件 = 测完废弃钱包，剩余资产转走**

### 四、不索要私钥，也可能通过签名拿到资产权限
- Approve / Permit / Permit2 / setApprovalForAll 都可能允许其他地址动用资产；**部分只需签名不需付 Gas，不弹链上交易 ≠ 没风险**
- 签名前看清：授权给哪个地址？什么资产？额度多少？有无到期？能不能转走全部 Token？**能精确额度就不要无限授权**
- 测完取消不再使用的授权；ScamSniffer 只是多一道提醒，插件没报警 ≠ 安全

### 五、容易忽略的小工具
- 来路不明的自建网页/小软件/浏览器插件/输入法/翻译工具都可能接触输入、复制、上传的内容
- **剪贴板替换攻击**：恶意程序识别你复制的钱包地址 → 替换成攻击者地址；首次转账小额测试、常用地址白名单、正式确认核对完整地址（不只首尾几位）
- 杀毒保持开启；陌生文件 VirusTotal 检查（**别上传带私钥/真实配置的文件**）；陌生程序进 Windows Sandbox/虚拟机，别在有主钱包的电脑环境跑
- 私钥/助记词/验证码/完整配置不进联网输入法、翻译网站、云笔记、AI 对话框

## 结论

与我们的安全铁律完全一致：账号密码/API key/私钥/Token 禁止明文、统一本地配置、聊天只引用变量名。**「开源可审计 + dry-run + key 走环境变量」仍是最快的第一道过滤器**；本笔记把第二道（运行前代码审查）和第三道（签名/剪贴板/小工具）补全了。
