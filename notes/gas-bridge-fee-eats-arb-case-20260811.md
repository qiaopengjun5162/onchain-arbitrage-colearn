# 实操案例：跨链套利毛利为正，gas+桥费翻负（2026-08-11）

> 来源：Paxon 实测记录（金额/盈亏表，汇率 1876.73 U/ETH）
> 一句话：理论上套利成功了，gas+桥费说：不，你没有。

## 原始数字

| 项目 | ETH | U（×1876.73） |
|---|---|---|
| 初始金额 | 0.004 | 7.51 |
| 交易结束金额 | 0.00400498 | 7.52 |
| 本金差额（毛利，跨链价差） | +0.00000498 | **+0.01** |
| 另付费用（起始链 gas + 桥费） | −0.00005873 | **−0.11** |
| **盈亏（净）** | −0.00005375 | **−0.10** |

## 拆解

- 毛利价差率 = 0.01 / 7.51 = **+0.133%**（跨链后到手确实多了，价差捕捉成功）
- 成本率 = 0.11 / 7.51 = **−1.46%**（gas+桥费占本金比例）
- **成本是毛利的 11 倍** → 净亏 −0.10 U
- 打平所需价差 = 1.46%；或同等价差率下打平本金 = 0.11 / 0.00133 ≈ **$83**
- 也就是说：这笔的结构在 $83 本金时刚打平，$1000 本金时才进入 LI.FI 实测的 1000U 成本最优点（25bps 稳定币到手率）——当前 7.51U 仓位远低于最小有效规模

## 为什么小仓位必死（机制）

- gas 和桥费是**固定成本**，不随仓位缩放：0.004 ETH 的跨链和 1 ETH 的跨链付几乎同样的 gas。
- 价差率（%）随仓位基本不变，成本率（%）随仓位缩小爆炸上升。
- 套利最小有效规模 = 固定成本 / 期望价差率。低于它，毛利再真实也是净亏。
- 结论：这不是「套利失败了」，是「仓位规模低于该路径的最小有效规模」。**同一路径，$7.5 亏钱，$1000 赚钱**——规模是套利参数的一部分，不是可选项。

## 互证

- LI.FI 0.25% 固定费成本地板 + 1000U 最优点（`notes/colearn-incremental-137-digest-20260810.md`、`notes/day6-lifi-quote-compare-20260810.md`）
- 066 s_min 公式：价差门槛 = 费率 + gas（`notes/backtest-verify-066-128-20260810.md`）
- 门槛公式：expectedSurplus > successGas + 失败摊派 + 机会成本（`scripts/execution_quality_tracker.py`）——本例 successGas+桥费 = 0.11U > expectedSurplus 0.01U → 公式判定 NO-GO，与实测一致
- 无套利带：价差被压在两腿费率走廊内，本例的 0.133% 价差正好落在走廊内（<1.46% 成本带）

## 教训一句话

毛利为正 ≠ 套利成功；**成本项要在下单前按「固定成本/本金」算成费率，再和价差率比**。下单前先过门槛公式，而不是成交后才发现 gas 把利润吃光。
