## 核心命题

**区块空间是稀缺资源**——由去中心化共识保障的可验证计算+数据存储。以太坊核心产品 = 区块空间，主要业务 = 出售访问权。交易**排序**改变结果（先执行者享受更好价格）→ 排序权 = 经济价值。

## 以太坊交易供应链（四层）

```
订单流层 → 路由层 → 区块构建者层 → 最终确定
```

### 1. 订单流层（orderflow）
- 所有希望上链的交易集合：用户/钱包、dApps、求解器（solvers）、MEV 搜索者
- **区块空间按两个维度定价**：
  - **纳入市场**（inclusion market）：交易能否进区块（EIP-1559 基础费，拥堵时变贵）
  - **位置市场**（position market）：交易在区块中的位置（三明治/套利者先交易=机会消失）→ **价值的大部分来自位置**
- 理性套利者愿付 ≈ 全部可捕获利润的费用确保先执行（优先费）；简单 USDC 转账位置无关 → 不付优先费
- **MEV 存在的原因**：对共享状态的优先访问始终有经济价值（传统金融靠延迟优化投资定价，链上靠优先费+区块价值定价）

### 2. 路由层
- 广播到公共内存池 → 风险：被复制、backrun、三明治
- 趋势：**私有 RPC/OFA**（减少信息泄露，返还部分价值给订单流提供方）；builder RPC 直连（复杂订单流要细粒度排序/回扣）

### 3. 区块构建者层
- 从交易+费用中组装**价值最高**的区块（每个 slot 模拟数千候选区块）
- **关键不对称**：只看到公共池的构建者永远干不过能收到独有订单流的构建者 → 构建者=订单流的服务提供商，被迫创新吸引高价值订单流

### 4. 最终确定
- 构建者提交出价给**中继**（relay，模拟验证防窃取/防无效区块）
- **只需胜过次优出价**，不是报全价 → 真实价值与获胜出价的差额 = 构建者利润
- 验证者（提议者）只需选出价最高且有效的区块

## 术语表要点（对共学有用的）

- **PBS**：提议者-构建者分离（The Merge 后架构原则）
- **MEV-Boost**：链下实现 PBS 的中间件（验证者通过中继接构建者市场）
- **OFA**：订单流拍卖（钱包把用户交易拍卖给搜索者/构建者，部分收益返还）
- **Intent/Solver**：意图（高层次目标表达）+ 求解器竞争满足（跨流动性源最优执行）
- **应用特定排序**：dApp 自定义排序规则（强制公平/减 MEV/自定义执行环境）
- **私有内存池**：绕过公共池直交构建者（防抢跑 + 构建者信息优势）

## 为什么重要（对我们的意义）

1. **MEV 的根源**：优先访问共享状态永远有经济价值——这是三明治/套利/backrun 存在的基础逻辑（Solana 侧 = Jito 拍卖等价物）
2. **「只需胜过次优出价」= 构建者利润来源**：理解了 relay 竞价机制，就理解为什么独有订单流=护城河（对应 RHC 机器人「链下模拟器是护城河」的结论）
3. **私有订单流占比上升**：92% DEX 交易量走私有 mempool（Part I 数据）→ 公共 mempool 机会在减少，但套利（原子/stat arb）仍通过 flashloan 和模拟器竞争
4. **位置市场 vs 纳入市场**：套利者付的是「位置费」不是「纳入费」——分析 tx 优先费时要区分（Robinhood 地址分析中 0.0045 失败成本 = 位置市场入场费）
