# 打卡 2026-08-06

## 今日分享

在共学群分享了 LI.FI 跨链执行基础设施的用法和 Agent 集成方式，核心内容：

1. **LI.FI 定位**：策略系统的执行层，不是策略本身。负责回答"资金怎么走、花多少钱、到哪一步了"。

2. **真实成本测算**：Ethereum 1,000 USDC → Arbitrum，LI.FI Service Fee 25bps + Gas ≈ 27.5bps 总显性成本。套利价差经常只有几十个bps，这个磨损会直接决定机会是否可执行。

3. **Break-even公式**：最低所需价差 = LI.FI费 + Bridge/DEX费 + 双链Gas + 滑点 + Price Impact + 延迟/失败成本。

4. **Agent集成**：LI.FI MCP Server (`https://mcp.li.quest/mcp`) 已提供只读工具，Hermes 可直接配置接入。签名/广播应交给隔离的钱包执行层。

5. **实测建议**：先做只读Route评估不交易，预置多链资金比临时跨链更可行，做好缓存和Rate Limit治理。

## 概念沉淀

区分了三层套利逻辑：
- **价差套利**（目标驱动）：跨所、三角、期现，买低卖高
- **MEV套利**（手段驱动）：三明治、Back-run，拼mempool+排序权
- **API套利**（应用层）：LI.FI/1inch/Jupiter，拼策略+资金+执行

个人开发者路线：API套利 → 积累策略能力 → 再考虑MEV。
