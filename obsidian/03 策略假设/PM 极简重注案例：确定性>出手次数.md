## 帖子内容

**案例**：PM 交易员六周 $500 → $177,000（累计仅 64 笔押注）

**策略（明确 5 条）**：
1. 放弃绝大多数机会，只等自己高度确定的比赛
2. 看准后重仓：单笔 5 万-10 万美元
3. 覆盖 CS 反恐精英 / Dota 2 电竞，偶尔网球
4. 专门押注**定价偏差**的一方（热门或冷门），持有至比赛结束
5. 每周仅靠少数几笔大额押注盈利，单笔最高获利 $77,000

**为什么极少人采用（作者自陈风险）**：
- 单笔过大，风险高度集中，心理压力极大
- 押注少，无分散掩护，每次判断对错直接影响账户
- 短期波动剧烈，一周不佳 = 账户亏数万
- 需要极强判断与信念，多数人不具备

## 与我们知识库的互证

| 案例要点 | 我们的认知 | 结论 |
|---|---|---|
| 只等高度确定的机会 | 「差价搬只在大价差进场」+「机会频率≠可执行频率」 | ✅ 同构：等确定窗口，不天天出手 |
| 定价偏差 + 持有至终场 | 我们「市场犯错即套利机会」（错误限价单/异常挂单=猎物） | ✅ 同构：吃定价偏差，不赌方向 |
| 电竞/网球窄赛道 | 「低竞争窄赛道」= 研究覆盖度=竞争拥挤度 | ✅ 吻合：冷门赛道竞争低 |
| 重仓 + 少次 | 我们 execution_guard：净收益门槛 + 资金护栏 | ⚠️ 他的重仓（$5-10万/笔）与我们「最小资金护栏」冲突——**他赢在定价能力，不是仓位大小** |
| 与 PM 涨跌盘（老鹰/0xPINK3）对照 | 那些是高频小步；这是低频重注 | ✅ 两个极端，中间是「48h 盘铺仓」 |

## 判定

归档。**思想吸收但执行不照搬**：
1. **「确定性 > 出手次数」**——与我们「肉在事件窗口、别天天交易」完全一致（第 3 次互证：taoli「大部分不成交」/runes_leo「12 个赢家」/本案例「64 笔」）
2. **电竞/网球 = 低竞争窄赛道实证**——PM 不止加密盘，电竞盘也有定价偏差机会（我们未覆盖的细分）
3. **风险警示**：$500→$177K 是幸存者偏差极端样本；他的重仓若无止损纪律 = 一次错误归零。我们用 execution_guard 护栏（≤20% 单笔、EXEC_APPROVED 人工确认）做「重注」的保险丝
4. referral 链接 = 推广性质（财经老王也是返佣推广者之一，与老鹰同族但内容质量稍高）
