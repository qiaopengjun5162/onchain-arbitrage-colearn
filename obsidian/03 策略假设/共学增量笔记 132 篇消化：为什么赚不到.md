- **067（starkxun）四周九个方向零成立总账** —— 资金费是离散事件（未跨结算收益为 0）、SVR 回收率 89.2% 且 Top1 solver 占 84.6%、COTI 单边触顶 45 小时净 +276.5 bps、厚尾均值/中位数差 21 倍、18 条错误清单 + 五问闭合检查器

## 高价值笔记速览（与用户研究线直接互证）

### ⭐ 010: Base/Morpho 清算执行手册（youchen-design，87 分）——事件驱动方向唯一实盘证据链
- **清算时点可预测**：预言机 0.5% 偏差 + 30 秒更新节奏 → HF 跌破 1 的时间窗口可算（1.008×985/1000=0.99288 式预计算）
- **决胜变量是延迟不是报价**：Flashblocks 200ms 子区块先到先得；同场竞争赢家付 2.5 gwei 赚 $10,679，付 25 gwei 的慢一个桶只捞 $254（**付更多 gas ≠ 更早，快一个桶 > 贵一个数量级**）
- **落袋率 81.7%**：22 笔理论毛利 $58,060 → 实际 $47,420；出货深度是天花板（不是进场是出场）
- **onMorphoLiquidate 回调先给抵押品、零本金不用闪贷**；抢输纯亏 gas（$1–36 残渣扣 $6 gas 几乎全赔）
- 7 天 159 笔事件驱动；HF<1×抵押品流动性>0 筛选（cbXRP/cbDOGE/cbADA 类长尾）
- → 互证：我们清算哨兵（DeFi Sphere API）同族；L2 清算 vs Solana 原子套利的竞争结构差异 = **清算拼预言机节奏预测 + 事件检测，不拼排序权**

### ⭐ 027: 竞品拆解（xzone911，90 分）——方法可直接复用
- 抽 3.5 万区块对手 108 笔成功交易，逐笔还原资金流（输入→路径→输出→利润 token）
- 三个差距全部对应代码能力缺口：live 链路没接某池、利润尾 token 被自己的过滤规则杀掉、多跳闭环被剪枝误杀
- **「成交≠净利润」**：样本 D 执行成功、扣 gas 后净亏——只看成交不看净利会高估自己差距
- 配套：010 逆向赢家合约（3 bytes calldata、利润扫到独立地址）；039 因果回放指标体系（Δindex、same-pool overlap、pre/post-S PnL）
- → 互证：我们 execution_quality_tracker 同思路，可加「对手 tx 逐笔还原」维度

### ⭐ 055 + 062: EV 模型 + 判断框架（Qy，80/89 分）——提交级台账的理论底座
- **055 EV 公式**：EV = p_land×P_land − p_revert×C_revert − p_drop×C_drop − C_infra − C_capital − C_rebalance；失败三分法（未纳入/回滚/微利成功——回滚烧 gas、未纳入也有基建+机会成本）
- **延迟衰减实证**：P(t)=P0·e^(−λt)，300ms 延迟把净利润从 0.95 打到 0.11 USDC；L0–L5 证据分级（L5 = 整组真实提交统计）
- **062 五问**：同状态为正？原子执行？可回滚？失败+竞争成本计入？可被证伪？；P_min 保护线须覆盖 Gas 误差+状态变化+失败成本+目标利润；**池子重叠使两条独立报价相加即高估**
- 058 配套：p_mev>0.6 设为 IGNORE 规则、不因信号放宽滑点
- → 互证：我们门槛公式（expectedSurplus > successGas + 失败摊派 + 机会成本×1.2）同构，055 补了 p_drop 维度（未纳入概率）

### ⭐ 008: Jito tip 拍卖机制（jinnzy，80 分）——同块排序痛点的机制底
- Bundle ≤5 笔、同 slot、全成全败；tip 下限 1000 lamports（只是被拍卖考虑的下限，实测要 >P99 才稳定落地——与我们 2026-08-15/16 实测完全一致）
- **拍卖结构**：50ms tick、按账户锁冲突分组并行、组内按 tip/CU 效率排序
- priority fee/tip 建议 70/30 分配；窗口 = 400ms 级 slot
- → 互证：我们 jito_bundle_pipeline v2（动态 tip = clamp(99th×1.5, 0.005, 0.01)）是同一机制的落地经验

### ⭐ 067: 四周九个方向零成立总账（starkxun，88 分）——「残酷」二字的量化
- 九个方向全部无正 EV 实盘结论；资金费=离散结算事件（不跨结算点收益为 0）
- 忽略 eMode 使自算 HF 低 16.61%；SVR 回收 89.2% 清算奖励、Top1 solver 占 84.6%（清算也高度中心化）
- COTI 单边触顶 45 小时净 +276.5 bps（各所结算上限不同造成结构性价差）；OU 半衰期 7–22h；自相关修正后高 carry 标的 t 值不显著
- 厚尾：均值/中位数差 21 倍——回测均值会被极值污染
- → 互证：我们 D19 四方向「费率事件窗口 > 原子套利」的排序；starkxun 的「离散结算」与我们的「事件驱动」是同一结论

### ⭐ 035/003/039/060: 为什么大众套利赚不到（多作者互证）
- **035（Zhou Junjie）common-value 拍卖**：可机械复制的毛利会被 priority fee 竞价瓜分——「**成交了，但利润归别人**」；插针行情 ETH −5.2%/SOL −11.5%，PUMP 3.5% 价差被提币 1–5 分钟延迟杀死；清算 5–10% 折扣才是确定性机会
- **003（Web3Rason）tip 因果链**：规模→毛利→可承受 tip→排序；公开机会的终局是利润竞价给 Builder；6,000U 仓位付 3–4U tip ≈ 5–6.7bps；主网竞价成本藏在 gas 栏外（6 区块 $56,000 不进 gas 字段）；未刷新候选中 72.7% 被取消（预期有效性约 27%）；AMM 估算 vs Quoter 差 70–100 倍且翻号
- **039（QQQ）R32x 高频微利钱包**：24h 约 30.1 万笔、每笔净利约 $0.0098、成本占 Revenue 46.5%、**Jito tip 占首尾差额 57%**；⚠️ ShredStream 2026-09-05 下线须迁 DoubleZero（低延迟数据源可替换性）
- **060（x-tan-dev）PBS/State Drift**：bundle 是 builder 承诺的顺序原子不可拆；**State Drift 是 searcher 头号亏损来源**（模拟盈利、上链 revert、小费照付）；P99 tail latency 才要命
- **044（xsl）模拟必须绑定执行过的区块状态**：双腿都用 latest 可能分属 N 与 N+1 块；leg1.block_hash ≠ leg2.block_hash → REJECT_STATE_MISMATCH；最小记录 = block_number/hash + calldata_hash + state_override

## 与「同块排序」痛点的互证（用户 08-24 提问）

用户在群里提出「卷速度做到同块了，发现同块还得排序，挤不进去还是赚不到」→ 本批笔记给出机制级答案：

1. **排序权 = 资本游戏，不是技术游戏**：leader 频率 ∝ 质押占比（1 万 SOL 对全网数亿 SOL ≈ 每天 7 个 400ms slot）；买（Jito tip 竞拍）> 造（当 leader，亿级资本门槛）
2. **035 公式化表达**：大众看得懂的机会 = common-value 拍卖，毛利被竞价吃光；「研究覆盖度 = 竞争拥挤度」在链上表现为 tip 出价直接吞利润
3. **003 补充**：公开机会终局是利润竞价给 Builder；有效候选率仅 ~27%
4. **060**：即使抢到位置，state drift 也会让模拟盈利变成链上 revert
5. **结论**：D19 四方向「原子套利排除」被本批证据强化——个人 edge 在事件窗口（清算/插针/新池），不在排序权
