# 跨所价差套利 Demo 决策记录（2026-08-08）

> 来源：Paxon 群内发言（2026-08-08）+ 共学群截图（「套利工具Astro与QQQ.bot讨论」话题确认）
> 关联：`[[Astro CEX 套利产品调研]]`、`notes/funding-fee-arbitrage-1token.md`

## 用户决策（原话要点）

1. **连交易所**：最好建**子账号**放小钱测试 + 设置 **API key 白名单**（绑定 IP）
2. **工具定位**：Astro / qqq.bot 都只是对接多个交易所的下单工具——**担心安全就让 AI 写一个类似的**
3. **CEX 搞自动 = 量化/做市**了，先手动跑一遍（就算亏钱）知道流程是干嘛的
4. **学习套利需要一个最小可行的 demo，从 demo 开始一步步往前走**
5. 三明治、清算、搬砖、跨链搬砖——**不同策略不同资金要求**
6. **套利策略比脚本代码更难找，copy 别人的策略比自己想更容易**
7. **最简单入手 = 不同交易所价差套利**：交易所 API 很健全，直接用 AI 说，自己把握细节

## 方法论结论

- 学习路径：**手动 → 半自动监控 → 小资金自动**，安全边界 = 子账号 + 白名单 + 小钱
- 策略来源：优先复制成熟策略（Astro 网格参数、资金费率套利框架），再自己调细节
- 跨所现货价差是 CEX 侧最简单策略：API 健全、无需链上 gas、无智能合约风险
- 风险控制：先只读监控（watchdog + 人工决策），绝不默认全自动下单
