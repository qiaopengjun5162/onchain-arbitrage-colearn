## 2. tonyke-bot/burberry — paradigm/artemis 改良 fork

- 153 stars，Rust。artemis 是 Paradigm 的 MEV 框架，模块化、事件驱动
- 结构：`engine.rs` + `action_submitter/` + `collector/` + `executor/` + `examples/`(map.rs, subscribe_mempool.rs)
- **引擎事件流**：链上数据源 → Collector → Engine+Strategy(`examples/map.rs`) → Executor → ActionSubmitter(上链)
- **与四层概念框架对应**：burberry = 「套利执行层」标准化样本。对比 BaseBuster（同层但实战 bot、已不编译）：**先读 burberry 建模块心智，再用 BaseBuster 的 0.02 美元时薪校准预期**

## 3. fuzzland/sui-mev — Sui 链套利 Bot

- 775 stars，Rust，作者 shouc（fuzzland 创始人），单次 commit 即 release 定型
- 运行：`cargo run -r --bin arb start-bot -- --private-key {}`
- 支持 10 个 Sui DEX（Cetus / Deepbook / BlueMove / FlowX …）
- **Relay 设计**：让验证者节点把 mempool 交易推到 relay server → bot，本质是"用验证者私有可见性做 MEV"
- **Sui 特殊性**：Narwhal-Bullshark + 对象模型，无公共 mempool；机会集中在 shared object（Deepbook 订单簿）
- **特有细节**：`merge_gas.sh`（合并 gas 对象）、`pool_related_ids.txt`（监控池 object ID）、`rust-toolchain.toml`
- **与四层框架对应**：`relay`=数据层+MEV深水区，`arb`=机会扫描+套利执行。完整端到端 bot，跨链（Sui/Move）参考实现

## 三链 MEV 通道对照

| 项目 | 链 | 学习角度 | MEV 通道模型 |
|---|---|---|---|
| BaseBuster | Base (EVM) | 现实收益预期（时薪 0.02 美元） | 公共 mempool → flashbots bundle / 公开 |
| burberry | Ethereum | 引擎模块分层 | 公共 mempool 订阅 + ActionSubmitter |
| sui-mev | Sui (Move) | 无 mempool 链的 relay 私有通道 | 验证者 relay 私有流 → bot → 上链 |

EVM 拼订阅+竞价；Solana 无公开 mempool、交易发 leader、Jito bundle 私有通道；Sui 无公开 mempool、靠验证者 relay 私有流。机制不同但目标一致：**在别人之前把套利交易放上链**。
