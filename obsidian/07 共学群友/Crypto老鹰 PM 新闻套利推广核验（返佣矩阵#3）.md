- 叙事：安卡拉 21 岁学生，1 个月开发交易机器人，一晚 $14,000；月稳收 $5-7 万（年 $60 万）

## 思想提取（与其他帖合并）

**「新闻事件 → 订单簿滞后窗口」= 事件驱动的时间差版**：
- 与我们已有的：闭市漂移（bStock）、涨幅差重置（ETF/TQQQ）、币安延迟价差（#2 帖）**全部同族**——**同一个资产/信息在两个市场定价不同步**
- 30-90 秒窗口 = 「快变量吃慢变量」的极端版（比闭市漂移的分钟级更快）
- 关键差异：**PM 需要新闻 API + 模型标定**，我们现有 CEX 数据流更简单

## 判定

归档。**思想吸收，执行不照搬**：
1. 「订单簿滞后窗口」已是我们事件驱动方向的第 5 个同族案例（闭市漂移/ETF 重置/币安延迟/新闻滞后/下架事件）——**「时间差套利」家族越来越完整**
2. 新闻套利对我们门槛高（需新闻源 + 标定 + CLOB 直连），不做
