### 币股 / RWA

- perp 市场三分法（majors/altcoins/equity&commodity），唯一空位=equity&commodity 面向亚洲散户；binary format 占 Polymarket/Kalshi 加密类交易量 60–80%
- SanDisk SNDK 事件：KOL 粉丝流泵薄 bStock/perp 簿→对冲仓位近爆仓——**对冲工具链不存在**（进场容易退出难）
- Neutrl 停赎事故：$53.7M 冻结 + 法律顾问介入——「停赎+法律顾问」= 链下风险爆穿信号

### 执行 / 成本模型

- **V2 大额利润非线性**：$100→+9.32% / $1,000→+9.12% / $5,000→+8.26% / $50,000→−0.56% 亏损（大额把便宜池推贵）；按储备 0.1%/1%/5% 三档模拟取最优
- **出场必须用卖出时点储备重算**：崩盘时流动性同步撤退，出场冲击常大于进场
- 可执行利润漏斗：100,000 机会→32,000 可执行→8,500 扣 gas 盈利→5,200 仿真→3,100 提交→1,240 上链→**980 真盈利（≈1%）**；13 种 failure reason 枚举
- LI.FI 报价拆账：总损耗 0.2876% 中**平台费占 87%**，剩余差额不能全写滑点；同区块模拟才是闭环唯一口径

### 工具 / 工程

- 金额精度模板：JSON 无 BigInt → 十进制字符串传输 + BigInt 比较；超 MAX_SAFE_INTEGER 会假 PASS；超精度 STOP 而非四舍五入；decimals 从 chainId+地址可信 Registry 读（不能信 symbol）
- REST 成功率实测：Bybit 99.58% / OKX 99.71% / HL 98.40% / **Binance 96.20% 最差**
- quote 比率（0.9975=0.25% 成本）≠ 真实跨链价差（同 token 各链现货价差）
