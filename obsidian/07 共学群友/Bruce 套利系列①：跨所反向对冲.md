## 文章核心（四做法 + 统一公式）

1. **两永续价差收敛**：A 高做空 + B 低做多，等价格靠拢。例：A=2/B=1 USDT，后 A=1.3/B=1.2 → 毛利润 900 USDT（A 腿 700 + B 腿 200）；价差可能继续扩大 → 先定退出条件和最大可承受损失（A 变 3 USDT = 爆仓/单腿风险）
2. **现货-永续基差**：现货买入 + 永续做空，赚基差收敛 + 资金费；反方向需借币（借币可用性/利率/提前召回）
3. **两永续资金费差**：价格接近但资金费不同，费有利边建仓 + 另一边反向对冲；净费 = A 腿实际收付 + B 腿实际收付；**页面预测费率不能当已锁定收益**
4. **跨所现货库存套利**：低价买 + 高价卖，**最易漏最后一步**：库存调回成本（充提/跨链/调仓，等待有风险）

**统一公式**：净利润 = 两腿价格盈亏 + 实际资金费收入 − 手续费/借币/充提/调仓/其他成本（价格冲击已含在实际报价，勿重复扣滑点；不同时成交要算单腿敞口损失）
