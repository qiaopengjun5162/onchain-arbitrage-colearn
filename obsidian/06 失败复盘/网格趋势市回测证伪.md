# 网格趋势市回测证伪

> 触发：X 推文「在金」vibe-coding 网格系统 4 交易所 6 账户 1 个月赚 1300U，评论区点破「这一个月没啥波动，网格特别舒服」。
> 假设：**网格盈利依赖低波动震荡市；趋势月靠单向库存浮亏把利润吃回去**——「低波动月赚钱」是市场给的面子，不是策略强。

## 结论先行

1. **幸存者偏差成立**：13 个月里下跌月亏损率 75~88%，非下跌月盈利率 100%；月净收益与 |月涨跌| 相关 -0.48 ~ -0.51。网格的钱 100% 在震荡里赚，趋势月无一例外亏
2. **结构上更扎心**：即使手续费为 0 全期依然净亏（窄区间 -$1,122）——趋势月库存浮亏（-$1,589~-$2,330）> 震荡月已实现价差（+$1,208）。**gross edge 是真的，但库存风险比 gross edge 更大**
3. **手续费 vs 格距是生死线**：90 档 BTC 网格格距仅 ~0.1%，双边 16bps 手续费直接吃掉价差；费率 0→10bps 净收益 -$1,122 → -$1,916。格距必须远大于 2× 费率
4. **杠杆把「单边突破」升级成「本金清零」**：10x 杠杆下 2026-01（月跌 -10.2%，不算最极端）单月回撤 10.2% 本金即爆仓。网格带杠杆 = 尾部从「大亏」变「归零」

## 回测口径（防伪要点）

- OKX BTC/USDT 1h 真实行情 10080 根（2025-06 → 2026-08），按月独立回测，区间=前 30 天极值×缓冲（无未来函数）
- 静态网格：L_i 买 → L_{i+1} 卖（v1 写成同档买卖 0 费永不赚，已修）；月末库存盯市计入浮亏
- 强平口径：月度内最大回撤 ≥ 保证金即判爆仓——单边突破「先打穿强平价再回来」，看月末净值会漏判

## 方法论贡献

- 「一个月测试」撞上 2026-07/08 低波动月不构成证据——样本窗口必须覆盖趋势月/极端行情（5 问之四）
- 与 CLMM「出区间=单边资产」同构：网格穿界风险是 AMM 集中流动性的对称问题
