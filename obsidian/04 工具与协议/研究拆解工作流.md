# 研究拆解工作流（L0011）

> 阶段三「用 Hermes 构建研究与信号工作流」核心方法：把「这玩意儿是不是机会」拆成可验证流水线。

## 五步框架

**观察 → 假设 → 证据 → 实验 → 决策**

| 步 | 产出形态 | 反例 |
|---|---|---|
| 观察 | 一句话 + 链接 | 只收藏不拆 |
| 假设 | 可证伪猜想 | 「牛逼」「学习了」 |
| 证据 | 链上取证数字 | 看页面标题 |
| 实验 | 成本模型跑净利 | 毛价差当净利 |
| 决策 | 闸门五问 + 风险清单 | 「感觉可以」 |

## T0-T5 六任务模板

```
T0 问题定义：一句话 + 判定标准
T1 元信息：blockscout /transactions/{hash}（from/to/status/gas/内部创建）
T2 主干：token-transfers 按时间画流 → 找循环（借→买→卖→还）
T3 身份：logs 认合约；Morpho 用 idToMarketParams(bytes32) 读四要素
        （新版 market(bytes32)=6×uint128 头寸数据，不是市场参数）
T4 成本：闪贷费·池 fee·借息·gas → 盈亏平衡线
T5 可复现：一次性 or 常驻？猎物特征？被搬平即失效？
```

## 实战验证（Morpho 闪贷灌金库，08-14）

- 从群友一个 tx 链接到「$297 净利 + 一次性 oracle/DEX 错价」结论，拆解 1 小时
- 关键坑：USDC 6 位 / sNUSD 18 位小数混算错一个数量级——先统一小数位再对账
- 完整案例：[[Morpho 闪贷灌金库 sNUSD 套利实战]]

## 分工模式

- 人：定义问题、定判定标准、复核结论（方向盘）
- Hermes：执行取证、跑数字、归档、同步（加速器）
- 取证动作固化进 skill，同类问题直接复用

## 衔接

- 一次性拆解 → 归档 notes/；值得盯的猎物特征 → 30 天证据流水线（[[L0013 证据记录体系]]）
- 下一步：同构猎物雷达（新生息代币 + vault 模式 oracle + 近空池）→ cron 收数
