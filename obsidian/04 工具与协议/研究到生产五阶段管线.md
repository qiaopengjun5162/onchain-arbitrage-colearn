# 从研究到生产：五阶段管线

**定位**：把「广撒网产出」收敛为「一条线走到底」的执行框架。每阶段有验收标准，不达标回上一阶段。

```
阶段0 策略研究    假设 + 5问筛选（口径/成本占比/返佣依赖/黑天鹅/容量）
阶段1 数据回测    历史数据跑数字（模拟器/证据流水线）
阶段2 脚本开发    监控/信号脚本（哨兵体系）
阶段3 模拟测试    paper trading（观察不实盘）
阶段4 生产测试    小额实盘 + 复盘（最小规模）
```

**原则**：
- 0-3 阶段 0 成本，阶段 4 才动用资金
- 发现机会 > 基建（顺序不能反）
- 每阶段 exit criteria 不达标回上一阶段

**当前位置（2026-08-14）**：0✅ / 1🔄（证据流水线收数中）/ 2✅（24 哨兵 + 雷达）/ 3-4 ⏳

**第一条全流程线候选**：币股闭市漂移（数据最扎实）> 跨所费率事件窗口 > PM 事件——D14 周总结定三选一。

**理解检验机制**：每天 15 分钟费曼复述——学习者用自己的话讲当天所学，AI 只提问纠正不代写。
