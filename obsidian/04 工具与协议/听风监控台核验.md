# 听风（wind.jokkimon.club）监控台核验与接入评估（2026-08-28）

> 触发：用户分享 https://wind.jokkimon.club/（@Jokki 的 JokkiMon 生态，by @Jokki）
> 方法：web_extract 页面全功能审读（28.6K 字符）+ 与库内监控基建对照
> 结论：**情报层工具（KOL 交易/喊单聚合 + 地址反查），非套利工具；「追风」反查补我们取证缺口，闭源+钱包登录需空钱包隔离；建议试用一周再定**

## 一、这是什么

第三方**全平台交易监控台**（非官方、闭源），聚合 X / Telegram / fomo（pump.fun）三类平台的监控账号动态，秒级实时流。

## 二、功能清单（页面审读）

- **实时流**：被监控账号的买卖/喊单/观点/共识卡片；按链筛选（含**币股=代币化股票**）、按类型筛选；每账号可单独设铃声/配色/事件偏好/链筛选；卡片含 CA/交易按钮
- **风向**：每日精选（23:55 收盘后出第一期）、Verify 新过审票、**近期共识**（多人同时段买同一币）、异动
- **追风**：**账号↔地址互查**——用户名/显示名反查钱包地址，地址反查是谁；支持 SOL + EVM；翻历史帖子；身份锚（改名后仍能认人）
- **查币**：贴 CA → 持有人数/交易量/均价/**前排 thesis**（谁在买、持仓均价、PnL）一屏看全，支持 EVM + Solana
- **监控列表**：目录推荐账号一键关注；支持 GMGN 订阅导出 JSON 直接粘贴批量导入
- **登录**：Telegram / EVM 钱包 / Solana 钱包（签名验证身份，声明永不接触资产、永不发起链上交易）/ Gmail（即将开放）；游客有监控名额上限，登录解锁独占名额 + 跨设备同步
- **币股筛选**：链筛选里明确有「币股（代币化股票）」选项——与我们的币股 RWA 线同题材

## 三、核验与安全评估

1. **闭源第三方工具**：无 repo 无开源声明，代码不可审计——同等风险级（Taoli 教训：主应用闭源 = 页面内逻辑不可审计）
2. **钱包登录**：页面自述「只需一次签名验证身份——永不接触资产、永不发起任何链上交易」，并建议「使用全新空钱包登录」+ 页面有防钓鱼提示（核对域名 wind.jokkimon.club）——按安全铁律执行：**空钱包 + 不授权任何交易**
3. 备选登录：Telegram 或 Gmail 零资产授权——比钱包更省心，但账号与交易行为绑定
4. 游客限制：监控名额有限（页面显示 guestMaxWatch），试用期够用

## 四、与库内对照

| 点 | 我们现状 | 听风补充 |

| 钱包反查 | onchain-address-forensics 手动（Polymarket 钱包定位靠 profile 页 HTML 0x 地址） | **追风 = 现成反查工具**（SOL/EVM），补取证效率缺口 |

## 五、判定与可执行项

1. **定位**：情报层工具（人层信号），不替代任何现有哨兵；价值 = ① 追风反查补取证缺口 ② 共识买入/异动当事件窗口前置信号 ③ 币股 KOL 动态
2. **接入评估（试用一周流程）**：
   - 空钱包（或 Telegram）登录 → 只加 3-5 个关键账号（币股/存储周期相关 KOL + 套利圈内人）→ 每天看实时流/共识/异动质量 → 一周后评估：命中率如何、噪声多大、值不值得占监控位
   - 关键验证点：追风反查准确率（拿 1-2 个已知地址测）、共识买入的时效性（多人同时段买入出现时价格还来不来得及）
3. **不付费不深度绑定**：闭源工具当辅助情报源，不当决策依赖；核心基建（自建哨兵）不动
4. 归属：8 组（量化监控 Bot 与工程实现）范围内的工具核验活
