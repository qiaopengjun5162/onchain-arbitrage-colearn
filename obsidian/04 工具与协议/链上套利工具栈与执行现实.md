# 链上套利工具栈与执行现实

> digest：Bruce Xu 官方工具文《做链上套利需要哪些工具？》+ 服务器方案评估 + Sequencer 287ms 实测

## 金句（顺序不能反）

**「工具当然有用，但顺序不能反过来。套利的关键是发现机会，不是基建。」**——先找到长期存在的价差，再谈优化速度。Bruce 自嘲：$2,000+ 组了服务器最后装了 Steam 玩了一年 CS。

## 工具栈速查

| 环节 | 工具 | 关键参数 |
|---|---|---|
| 报价/路由 | LI.FI | 100 RPM 免费 + 25bps 平台费（`integrator=jumper.exchange` 可归零，已实测）；70+ 链 |
| 行情/交易/钱包 | Binance Web3 API | 免费；Market/Trading/Transaction/Wallet 四类 |
| 对冲工具 | Taoli.tools | VIP0 免费 $5,000 上限；开源 Signer（EVM+Solana） |
| 发现层 | DEX Screener/DeFiLlama/Dune/Etherscan | 免费；Dune 60-300 次/分 |
| RPC | 公共（chainlist）→ QuickNode/Alchemy | 自建全节点预算 $1k-1.5k（不只月租）；初期用托管 |
| 私有交易 | Flashbots Protect / MEV Blocker / bloXroute | 防抢跑夹子；不保证成交/最佳价 |

## 服务器方案评估（H1/H2/H3 方案）

- 三机方案 $240-430/月：**研究/监控期过度配置**——现有哨兵全跑在公共 RPC + 免费层 + 本地 cron，0 成本
- 自建全节点只在：大数据回测 / 低延迟 MEV / 429 卡死业务（Helius $49 付费层即可解）
- Solana 128GB 硬门槛合理；Ethereum 首次同步别在监控盘上做

## Sequencer 287ms（L2 公共路径速度地板）

```
模拟+Gas 47.76ms → 签名 0.084ms → 广播 55.43ms → 触发→提交 145ms → 链上确认 142ms
```

- L2 无 Jito 式排序拍卖 → 个人 bot 别抢毫秒级，结构性机会（错价池/事件驱动）不需要
- 优化打大头：并行广播 + 预模拟缓存可省 ~70ms；链上确认 142ms 省不掉
- 专业队 sequencer 直连再砍一半——差距在基建不在代码

## 安全五规则（私钥=资产归零线）

1. 独立小额热钱包
2. API Key 不开放提现
3. 链上限单笔/日累计/目标合约
4. allowance 检查 + 停止期取消
5. **独立 Signer 签名机**（业务程序只生成待签交易）
