# AMM 数学 x*y=k

> D8 预习：Uniswap V2 恒定乘积推导 + Python 手算验证。核心结论：滑点曲线就是容量曲线。

## 核心公式

- 恒定乘积：池内储备 x × y = 常数 k，任何 swap 保持 k 不变（扣费后按有效输入重新平衡）
- 现货价（边际价格）：1 X = y/x Y——链上读两个 vault 余额就能定价
- 带费输出：Δy = y − k/(x + Δx·(1−fee))；手续费按有效输入扣，fee 部分留在池子变 LP 收入
- 价格冲击 = 无费理想输出 − 实际输出；总滑点 = 手续费 + 价格冲击

## 真实数据验证（Raydium SOL-USDC）

- 储备 SOL 67,851.11 / USDC 5,033,520.92 → 现货价 $74.1848 ✓
- 1 SOL swap 输出 **73.9612 USDC = 实测值，误差 0**
- **费率反推发现：Raydium 有效费率 0.30%（30bps）不是 25bps**（0.25% 算得 73.9982 差 0.037）
- 深池 vs 薄池（同池不同规模）：1 SOL 滑点 0.251% → 1000 SOL **1.695%**——冲击项从 100 SOL 起才显著

## 关键直觉

1. **价格冲击是凸函数**：仓位越大边际成本越陡。套利利润门槛在深池主要看手续费，在薄池主要看冲击
2. **k 守恒 = 套利者的猎物**：链上某池价格偏离市价时，x*y=k 保证买低卖高后储备回到市场价——Jito 原子套利的数据基础
3. **手续费是 LP 的卖铲子收入**：0.30% 每次 swap 都抽，高频下是稳定现金流，但 LP 承担无常损失

## 与知识库互证

- 滑点曲线 = 容量曲线 → 直接支撑 #13 低容量结构性价差量化（薄池扫描模式 = 算每个池的容量上限）
- 出区间=单边资产（CLMM 预告）→ 与网格穿界风险同构
