# 下架合约价差套利

来源：Paxon 群分享策略「bn 下架合约价差能有几十个点，盯着 OI 猛干就好了」+ 2026-08-07 结算批次实证验证（✅）

## 一句话

币安下架合约前 12–24 小时，被下架永续合约相对现货出现 1–4% 的溢价（方向为合约溢价现货），空头越拥挤、结算买压越大，价差越极端——OI 活跃度是窗口信号，多空比决定方向。

## 结论

1. **策略真实存在且已被数据验证**：下架前 12–24h 是确定性事件窗口，价差 1–4%，伴随天量平仓。
2. **「盯着 OI 猛干」的正确解读是「盯 OI 活跃度 + 多空比失衡方向」**：OI 绝对值方向不决定价差（HFT 的 OI +174.5% 与 ACX 的 OI −51.8% 方向相反，但价差都放大），OI 剧烈变化才是窗口打开的信号；L/S ratio 决定净方向。
3. **核心机制**：下架公告 → 空头大举进入（赌跌/吃 funding）→ 结算时空头必须买回平仓 = 确定性买压 → 合约价被推高 → 溢价现货。空头越拥挤（ratio 越低），结算买压越大，价差越极端。
4. **事件窗口短、波动剧烈、方向不定**，是典型的「高胜率但尾部凶险」策略，必须按 [[套利风控总纲]] 控制敞口。

## 为什么重要

- 这是**事件驱动型确定性窗口**：下架时间表公开、结算机制强制平仓，买压是机械性的而非博弈性的，edge 来源清晰（强制平仓 = 非弹性需求）。
- 为 [[套利策略全景]] 补上「交易所事件驱动的价差」这一类：与 [[跨所资金费率套利]] 的持续收费不同，这里是**一次性确定性事件**，容量小但单次收益高。
- 提供了可复用的**领先指标组合**：OI 活跃度（窗口信号）+ L/S ratio（方向预测因子），这套指标方法论可迁移到其他事件驱动场景（升级、硬分叉、大额解锁）。
- 再次验证了 [[套利第一性原理框架]] 的视角：先问「对手方为什么必须成交」，下架结算的空头就是那个必须成交的对手方。

## 证据

### 2026-08-07 09:00 UTC 结算批次

币安结算下架：ACX/HFT/PIVX/PYR/VANRY/VIC 永续（现货 8/17 才下架——对冲窗口存在）。

**HFT（最强案例）**

| 指标 | 值 |
|---|---|
| 价差峰值 | **439.2 bps（4.4%）** |
| 最后 6h 平均 | 226 bps（2.26%） |
| 全程平均 | 64.6 bps |
| 合约量峰值 | 12.55 亿/h |

**ACX（次强案例）**

| 指标 | 值 |
|---|---|
| 价差峰值 | 122.7 bps（1.23%） |
| 最后 6h 平均 | 70.4 bps |
| 全程平均 | 25.6 bps（min −48.9） |
| 合约量峰值 | 1.37 亿/h |

### 多批次横向证据

- 4 月批次：DENT 峰值 195.4 bps（量 325 亿/h）、TRU 171.4 bps、AI 153.8 bps——「几十个点」是常态。
- 方向不总是单边：ACX 出现 −48.9 bps 合约折价，说明净方向取决于多空比，不能无脑做空合约。

### OI 实证（修正「盯 OI」逻辑）

- **HFT：OI +174.5%**（2 亿 → 5.47 亿）——公告后投机潮涌入，价差峰值 439 bps 出现在 OI 峰值附近。
- **ACX：OI −51.8%**（5727 万 → 2760 万）——持仓者提前离场，价差峰值 123 bps。
- **结论：OI 绝对值方向不决定价差，OI 活跃度（剧烈变化）才是窗口信号。**

### L/S ratio 是价差强预测因子（92h 对齐实证）

- **空头主导（ratio<0.5，22h）：价差均值 162.7 bps**
- **多头主导（ratio≥0.5，70h）：价差均值 38.6 bps**
- 价差峰值 439 bps 正出现在 ratio 跌至 0.407 时；结算前 ratio 从 0.53 一路跌到 0.31。
- ACX 的 −49 bps 折价也解释通了：折价出现时 L/S ratio 必然偏向多头（多头拥挤 → 结算卖压）。

## 假设

1. **空头拥挤 → 结算买压 → 合约溢价**：ratio<0.5 时价差均值 162.7 bps vs 多头主导 38.6 bps，支持该机制；但样本仅 2 币种 × 92h，需更多批次验证。
2. **OI 活跃度（变化率）驱动价差**：HFT（OI 暴涨）与 ACX（OI 暴跌）两案例方向相反但价差都大；「OI 剧烈变化 = 窗口打开」需更多样本验证。
3. **现货下架晚于合约**：对冲腿在结算窗口内存活是前提（本次现货 8/17 才下架，窗口存在）。
4. **价差可吃**：统计到的价差是 kline 对齐的名义价差，真实可成交价差需扣滑点与冲击成本。

## 风险

| 风险 | 本次案例证据 |
|---|---|
| 对冲腿卡死 | ACX 现货窗口存在，但 PIVX 等现货数据已异常——不是所有币都有干净对冲腿 |
| 方向不确定 | ACX 出现折价 −49 bps，HFT 是溢价——净方向要盯 L/S ratio，不能无脑做空合约 |
| 流动性陷阱 | 价差 4.4% 但盘口薄，进场冲击成本未知（需订单簿验证） |
| 时间风险 | 价差收敛节奏不定（HFT 在 41↔439 bps 大幅摆动），进场时机决定收益 |
| 数据可得性 | 部分 OI/多空比数据源受地区限制，需换源获取 |
