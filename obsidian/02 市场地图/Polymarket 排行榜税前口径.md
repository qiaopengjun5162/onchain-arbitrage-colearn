# Polymarket 排行榜税前口径

> 触发：X 推文称排行榜收益是税前（gross）、榜前地址真实到手仅 24-45%、返佣按手续费比例返（返佣多=坏信号）。不用信推文，用公开 API 重建验证。

## 结论先行

1. **手续费公式逐档验证正确**：100 股 × 0.07 × p×(1−p) → p=0.50 时 $1.75、p=0.99 时 $0.07。p=0.50 手续费是 p=0.99 的 25 倍（价位决定成本）
2. **每股手续费实测 0.0122–0.0142**，与推文吻合；对毛 edge 每股 $0.007–0.016 的吃单 bot，费用与 edge 同量级 → 直接翻负
3. **返佣真实且可量化**：Djdjdjekekek 11 天 TAKER_REBATE $57,467 + MAKER_REBATE $17,119 = **$74,586**（返佣是榜外真实回流）
4. **榜单确实 gross**：费用是额外成本、返佣是额外收入，都不在榜单数字里
5. **实锤「榜单 vs 真实方向反转」**：HomeRunHazard 月榜 +$453,919，近 11 天纯交易 −$121,337（每股 edge −0.0348）——照榜学策略会学到正在亏钱的人
6. **修正推文表述**：24–45% 只适用于「edge≈费用」的吃单 bot；有真 edge 的地址（每股 edge ≈ 4× 每股费）到手率 ~82–92%
