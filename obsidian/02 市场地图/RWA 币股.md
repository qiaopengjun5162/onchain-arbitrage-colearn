# RWA 币股套利

> 群友：这么多发行方都和股票锚定，感觉和稳定币套利思路很像。Binance Web3 API 支持 bstock、Ondo、xStocks，机会很大。

## 为什么"和稳定币套利思路很像"

稳定币：多发行方各自承诺 1:1 锚定美元，二级市场价格短期脱锚，价差+赎回通道=套利空间。

币股同构：
- **同一底层，多个发行方**：AAPL 有 Ondo 版、xStocks 版、bstock 版，各自铸造/赎回规则、支持链、费用、门槛不同
- **锚定机制不同**：可赎回（KYC）/ 仅二级流通 / ETF 持仓。锚定越硬收敛越快，越软价差越持久
- **多了"时钟差"维度**：股票有开闭市，闭市期间链上币股仍在交易、纯靠做市商和情绪定价，常漂移；开盘瞬间向真实股价收敛（稳定币套利没有这个）

## 四条路线对照

| 路线 | 结构 | 门槛 |
|---|---|---|
| A. 期现套利（币股版） | 链上现货 + 合约做空，锁定价差吃资金费 | 中；闭市对冲失效 |
| B. 股票 vs 链上币股（跨市场） | 链上买折价币股 + 券商做空真股票 | 高；需做空券商+借券 |
| C. 组 LP 吃手续费 | 做市收过路费 | 低但闭市漂移有无常损失 |
| **D. 发行方间价差** | 同股票 Ondo/xStocks/bstock 同刻价差，三腿全链上 | **最低**，稳定币套利直接平移 |

**建议推进顺序**：先做 D 的数据监控（纯观察不交易）→ 用 B 当定价锚理解 D 成因 → 数据跑出规律再判断 A/C。

## 产品形态对照

| 类型 | 映射 | 时段 | 说明 |
|---|---|---|---|
| ADR | 完全映射 | 与美股同步 | 传统存托凭证 1:1 |
| bStock | 底层映射 | 7×24 | 闭市漂移是套利窗口 |
| 合约 | 不映射 | 7×24 | 永续对赌，无实物锚定 |

bStock 7×24 + 正股仅美股时段 = "机制差"套利来源。

## Binance Web3 Trading API 实测要点（D3，2026-08-07）

- DEX 聚合器：quote / swap / quote-and-swap(Flash) / approve / history / order submit(RFQ)
- **SWAP**（普通代币、含 bStock LiquidMesh）vs **RFQ**（权益代币 Ondo/BStock，EIP-712 签名→提交→轮询）
- 权益代币集：Ondo(type=1)、BStock(type=3)，**严格互斥**
- **关键约束**：`quoteId` 有效期仅 30 秒；非交易时段 Ondo/BStock API 直接拒绝（40367/40369）——闭市漂移窗口内无法用官方 RFQ 套利；RFQ 需 EIP-712 签名+提交+轮询，多 3 步，自动化门槛高但竞争者少

## 关键风险（不同于稳定币）

- **赎回门槛**：币股赎回多要 KYC+合格投资者，散户可能只能"单腿"（赌收敛，非真套利）
- **流动性薄**：TVL/成交量远低于主流币，冲击成本高
- **企业行动**：拆股/分红/并购代币如何处理，各发行方不同
- **合规风险**：司法辖区合法性差异大，政策变化可能直接归零某路径
