# Bitget 资金费逃票查证

## 一句话

**逃票不成立**：主流币费率被钳制 ±0.01%（p99=0.0100%），往返手续费 0.12% 是费率的 12 倍，100 期 0 期扣费后为正——结构性倒挂。

## 官方规则（核验）

- **结算频率分叉**：主流币（BTC/ETH/SOL）8h 结算（实测北京时间 08:00/16:00/00:00）；长尾币 4h（COW/ACE/WAL/ALICE/HOME）；个别 1h（PROM）
- ⚠️ 官方文档写 07:00/15:00/23:00 (UTC+8) **已过时**，实测差 1 小时——以 API fundingTime 为准
- 结算时点持有仓位才收付；正费率多头付空头；资金费用 = 费率 × 仓位价值（与杠杆无关）
- 特殊条款「至多扣至维持保证金率」：书面推演 10x/100x 均不触发，无逃票空间

## 实测（100 期 ≈ 33 天）

| 币 | 均值 | p99 | 扣费后净正期数 |
|---|---|---|---|
| BTC | +0.0037% | +0.0100% | 0/100 |
| ETH | +0.0042% | +0.0100% | 0/100 |
| SOL | +0.0041% | +0.0100% | 0/100 |

- 长尾币高费率（COW −2%/ACE −1.13%）**全是负费率**（空头付费，方向相反）且是**单次事件**（COW 99 期 +0.005% 常态）
- 结论：「常态空间负、肉在事件窗口」再次印证——但这类事件是负费率+无对冲腿=方向性投机，出局

## 方法论（四步查证范式，30 分钟出结论）

1. 官方规则：结算频率/方向/特殊条款
2. 历史费率分布：钳制位（±0.01%）
3. 手续费门槛：往返 0.12% 对比
4. 事件性验证：高费率是常态还是单次
