# 跨所资金费率套利

来源：1Token《资金费套利策略》+ 群讨论（2026-08-05/06）

## 核心机制

资金费率是永续合约让合约价格贴近现货/指数的机制，多空双方定期支付，不是交易所手续费。

- 正资金费：做空永续 + 买入等量现货
- 负资金费：做多永续 + 借币卖出现货（前提借币利率 < 资金费收益）
- 资金费 = 资金费率 × 头寸名义价值

## 主要风险（"套利不是无风险"的典型）

1. **逼空和强平**：现货+永续完全对冲，但杠杆过高/集中，极端行情下基差拉开 → 保证金不足。看单账户维持保证金率、超额保证金、单币种集中度、抵押品折价、基差
2. **ADL 强行减仓**：盈利侧被强减 → 突然暴露敞口，需第一时间探测仓位变化并决策（市价平/限价平/人工）
3. **抵押品折价**：非稳定币抵押会被折价，要看交易所风控认可的抵押品价值
4. **Maker/Taker 执行风险**：maker 成本低但暴露 delta；taker 成本高且带滑点
5. **基差即成本**：高资金费 = perp 偏离大 = 入场时已在偏离价位成交。真实收益 ≈ 资金费 − 基差收敛成本 − 双边手续费滑点。比较机会要同时看 basis 历史分位

## 策略风格维度

| 维度 | 选项 |
|---|---|
| 场所 | 同所（组合保证金、容量大）/ 跨所（成本高风险低容量低） |
| 币种 | 大币（稳定）/ 小币（费率高但折价+集中度风险高） |
| 标的 | 现货+USDT 永续 / 现货+USDC 永续 / U 本位+币本位 |
| 调仓 | 主动（追高费率，执行要求高）/ 被动（统计+持仓管理） |
| 成交 | maker+taker / taker+taker / maker+maker |

## 群友入门建议（诚实分层）

> 资金费套利非常简单可操作（赚钱另说），统一账户的现货合约资费套利、LP 组建都可先试。

- **统一账户（组合保证金）是新手正确入口**：抵押品共享，对冲腿保证金占用最低
- **"简单可操作，赚钱另说"是诚实分层**：先练风控和记账闭环，不指望出 edge

## 简单实现步骤（Paxon）

1. 扫描 Binance 合约资金费率，找高额正资费且有现货的币种
2. 对冲开仓：合约做空 + 现货买入（手动或 API）
3. 吃费率：持有到结算收资金费，价格波动由对冲平衡
4. 退出：费率趋近 0 时平仓

### 核心结论：资金费套利 = 卖保险

收确定的保费（资费），扛不确定的赔付（暴涨）。**赔付上限（保证金）才是生死线，保费只是零花钱。**

- 刚暴拉的币做 SF 有风险：基差虚高（合约涨得比现货凶，收敛时反噬）+ 高资费是过热信号 + 深度薄滑点吃利润
- 冲高回落→横盘后吃资费最稳：波动率降 → 方向性风险≈0，但多头仓位没走 → 资费维持高位收租不变
- 金句：**资费高 ≠ 机会好，波动降下来资费还高才是机会好**

### CrossEx 底层盈利点拆解（08-20 群分析）

**结论：CrossEx = Gate 用重基建换返佣流量入口的生意。** 用户免费/低价用跨所协同，Gate 赚交易量返佣。

- 返佣（主菜）：Gate 在 Binance/OKX 底层高返佣做市商账户，用户下单成交记其头上 → 交易额返佣归 Gate；官方卖点「交易量合并统计」就是为提 VIP 等级拿更高返佣（闭环证据）
- 手续费（佐料）：机构/量化向，费率走 Gate VIP 档，撑不起系统成本
- 次要收入：联合保证金池闲置资金吃利息差；内部低延迟撮合赚双边价差
- 成本端：跨所撮合+联合保证金清算+多所风控联动=重基建 → 只有二线大所会做（聚合一线所流动性竞争；一线所无动力）
- **对套利者含义**：平台靠交易量返佣赚钱（非靠用户爆仓）→ 无恶意坑单动机；插针风险依然来自市场本身（TUT 剧本下照样爆仓）

### ⚠️ 合规风险：受限司法辖区（方案级，08-20 追加）

Gate 官方 Restricted Locations（用户协议 §2.5）：**美国、中国大陆、香港、新加坡、加拿大、英国、法国、德国、西班牙、荷兰、奥地利、马耳他、马来西亚、日本、韩国、印度、印尼、泰国、阿根廷、柬埔寨、UAE、俄罗斯、缅甸、委内瑞拉、乌兹别克斯坦等 35+ 辖区**。受限用户「可能被终止服务、强制平仓」，列表随时更新不另行通知（gate.com/help/guide/faq/40959/restricted-locations）。

- CrossEx 是 Gate 子产品 → 同一套风控，且机构/量化向 KYC 审核更严
- **身份/运营地在中国大陆或香港 → 账户终止+强制平仓是官方条款明确写的风险，非「可能」**
- 跨所连接 Binance/OKX 三方，风控联动更严；假资料/代理运营=冻结高风险
- 决策影响：合规前提=确认 KYC 资格；受限地区优先考虑**同所统一账户**（Bybit Unified / OKX Unified / Binance Portfolio Margin），或放弃 CrossEx 路线
- 行动项：开通前资格自检（身份地区 × 运营地 × Gate 最新受限列表）

### BNC 实测评估（08-20 真实数据否决）

> 用户计划用 BNC（妖币）实践。ccxt 实测 Binance/Bybit/OKX/Gate：**当前不宜做，三个硬伤**。

1. **无现货可对冲**：Binance/Bybit 只有永续（~$2.85），三所现货无 BNC；Gate "BNC/USDT" 现货 $0.0144 ≠ 永续 $2.85（相差 200 倍=同名不同物）→ SF 形态做不了，只能纯永续空吃资费（方向敞口全裸）
2. **深度极浅**：Binance 永续前 10 档 bid $2,211/ask $1,490，买卖价差 0.21% → 容量 $500-1,000 级，玩具仓
3. **资费被操控**：近 3 天 +0.49% → +0.27% → **-0.42%** → **+1.09%**，一天内剧烈跳变 = 费率诱导（TUT 剧本第一步）
4. **时机未到**：48h +12.9%、12h +7.6%、距高点 -3.5% → 拉升尾段，非「冲高回落横盘」

**决策**：放弃 BNC。等「资费连续 3+ 次结算同向 + 横盘确认」后，在 Bybit Unified 上选**有现货**的币做。
