```
① 池1 (WETH/USDG) → 机器人: USDG 53,768,973
```

**模式**：三池三角套利 + WETH 闪电铸——借 USDG → 买 FRONG → 卖 FRONG → 闪铸 WETH 平账。利润 ≈ 回款 − 闪铸费 − gas。

## 0xd712 完整画像（26 天，约 68 万笔）

**结论：高频原子化三角套利/MEV 执行账户，不是"选币胜率高"的交易钱包**

- 核心模式：链下搜索价差并模拟 → 一笔交易跨多池 → **有利润才结算，否则整笔回滚**（原子性）
- **DeBot 显示的"高胜率高收益"是统计幻觉，5 个来源**：
  1. 原子套利结构性胜率（失败回滚）
  2. 幸存者偏差（失败不计入）
  3. 极高频率（单笔利润极小，靠量堆）
  4. 毛利润口径（不一定扣失败 Gas）
  5. 执行器 ≠ 受益者（利润转其他地址）

呼应 [[套利第一性原理框架]]：只看胜利者样本会高估机会。

## 成本结构实测

- 闪铸费：0.5028%（最大摩擦项）
- gas：$0.03（RHC 极低）
- 三个池全是 CLMM（V3 风格），不是 V2 固定 0.3%——fee 分档或动态

**盈亏平衡**：跨池价差必须 > 0.5%（闪铸费）+ 两池 CLMM fee + gas，机器人才有利润。

## 方法论收获

1. **交易还原三件套**（已实战验证）：`token-transfers + internal-transactions + logs` 三个 blockscout API 端点即可完整还原任意 EVM 套利交易——「蒸馏别人交易方法」的基础设施（Solana 侧 = solscan/Helius）
2. **手续费 = 套利生死线**：评估机会先算摩擦成本（swap fee + 闪铸/闪电贷费 + gas + 滑点），价差必须盖过摩擦——见 [[套利成本模型]]
3. **闪铸 = 零本金杠杆**：Solana 对应闪电贷；借鉴"零本金验证机会"思路
4. **新链红利**：新链 = 流动性碎片化 = 价差窗口，与「上币公告监控」联动
5. **CLMM vs V2**：定价模型不同（tick 区间流动性 + 分档 fee）
