# 预测市场套利（Polymarket）

> 来源：0x 哆啦A梦 NO 回收套利帖 + pritipatelfgoo 数学原理帖（同论文 arXiv 2608.00666，2.59 亿笔历史交易）
> 定位：机制套利（协议规则产生的结构性机会），不是价格博弈

## 一句话

专业量化团队 2024.04-2025.04 从 Polymarket 提取约 **4000 万美元**套利收益（单市场 1058 万 + 篮子 2901 万 + 组合 9.56 万）；论文估算 NegRisk Adapter「NO 回收」机制套利 **111.8 万 USDC**（97% 来自 NegRisk）。但这是**机构级游戏**（Gurobi 求解器 + 毫秒级执行 + 50 万+ 资金 + 8600 万笔链上数据）——个人几乎无法复制，但认知可直接迁移。

## 两条深度（同一机会）

### 浅：NO 回收套利（机制玩法，可读可尝试）

- **恒等式**：NO A + NO B ≡ 1 美元现金 + YES C（三个互斥结果）
- **玩法**：低价挂 NO 买单 → 陆续成交 → 记录真实成本 → 找最赚钱子集 → Adapter 转换换回现金 + 剩余 YES → 处理剩余 YES → 循环
- **本质**：小型做市——NO 是原料、Adapter 是加工厂、剩余 YES 是副产品；利润由收货价、库存搭配、资金周转次数决定
- **风险**：库存风险（部分成交变成真方向仓位）、maker 不保证成交、剩余 YES 深度、利润中位数从 1 USDC 骤降到 0.08 USDC（拥挤化）
- **AI 降低门槛**：作者给出「只读 NO 库存优化器」开发需求；渐进路线：只读一周 → 模拟 maker → 小资金真实挂单 → 跑通再自动化。**别一上来把私钥交给 AI**

### 深：套利数学内核（机构级，学认知）

- **Marginal Polytope（边际多面体）**：YES+NO=1 是最底层；真套利来自市场间逻辑依赖（如「共和党赢 5%+」⇒「特朗普赢宾州」）。n 条件理论 2ⁿ 结果，用整数规划把指数搜索压到毫秒级。论文实测 17,218 市场条件中 **7,051 个（41%）存在单市场套利**——市场远没想象中有效
- **Bregman Projection**：把当前价格投影到无套利空间。LMSR 下 Bregman 散度 = KL 散度（符合概率定价逻辑）。投影同时给出：μ*（该交易什么）、D（能赚多少）、∇D（怎么下单）
- **Frank-Wolfe**：指数级顶点逐步扩展，每次迭代只加一个点（100 次=100 关键点 vs 2⁶³）。Gurobi 求解，比赛开始 <1s、中期 10-30s
- **非原子执行（关键）**：CLOB 每笔订单独立撮合，不能保证同时成交——发现套利 ≠ 赚到钱。论文只统计利润 ≥0.05 美元的机会（低于此被滑点/波动/延迟/Gas 吃光）。跟单快钱包几乎赚不到（给别人提供退出流动性）

## 与个人套利者的关系（诚实）

- 这是「拼数学 + 拼工程 + 拼资金」的机构游戏，**个人无法复制**
- 但认知可迁移：市场间逻辑依赖 = 套利来源；KL = 正确的价格距离；非原子执行风险适用于任何订单簿套利
- **当散户/跟单者 = 给别人提供流动性**（论文反复证明）。个人 edge 在「新市场依赖关系发现」（DeepSeek 自动分析市场依赖思路可简化后用）

## 与主线呼应

- 呼应 [[套利第一性原理框架]]：非原子执行 = 「能否原子锁定」检查不成立，呼应四道检查
- 呼应 [[套利策略全景]]：属「机制/规则套利」类（新规则 edge），非价格博弈
- 呼应 [[MEV]]：CLOB 非原子成交 = 订单簿撮合模型，与 AMM 不同
- 论文方法可迁移：DeepSeek 判断市场依赖（81% 准确率）→ 人工确认 = AI 辅助研究标准范式
