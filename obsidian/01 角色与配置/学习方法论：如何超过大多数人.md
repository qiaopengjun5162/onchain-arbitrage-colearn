# 学习方法论：如何超过大多数人

> 陈皓（左耳朵耗子）《如何超过大多数人》，2019。共学群分享归档：`notes/coolshell-outperform-most-people-20260821.md`

## 核心模型：认识 ≠ 知识 ≠ 技能

人的能力从「认识」开始，经培训/书本变成「系统知识」，再经训练实践变成「技能」。每道转换关卡过滤掉大部分人——90% 的人倒在硬核知识前，不是因为智商，是因为没有耐心。

## 反向自查清单（怎么被喂大的）

1. 信息渠道被截断 → 只能吃二手/三手信息（中间人攻击）
2. 信息质量差 → garbage in garbage out
3. 混淆认识与知识 → 「开阔认知」=「学习」的幻觉
4. 碎片化学习 → 失去精读耐性
5. 收藏家陷阱 → 存一堆资料抓不住重点
6. 死记硬背劝退 → 失去信心直接放弃
7. 玩具化 → 玩玩具以为就是专业
8. 伸手党 → 直接要答案，从此不思考
9. 「读完了=学好了」 → 不总结不实践
10. 996 = 唯一成功路径 → 困在低端劳动力
11. 一夜暴富叙事 → 股市/数字货币财富神话
12. 「21 天学会 X」 → 难事都有捷径
13. 比较焦虑 → 浮躁、失去耐性、剑走偏锋
14. 患得患失 → 只看失去的，不识真正价值

## 正面四层模型

**认知层**：一手信源 > 二手解读；信息质量 > 信息数量；密度大的信息逼你搜索、沉思、验证（经验性文章 > 知识性文章）。

**知识层**：学知识树/图不学孤立点（根基=基础知识）；知其然且知其所以然（缘由 > 记忆）；学方法不学答案（方法套路 > 解题本身）。

**技能层**：精益求精（每次重复找更好方法，否则是搬砖）；主动犯错并反思（唯一别重复犯同一个错）；找高手切磋（「哇还可以这么玩」）。

**领导力层**：识别特长天赋（别人费力你不费劲的事，是鱼就拉人下水，别上岸拼）；识别真兴趣（愿付出一辈子的死磕 = 事业，多数人只有职业）；建立高级习惯（自律+目标：每年一新技术/每月一算法/每周一篇英文论文）；勤奋兜底（一万小时，拼不过聪明人拼过懒人就行）。

## 与共学机制的映射

| 陈皓模型 | 我们的机制 | 状态 |
|---|---|---|
| 一手信源 | evidence-tracker、链上取证原始 RPC | ✅ |
| 知识树 | L0009 知识图谱（概念→机制→工具→决策） | ✅ |
| 知识缘由 | 拆机制不背结论（TUT 屠宰场三件套） | ✅ |
| 技能=实践+犯错 | 双实现脚本、回测验证、失败想法完整记录 | ✅ |
| 高手切磋 | 周会 digest、群友案例拆解 | ✅ |
| 反「知道≠做到」 | 费曼复述 15min/天 | ✅ |

## 结论

- 学习机制本身就是护城河：碎片化、收藏家、「读完了=学好了」是三个最大坑，我们的机制设计全部在对抗这三者。
- 金句：超过大多数人不需要多聪明，只需要拼过懒人——但前提是走完认知→知识→技能转换，不是停在「开阔认知」。
