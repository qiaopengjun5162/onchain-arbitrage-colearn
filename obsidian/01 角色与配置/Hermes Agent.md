# Hermes Agent（共学执行层入口）

> 来源：Bruce 配置指南（2026-08-05，共学第一天）
> 定位：长期在线、Telegram 随时接任务、能找回历史会话、把重复流程沉淀成 Skills 的辅助 Agent

## 为什么用 Agent 辅助套利（按价值排序）

1. **积累判断**：普通聊天问完就过，Agent 把看过的策略、回测、为什么不成立都留下——下次类似机会不用从零来（**这是复利来源**）
2. **自动化验证**：写脚本、跑回测，快速证伪
3. **学习**：不懂直接问，顺着资料查

典型：把 X 帖子丢给 Hermes → 提取策略 → 规则明确就找数据、写脚本、跑回测。某「土狗王」喊单回测约 1 小时完成。Bruce 自标：回测和实盘两码事，价值是「快速证伪」不是「发现圣杯」——1 小时排除不靠谱策略就是巨大收益。

## 与本项目（Codex/桌面端）的分工

- **Hermes（Telegram 入口）= 执行层**：已想清楚的原子任务（查资料/跑脚本/打卡/拆步骤）
- **桌面端 Codex（本仓库维护者）= 沉淀层**：理结构、机制分析、把讨论蒸馏成长期笔记、决定组织方式
- 判断标准：**想「做」具体小事 → Hermes；想「想清楚/整理/沉淀/定方向」→ 桌面端**

## 部署路径

- 新手先本地（Mac/Windows 用 Hermes Desktop，Linux/macOS/WSL2 命令行）；进阶再上服务器（需一直在线）
- 判断：先本地跑通一次确认真会长期用，再迁移
- 硬件：起步 2C 4G 够；Bruce 自用 i7-14700KF/128G。CN2 主机商小兔互联（moebun.com）28 RMB/月，但**重要代码和私钥不合适放无状态反代**

## 模型与存储

- 主模型 gpt-5.6-sol medium/high（200 USD Sub + Sub2API 反代）；备模型 DeepSeek（量化场景优势待验证）
- 原则：永远用前沿模型；预算有限可便宜模型但设好预期
- 数据：大量读写直接让 Hermes 起 PostgreSQL 容器，别用 Markdown 硬扛

## 消息平台

- 主力 Telegram：建私人群 + 开 Topics（按策略/任务分区）；Bruce 分类「套利学习/策略研究/数据与回测/开发/打卡」
- 国内替代飞书；微信不适合主入口（单窗口、无法并发、群消息接入不可靠）

## 学习方法（开新方向首 Prompt）

> 问我 10 个问题，判断我对链上/DeFi/编程/套利的了解、想做什么、每天投入多少。一次一个，问完再出计划。

让 Agent 先知道六件事：已会什么、真正感兴趣方向、编程/链上能力、偏研究/开发/数据/实盘、每天投入、哪些不能自动执行。计划先给最近一两周，今天能做的进 Todo。

## 共学平台接入

- 官网 Access Keys 创建 Key → 发给 Hermes 测连通性 + 读课程内容
- 每天学完让 Agent 整理「做了什么/证据在哪/没完成什么」并自动打卡
- 可定期任务检索几百位同学打卡笔记（「大佬笔记是精华」有了可执行读取方式）
